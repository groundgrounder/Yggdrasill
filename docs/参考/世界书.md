# 参考：世界书

本文逐项列出世界书的目录、文件、ID、声明与模板。各项的含义见第一章“世界书”。

## 目录

| 类 | 目录 | 层 | 要求 |
|---|---|---|---|
| 固定根 | `角色`、`历史`、`设定` | 一 | 必须存在 |
| 文本容器 | `世界概况`、`扮演准则` | 四、五 | 名称固定，只放供模型阅读的正文，按文件名的码点顺序读取 |
| 条目库 | 由 `设定/条目库.yaml` 声明的库名 | 二 | 平铺在根下，未声明的目录报错 |

以 `.` 开头的文件与目录不读取。

## 固定根

| 路径 | 扩展名 | 内容 |
|---|---|---|
| `角色/{角色组ID}/角色组.yaml` | `.yaml` | 角色组、版本与档案项，见参考“角色” |
| `角色/{角色组ID}/档案/{档案ID}/基本信息.txt` | `.txt` | 基本信息，每份档案必须且只能有这两份文件 |
| `角色/{角色组ID}/档案/{档案ID}/角色印象.txt` | `.txt` | 角色印象 |
| `历史/事件/{事件ID}/事件.txt` | `.txt` | 预设事件，见参考“事件” |
| `历史/事件/{事件ID}/角色/{角色组ID}.txt` | `.txt` | 角色位置，事件目录下只有 `事件.txt` 与 `角色/` |
| `历史/事件串/{事件串ID}.yaml` | `.yaml` | 事件串 |
| `历史/开局选项.yaml` | `.yaml` | 开局选项，可选 |
| `历史/开局方案/{方案ID}.yaml` | `.yaml` | 开局方案 |
| `设定/{声明名}.yaml` | `.yaml` | 声明，见“声明文件” |

固定根不放说明文件。

## 协议读取的条目库

| 库 | 协议读取的字段 | 用途 |
|---|---|---|
| 技能 | `技能ID`，以及技能可用规则引用的字段 | 计算可用技能、展开技能条目、校验技能补充与集合维度中的技能成员 |
| 装备 | `装备ID` | 本局中装备的键、初始装备与变化引用的装备 |
| 地点 | `地点ID`，上级由目录推出 | 当前地点的地标、地点链、条件“当前场景”与所在的比较 |

三库都可以不声明。地点库须按上下级分。依赖它们的条件与字段，在没有声明时不可用。

## 扩展名

| 扩展名 | 读者 | 进入上下文或展示给玩家的部分 |
|---|---|---|
| `.txt` | 叙事模型 | 剥离机器字段后的文本字段，路由按各部分的规定选取 |
| `.yaml` | 工具 | 只有：角色组与版本的显示名、别名，版本的简介；事件串的概述，开局选项的问题与选项文字，开局方案的概述 |

两种文件的内容都按 YAML 书写。措辞检查扫描 `.txt` 中的文本字段与 `.yaml` 中的上列字段。扩展名与文件的种类不符时报错。

## ID

| 对象 | ID 的来源 | 文件中是否写 ID |
|---|---|---|
| 角色组 | 目录名 | 否 |
| 版本 | `角色组.yaml` 中的 `版本ID` | 是 |
| 档案 | 档案目录名，`角色组.yaml` 的档案项写 `档案ID`，须与目录一一对应 | 两份档案文件不写 |
| 预设事件 | 事件目录名 | `事件.txt` 写 `事件ID`，须等于目录名 |
| 分支 | 事件中的 `分支ID`，事件内唯一 | 是 |
| 角色位置 | 事件目录名与文件名 | 写 `事件ID` 与 `角色组ID`，须一致 |
| 事件串、开局方案 | 文件名 | 否 |
| 条目 | 文件名；按上下级分的库，目录型实例的目录名 | 写 `{库名}ID`，须一致 |
| 动态事件 | 命令给出 | 本局的事件记录以它为键 |
| 首次登场初始化 | `初次登场·{角色组ID}` | 本局的事件记录以它为键 |

## 命名

| 规则 | 适用的 ID | 层 | 级别 |
|---|---|---|---|
| 不为空，首尾不留空白，不含 `.`、`/`、`\` | 全部 | 一 | 错误 |
| 不用保留字 `玩家`、`__proto__`、`constructor`、`prototype` | 全部 | 一 | 错误 |
| 动态事件ID不与预设事件重复，不以 `初次登场·` 开头 | 动态事件 | 一 | 协议报错 |
| 不呈编码样式，即不只由拉丁字母、数字、`_`、`-` 组成 | 角色组、版本、事件、条目 | 四 | 提示 |
| 不超过 12 字 | 角色组、版本、事件、条目 | 四 | 提示 |
| 本卡的命名规则 | 按 `设定/文本规范.yaml` 的声明 | 五 | 错误 |

## 声明文件

| 文件 | 必需 | 声明 |
|---|---|---|
| `纪年.yaml` | 是 | 时间的写法 |
| `等级.yaml` | 声明了等级维度或引用了 `等级.{名字}` 时 | 等级序列 |
| `能力.yaml` | 有技能库，或引用了 `能力.{维度}` 时 | 能力维度与技能可用规则，见参考“角色” |
| `事件分类.yaml` | 是 | 主类型、世界事件、标签、事件结果 |
| `条目库.yaml` | 有条目库时 | 各库的分法、分级、上级类型与字段 |
| `本局变量.yaml` | 是 | 词表、二层的角色与世界字段、单次增减上限，见参考“协议” |
| `剧情标记.yaml` | 有剧情标记时 | 剧情标记及其取值 |
| `角色分类.yaml` | 有角色组时 | 角色包与分类 |
| `文本规范.yaml` | 否 | 第五层中能机器检查的部分 |

`设定/` 只放 `.yaml`。默认声明在世界树仓库的 `defaults/设定/`：`事件分类.yaml` 与 `本局变量.yaml`。

## 声明的键

| 文件 | 键 | 必填 | 写法 |
|---|---|---|---|
| `等级.yaml` | `{序列名}` | | 非空、无重复的等级列表，从低到高 |
| `事件分类.yaml` | `主类型` | 是 | 非空、无重复的列表 |
| | `世界事件` | 否 | `主类型` 中的一项 |
| | `标签` | 是 | 非空、无重复的列表 |
| | `事件结果` | 是 | 映射：结果名 → 支撑字段的列表，可以为空列表 |
| `剧情标记.yaml` | `{标记ID}` | | 非空、无重复的取值列表，第一个是开局值 |
| `角色分类.yaml` | `角色包` | 是 | 非空、无重复的列表 |
| | `分类` | 是 | 非空、无重复的列表 |

事件结果的支撑字段，取一层骨架的角色与世界字段、能力维度、二层角色字段、`剧情标记`，或保留的支撑名 `档案切期`。

## 纪年

| 键 | 写法 |
|---|---|
| `前缀` | 文本，首尾不留空白 |
| `年位数` | 1 至 11 的整数 |
| `月数` | 1 至 99 的整数 |
| `每月天数` | 1 至 99 的整数，或长度等于月数、每项 1 至 99 的整数列表 |

四个键都须写，不能有其它键。

| 时间 | 写法 | 区间 |
|---|---|---|
| 写到年 | `{前缀}{年}年`，年补足到年位数 | 整年，即首月首日至末月末日 |
| 写到日 | `{前缀}{年}年{MM}月{DD}日`，月日各两位 | 当日 |

区间含起点、不含终点。事件的时间写到年或写到日。

## 条目库声明

`条目库.yaml` 的每个顶层键是一个库名，等于根下的目录名，库名不能与固定根、文本容器或保留字重名。

| 键 | 必填 | 写法 |
|---|---|---|
| `分法` | 是 | `按种类` 或 `按上下级`，地点库只能按上下级 |
| `分级` | 按种类时必填 | 字段名列表，依次对应各级子目录，每个字段须是本库已声明的单值取值字段，按上下级时不能写 |
| `上级类型` | 否 | 只用于按上下级：映射，类型 → 允许的上级类型列表，空列表表示只能在库根 |
| `字段` | 是 | 字段名 → 字段声明，见“字段写法”，不能声明 `名称`、`ID` 或本库的 `{库名}ID` |

写了上级类型，或某个字段写了适用类型的库，须声明名为 `类型`、以行内列表为取值的单值字段。条目的 `{库名}ID` 必填、等于文件名。`名称` 可选，省略时等于 ID。其余的键都须已声明。

| 分法 | 实例文件 | 说明文件 | 上级 |
|---|---|---|---|
| 按种类 | 其余 `.txt`，所在各级目录名须等于分级字段的值 | 库根与各级分类目录下与目录同名的 `.txt` | 无 |
| 按上下级 | 全部 `.txt`，与所在目录同名的是该目录这个实例的条目 | 只有库根的 `{库名}.txt` | 与目录同名时为再上一级目录的实例，否则为所在目录的实例，库根下的实例没有上级 |

## 字段写法

字段声明恰好写下列一种写法，可加修饰。

| 写法 | 含义 | 层 | 可用于 |
|---|---|---|---|
| `形态: {形态}` | 文本，形态见“文本形态” | 四 | 条目库、本局变量、档案追加字段 |
| `取值: {值域}` | 值须在值域之内 | 三 | 同上 |
| `引用: {库名 / 角色组 / 事件}` | 值须是能解析的 ID | 三 | 同上 |
| `子字段: {子键: 声明, …}` | 由固定子键组成，子键按同样的写法声明，非空 | 按子字段 | 同上 |
| `映射: {键: 声明, 值: 声明}` | 键任意、结构相同的字典 | 按键与值 | 同上 |
| `数值: [下限, 上限]` | 整数，下限不大于上限，结果截断在范围之内 | 三 | 只用于本局变量 |
| `集合: 声明` | 无序、不重复的成员，只能逐项新增或移除 | 按成员 | 只用于本局变量 |

| 修饰 | 写法 | 限制 |
|---|---|---|
| `必填` | 布尔 | |
| `列表` | 布尔，值是一组 | 只用于取值与引用 |
| `适用类型` | 类型列表，只有这些类型的条目可以有这个字段 | 只用于条目库，须引用本库的类型字段 |

| 值域 | 含义 |
|---|---|
| 行内列表 | 非空、无重复的值的列表 |
| `等级.{名字}` | 某个等级序列中的等级 |
| `能力.{维度}` | 某个等级映射维度的键 |
| `纪年` | 按纪年书写的时间 |
| `词表.{名字}` | `设定/本局变量.yaml` 中命名的取值表，第一个值是默认值 |

## 文本形态

| 形态 | 写法 |
|---|---|
| 文本 | 非空的一句话 |
| 文本列表 | 每项一句话 |
| 短语列表 | 每项一个短语，不以句号结尾 |
| 情境列表 | 每项是单键映射，键写情境，值写表现 |
| 禁区列表 | 每项以“不”开头 |

可选字段没有内容时整键省略。能力特征的特征与技能补充例外：没有内容时写空列表。

## 本卡文本规范

`设定/文本规范.yaml` 的键都属第五层，只能收紧或补充第四层。

| 键 | 写法 |
|---|---|
| `禁用词` | 追加的禁用词列表，出现即报错 |
| `ID命名` | 映射：命名空间 → 规则。命名空间为 `全部`、`角色组ID`、`版本ID`、`档案ID`、`剧情标记ID`、`能力键`、`事件ID` 或 `{库名}ID`；规则为 `只用中文: true`，即不含拉丁字母，或 `前缀字段: {本库字段}`，即 ID 写作“该字段的值·名称” |
| `档案追加字段` | 映射：`基本信息` 或 `角色印象` → 新增的可选字段，写法同“字段写法”，不能与已有字段重名，不能必填 |
| `长度预算` | 映射：对象 → 正整数，不能大于第四层的预算，见“措辞检查” |

## 措辞检查

措辞检查扫描的文本：条目、说明文件、档案与文本容器的 `.txt` 中的文本字段，事件与角色位置中除结构字段之外的字段，`.yaml` 中见“扩展名”所列的字段。

| 检查 | 范围 | 内容 | 级别 |
|---|---|---|---|
| 禁用词 | 全部扫描的文本 | `stat_data`、`变量`、`schema`、`索引`、`路由`、`ID`、`状态0`、`状态1`、`状态2`、`状态0/1/2`、`候选事件`、`额外模型`、`冲突队列`、`条目`、`注册`、`挂载`、`加载`、`目录`、`记录规则`、`目录规则`、`统一格式`、`登记规则`、`引用边界`、`记录边界`、`维护`，以及第五层追加的禁用词 | 错误 |
| 系统视角 | 说明文件，以及按上下级分的库中与目录同名的条目 | `模块`、`读取`、`登记`、`记录`、`资料`、`写入`、`本文件`、`运行状态`、`定义`、`依据`、`入口` | 错误 |
| 破折号 | 全部扫描的文本 | U+2014、U+2015，出处的台词记录所列的原台词中出现时只提示 | 错误 |
| 陈旧的写法 | 全部扫描的文本 | `似乎`、`几乎`、`仿佛`、`如同`、`宛如`、`嘴角微微上扬`、`眼中闪过一丝`、`心湖泛起涟漪`、`万念俱灰` | 提示 |
| 长度 | 见下表 | 去掉空白后的字数超出预算 | 提示 |

| 长度预算的对象 | 字数 |
|---|---|
| 说明文件与按上下级分的库中与目录同名的条目 | 300 |
| 基本信息 | 500 |
| 角色印象 | 600 |
| 事件 | 800 |

## 模板

模板是世界树仓库 `templates/` 下的三份文本，属第一层：`变量更新规则.txt`、`角色通用约束.txt`、`扮演准则.txt`。打包时依次生成，以空行分隔，构成协议文本。`变量更新规则.txt` 是关闭记账时的正文 `<命令>` 版本；默认记账开启时，适配层按第六章切换为记账版协议文本。占位符只有下表五种，出现其它占位符时报错。

| 占位符 | 生成 |
|---|---|
| `{{纪年格式}}` | 纪年的写法与每月天数，例如“中平YYY年或中平YYY年MM月DD日（年份 3 位，每年 12 个月，每月 30 天）”，各月天数不同时列出各月天数（如“各月 91、91、91、92 天”） |
| `{{单次增减上限}}` | 第二层声明的单次增减上限 |
| `{{可写字段}}` | 动态事件可写的字段，见“可写字段” |
| `{{地点列表}}` | 地点库的全部地点，按上下级缩进，每级两个空格，同级按 ID 的码点顺序，每行“地点ID（类型）”，没有地点库时为“无” |
| `{{本卡扮演准则}}` | `扮演准则/` 下各文件的原文，按文件名的码点顺序，以空行分隔，没有时为“无” |

## 可写字段

`{{可写字段}}` 每行写“路径：操作；取值”，按下列顺序。在场、所在、能力移除记录与已初始化不列。

| 顺序 | 路径 | 操作 |
|---|---|---|
| 1 | `世界.剧情标记.{标记ID}`，按声明的顺序 | 设定 |
| 2 | `世界.{二层世界字段}` | 按字段的写法 |
| 3 | `角色.<角色组ID>.{二层角色字段}` | 按字段的写法 |
| 4 | `角色.<角色组ID>.{能力维度}`，等级映射写作 `….<键>` | 等级为提升、设定、移除，集合为新增、移除 |
| 5 | `角色.<角色组ID>.装备.<装备ID>`，有装备库时 | 新增、设定、移除 |

| 字段的写法 | 操作 | 取值的写法 |
|---|---|---|
| 取值、文本、引用 | 设定 | 取值表写作“甲 / 乙 / 丙”，纪年写纪年格式，文本写“文本”，引用写 `<库名ID>` |
| 映射 | 路径加 `.<键>` 或 `.<库名ID>`，值为设定、新增、移除 | 按值的写法 |
| 数值，包括值为数值的映射 | 增加、减少 | “下限 至 上限 的整数” |
| 集合 | 新增、移除 | 成员的取值，成员取自条目库时写 `<库名ID>`，有成员条件时后接“（字段为 值）” |
| 子字段 | 各子字段逐个展开成单独的行 | 按子字段的写法 |
| 等级维度 | 见上表 | 该维度所用的等级，等级映射另列可用的键 |

## 出处记录

`作者资料/出处/` 下的 YAML 文件，每项是一条记录，文件划分由项目自定。

| 记录 | 字段 | 校验 |
|---|---|---|
| 事件级记录 | `事件ID`、`来源` | 事件存在 |
| 台词记录 | `事件ID`、`角色组ID`、`台词`、`来源` | 事件存在，该事件有这个角色组的角色位置，台词在它的候选台词中 |

记录中不能有其它键，`来源` 为文本。台词记录所列的台词，措辞检查视为原台词。台词在来源原文中逐字存在、说话人与角色位置一致，由作者人工核对，不在世界树工具的自动核对范围内。

## 暂存清单

`作者资料/暂存/暂存清单.yaml` 逐项登记暂存的内容，接回之后删除对应的项。检查器不读取它。

| 字段 | 写法 |
|---|---|
| `类型` | 档案、事件或条目 |
| `ID` | 暂存内容的 ID |
| `接回位置` | 接回后在世界书中的路径 |
| `接回结构` | 接回时要写入的结构，例如档案在 `角色组.yaml` 中的档案项 |
| `接回条件` | 文本，说明须先满足什么 |

## 输入限制

| 对象 | 限制 | 违反时 |
|---|---|---|
| YAML 文件 | 键不能重复，别名不超过 100 个，不能有循环别名 | `目录.YAML错误`，声明文件同 |
| 运行参数文件 `yggdrasill.yaml` | 只有 `运行参数` 一个键 | `运行参数.格式` |
