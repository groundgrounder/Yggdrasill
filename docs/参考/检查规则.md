# 参考：检查规则

本文列出检查器报告的规则名、命令行工具的错误码、协议与路由的错误码，以及酒馆适配层的错误码。检查器的每条结果写规则名、级别、文件与说明。错误须改正，提示由作者判断。本表按代码中的规则名与错误码整理，规则的依据见各章与其余参考表。

## 目录

| 规则 | 级别 | 触发 |
|---|---|---|
| `目录.缺少固定根` | 错误 | 缺少角色、历史或设定 |
| `目录.未声明目录` | 错误 | 根下的目录不是固定根、文本容器或已声明的条目库 |
| `目录.未知文件` | 错误 | 固定根或历史下出现未规定的文件与目录，文件无法归类 |
| `目录.扩展名不符` | 错误 | 扩展名不是 `.txt` 或 `.yaml`，或与文件的种类不符 |
| `目录.包裹标签` | 错误 | 源文件中有单独成行的包裹标签 |
| `目录.空壳说明` | 提示 | 说明文件没有内容 |
| `目录.YAML错误` | 错误 | YAML 解析失败，或有重复的键、循环别名，或别名超过 100 个 |
| `目录.读取失败` | 错误 | 目录或文件无法读取（含实际路径与 EACCES 等错误类型），符号链接与特殊文件不读取 |

## 命名

| 规则 | 级别 | 触发 |
|---|---|---|
| `命名.非法字符` | 错误 | ID 为空、首尾有空白，或含 `.`、`/`、`\` |
| `命名.保留字` | 错误 | ID 使用了保留字 |
| `命名.编码样式` | 提示 | 角色组、版本、事件或条目的 ID 只由拉丁字母、数字、`_`、`-` 组成 |
| `命名.过长` | 提示 | 角色组、版本、事件或条目的 ID 超过 12 字 |
| `命名.本卡规则` | 错误 | 违反 `设定/文本规范.yaml` 的 ID 命名规则 |
| `命名.文件名不符` | 错误 | 条目的 `{库名}ID` 不等于文件名 |

## 设定

| 规则 | 级别 | 触发 |
|---|---|---|
| `设定.缺少文件` | 错误 | 缺少必需的声明文件，或缺少用到的声明文件，有角色组而没有 `角色分类.yaml` |
| `设定.格式` | 错误 | 声明不是映射，有未知的键或缺少必填的键，列表为空或有重复，世界事件不在主类型中 |
| `设定.纪年` | 错误 | 纪年的四个键不齐，或位数、月数、每月天数不合法 |
| `设定.能力` | 错误 | 能力维度的类型、等级、键、成员或综合实力不合法，维度与角色字段重名 |
| `设定.技能可用` | 错误 | 技能可用规则的形状、维度、适用条件或引用的技能字段不合法，有规则而没有技能库 |
| `设定.条目库` | 错误 | 库名、分法、分级、上级类型或适用类型不合法 |
| `设定.字段声明` | 错误 | 字段声明不是恰好一种写法，值域或引用不存在，修饰用错位置，数值或集合用在本局变量之外 |
| `设定.本局变量` | 错误 | 缺少 `词表.装备状态`，字段与骨架或能力维度重名，单次增减上限不是正整数 |
| `设定.事件结果支撑` | 错误 | 事件结果的支撑字段未声明 |
| `设定.剧情标记` | 错误 | 剧情标记的取值不是非空、无重复的列表 |
| `设定.文本规范` | 错误 | 第五层的禁用词、ID 命名、档案追加字段或长度预算不合法，或放宽了第四层 |

## 条目

字段的取值按声明校验，规则名为 `条目.{项}`，项为 `形态`、`取值`、`引用`、`子字段或映射`、`缺必填`、`适用类型`。

| 规则 | 级别 | 触发 |
|---|---|---|
| `条目.形态` | 错误 | 条目不是映射，名称不是文本，文本字段不合形态 |
| `条目.未声明字段` | 错误 | 条目中有未声明的键 |
| `条目.缺必填` | 错误 | 缺少 `{库名}ID`、必填字段或技能可用规则所需的字段 |
| `条目.重复ID` | 错误 | 库内 ID 重复 |
| `条目.分级` | 错误 | 按种类分的库，目录与分级字段的值不一致，或层数超出分级 |
| `条目.上级类型` | 错误 | 按上下级分的库，上级不存在、类型搭配不合声明，或实例目录缺少同名实例文件 |
| `技能.可用规则` | 错误 | 技能不是恰好适用一条技能可用规则 |
| `技能.门槛取值` | 错误 | 技能的键字段或等级字段的值不合维度 |
| `技能.集合成员` | 错误 | 集合持有所管辖的技能不合集合维度的成员声明 |

## 命令

命令行工具在参数、读取或封卷失败时，用下列规则名报告并退出非零，覆盖全部十一个子命令：`check`、`trace`、`if`、`preview`、`context`、`tree`、`status`、`init`、`view`、`pack`、`format`。结果里的错误与提示仍按本表前文的级别处理。

| 规则 | 触发 |
|---|---|
| `trace.参数` | 对象键缺少类型前缀或 ID |
| `trace.未知类型` | 对象键的类型不在事件、事件串、角色组、档案、条目、剧情标记、开局选项、开局方案八类中 |
| `trace.歧义` | 同一对象键对应多个定义 |
| `trace.对象不存在` | 对象键合法但对象不存在 |
| `trace.读取失败` | 世界书或声明无法读取 |
| `引用.目标不存在` | 级别为错误；`trace` 建立引用索引时，引用指向的目标对象不存在 |
| `引用.结构` | 级别为错误；`trace` 建立引用索引时，引用目标 ID 缺失或不是文本 |
| `引用.条件结构` | 级别为错误；`trace` 建立引用索引时，门槛或生效条件不是单键映射、组合词列表为空或条件类型未知 |
| `if.参数`、`if.参数冲突` | if 选项不合法或互相冲突 |
| `if.方案不存在`、`if.事件不存在`、`if.分支不存在`、`if.角色组不存在` | 选项引用的对象不存在 |
| `if.时间轴为空`、`if.纪年`、`if.时间轴` | 无法按事件窗口确定时间轴末尾 |
| `if.读取失败` | if 读取或封卷失败 |
| `if.计算失败` | 级别为错误；`if` 计算过程中捕获未带已知规则码的意外异常时的兜底错误码 |
| `预览.参数` | preview 选项不合法，或 `--本局` 与 `--开局`、`--方案` 同用 |
| `预览.角色组` | 角色组不存在 |
| `预览.方案` | 开局方案不存在 |
| `预览.时间轴` | 无法按事件窗口确定时间轴末尾 |
| `预览.封卷` | 封卷失败；说明保留原 `封卷.*` 错误码与信息 |
| `预览.本局` | 本局文件不可读、不是合法 JSON、不是已封卷状态，或其中的本局变量不合法 |

| `上下文.方案` | 开局方案不存在 |
| `上下文.时间轴` | 无法按事件窗口确定时间轴末尾 |
| `上下文.本局` | 本局文件不可读、不是合法 JSON、不是已封卷状态，或其中的本局变量不合法 |
| `上下文.封卷` | 封卷失败；说明保留原 `封卷.*` 错误码与信息 |
| `上下文.地点` | 地标不存在 |
| `上下文.角色组` | 角色组不存在或未启用；“玩家”仅在自建模式下可在场 |
| `上下文.场景` | 推演在场或写场景被协议拒绝（含 `--不自动初始化` 下的首次登场门禁）；说明保留原 `协议.*` 错误码与信息 |
| `上下文.读取失败` | 世界书或运行参数读取失败、编译有错误级问题，或其它未预期错误 |
| `事件树导出.参数` | tree 选项不合法、缺少或多给世界书目录 |

| `事件树导出.写入失败` | 无法写入导出文件 |
| `状态.参数` | status 参数不合法：多给目录或未知选项 |
| `状态.路径` | 目标路径不存在、不可读或不是目录，或诊断本身失败 |
| `初始化.参数` | init 选项不合法，或纪年参数组合不合法 |

| `初始化.已存在` | 未传 `--force` 而目标已有脚手架文件；预检拒绝，不写任何内容 |
| `view.参数` | view 参数不合法 |
| `view.启动失败` | 存储隔离校验未通过、端口或本地服务启动失败；保存错误另走 HTTP 4xx，预览/保存冲突为 409 |
| `pack.参数` | pack 选项不合法、重复 `--face`、非法 `--compatible` 指纹或多给项目目录 |
| `pack.失败` | 卡面读取/字段校验失败（含 `可选在场`、`必需角色组`、`按方案` 的未知方案、未知键、`玩家` 红线、重复或冲突、方案开场白含 `<命令>`）、世界书编译/检查失败、顶层或逐方案开场命令封卷/执行失败、程序依赖校验失败或 `esbuild` 缺失/打包失败 |
| `检查.规则失败` | 检查器外层失败；静态检查有错时另加 `抽样.未执行` 提示 |

`check` 不另设命令错误码；`format` 用 `项目.异常` 计数，有差异或有异常时退出非零；`trace` 异常还包含上表“开局与出处”中的 `出处.结构` 与 `出处.角色位置不符`（级别均为错误）。

## 协议的错误码

协议与路由在写入或读取失败时报错，什么也不写。错误码如下。

| 错误码 | 触发 |
|---|---|
| `协议.参数` | 本局变量、命令或读取的参数不合法，命令不是已知命令名到参数映射的单键映射；写场景时角色组或地点不存在，时间、地点、在场或所在的形状与取值不合法 |
| `协议.未封卷` | 写入之前没有封卷 |
| `协议.事件状态` | 确认的事件不是候选、已有排除记录或已以其他分支确认，所选分支的门槛不成立，待登记事件更换了分支，或结束的事件串不在进行中 |
| `协议.变化` | 变化不合法，路径中的角色组未启用，或扮演模式下写了“玩家” |
| `协议.参与者` | 实际参与者未启用，或扮演模式下列入了“玩家” |
| `协议.场景` | 当前时间倒退；写在场时的角色组未启用、是扮演角色组或写了 `玩家`，或从未出场的显式确认角色组未初始化；写所在时的角色组未启用，或该角色组仍在场 |
| `协议.初始化` | 确认初始化的角色组未启用，或当前档案不成立 |
| `协议.能力取值` | 本局中能力的值不在维度的范围之内 |
| `协议.排斥冲突` | 排斥检查不通过 |
| `封卷.参数` | 封卷的参数不合法，方案不存在，或缺少开局时间 |
| `封卷.历史选择` | 历史选择的事件不是开局前事件或值不合法，或指定的分支未能写入 |
| `封卷.时间顺序冲突` | 封卷的历史求解中出现倒流 |
| `封卷.配置冲突` | 封卷的排斥检查不通过 |
| `运行参数.格式` | 运行参数不合法 |
| `模板.占位符` | 模板中出现未知的占位符 |

## 适配层错误码

酒馆适配层（`adapter/`）在打包清单、内存文件系统、宿主权限、开局与开场、楼层记录与归属、记账、修补、重放及提交阶段使用的错误码如下（含 `开局.*`、`开场.*`、`记录.*`、`归属.*`、`运行清单.*`、`清单.*`、`路径.*`、`权限.*`、`记账.*`、`修补.*`、`重放.*`、`提交.*` 共 49 个核心错误码，以及命令解析、路由、执行与兜底校验码）。

### 开局与开场

| 错误码 | 触发 |
|---|---|
| `开局.失败` | 开局预演或提交发生未归类错误（如聊天切换、开场白缺失或变更、非第 0 楼提交、保存或回滚异常） |
| `开局.未完成` | 尚未完成开局，处于等待玩家确认开局的状态 |
| `开局.方案` | 所选开局方案在世界书中不存在 |
| `开局.角色组` | 开局选定的角色组不存在，或修改补丁不是映射 |
| `开局.必需角色组` | 当前方案必需角色组、非可选开场命令涉及角色、生效前置历史事件核心参与者或玩家扮演角色组未启用 |
| `开局.玩家` | 玩家模式不是 `自建` 或 `扮演`，或所选扮演角色组不存在 |
| `开局.档案` | 自建玩家档案草稿 YAML 解析失败，或解析结果不是 YAML 映射 |
| `开局.历史选择` | `自由组合` 关闭时尝试修改历史选择，或选择的事件与分支不在 `开局选项` 声明内 |
| `开局.封卷` | 第 0 楼本局的 `开局` 中 `已封卷` 字段不为真，或重放第 0 楼封卷时抛出未带已知错误码的异常 |
| `开场.命令` | 第 0 楼开场命令经协议执行后存在失败项 |
| `开场.重复` | 尝试对第 0 楼重新记账（第 0 楼不会重新执行开场命令） |
