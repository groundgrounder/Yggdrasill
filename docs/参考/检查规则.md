# 参考：检查规则

本文列出检查器报告的规则名与协议的错误码。检查器的每条结果写规则名、级别、文件与说明。错误须改正，提示由作者判断。本表按代码中的规则名整理，规则的依据见各章与其余参考表。

## 目录

| 规则 | 级别 | 触发 |
|---|---|---|
| `目录.缺少固定根` | 错误 | 缺少角色、历史或设定 |
| `目录.未声明目录` | 错误 | 根下的目录不是固定根、文本容器或已声明的条目库 |
| `目录.未知文件` | 错误 | 固定根或历史下出现未规定的文件与目录，文件无法归类 |
| `目录.扩展名不符` | 错误 | 扩展名不是 `.txt` 或 `.yaml`，或与文件的种类不符 |
| `目录.包裹标签` | 错误 | 源文件中有单独成行的包裹标签 |
| `目录.空壳说明` | 提示 | 说明文件没有内容 |
| `目录.YAML错误` | 错误 | YAML 解析失败，或有重复的键、循环别名，或别名超过 100 个 |
| `目录.读取失败` | 错误 | 目录或文件无法读取，符号链接与特殊文件不读取 |

## 命名

| 规则 | 级别 | 触发 |
|---|---|---|
| `命名.非法字符` | 错误 | ID 为空、首尾有空白，或含 `.`、`/`、`\` |
| `命名.保留字` | 错误 | ID 使用了保留字 |
| `命名.编码样式` | 提示 | 角色组、版本、事件或条目的 ID 只由拉丁字母、数字、`_`、`-` 组成 |
| `命名.过长` | 提示 | 角色组、版本、事件或条目的 ID 超过 12 字 |
| `命名.本卡规则` | 错误 | 违反 `设定/文本规范.yaml` 的 ID 命名规则 |
| `命名.文件名不符` | 错误 | 条目的 `{库名}ID` 不等于文件名 |

## 设定

| 规则 | 级别 | 触发 |
|---|---|---|
| `设定.缺少文件` | 错误 | 缺少必需的声明文件，或缺少用到的声明文件，有角色组而没有 `角色分类.yaml` |
| `设定.格式` | 错误 | 声明不是映射，有未知的键或缺少必填的键，列表为空或有重复，世界事件不在主类型中 |
| `设定.纪年` | 错误 | 纪年的四个键不齐，或位数、月数、每月天数不合法 |
| `设定.能力` | 错误 | 能力维度的类型、等级、键、成员或综合实力不合法，维度与角色字段重名 |
| `设定.技能可用` | 错误 | 技能可用规则的形状、维度、适用条件或引用的技能字段不合法，有规则而没有技能库 |
| `设定.条目库` | 错误 | 库名、分法、分级、上级类型或适用类型不合法 |
| `设定.字段声明` | 错误 | 字段声明不是恰好一种写法，值域或引用不存在，修饰用错位置，数值或集合用在本局变量之外 |
| `设定.本局变量` | 错误 | 缺少 `词表.装备状态`，字段与骨架或能力维度重名，单次增减上限不是正整数 |
| `设定.事件结果支撑` | 错误 | 事件结果的支撑字段未声明 |
| `设定.剧情标记` | 错误 | 剧情标记的取值不是非空、无重复的列表 |
| `设定.文本规范` | 错误 | 第五层的禁用词、ID 命名、档案追加字段或长度预算不合法，或放宽了第四层 |

## 条目

字段的取值按声明校验，规则名为 `条目.{项}`，项为 `形态`、`取值`、`引用`、`子字段或映射`、`缺必填`、`适用类型`。

| 规则 | 级别 | 触发 |
|---|---|---|
| `条目.形态` | 错误 | 条目不是映射，名称不是文本，文本字段不合形态 |
| `条目.未声明字段` | 错误 | 条目中有未声明的键 |
| `条目.缺必填` | 错误 | 缺少 `{库名}ID`、必填字段或技能可用规则所需的字段 |
| `条目.重复ID` | 错误 | 库内 ID 重复 |
| `条目.分级` | 错误 | 按种类分的库，目录与分级字段的值不一致，或层数超出分级 |
| `条目.上级类型` | 错误 | 按上下级分的库，上级不存在、类型搭配不合声明，或实例目录缺少同名实例文件 |
| `技能.可用规则` | 错误 | 技能不是恰好适用一条技能可用规则 |
| `技能.门槛取值` | 错误 | 技能的键字段或等级字段的值不合维度 |
| `技能.集合成员` | 错误 | 集合持有所管辖的技能不合集合维度的成员声明 |

## 协议的错误码

协议与路由在写入或读取失败时报错，什么也不写。错误码如下。

| 错误码 | 触发 |
|---|---|
| `协议.参数` | 本局变量、命令或读取的参数不合法，命令不是已知命令名到参数映射的单键映射 |
| `协议.未封卷` | 写入之前没有封卷 |
| `协议.事件状态` | 确认的事件不是候选，所选分支的门槛不成立，或待登记事件更换了分支，结束的事件串不在进行中 |
| `协议.变化` | 变化不合法，路径中的角色组未启用，或扮演模式下写了“玩家” |
| `协议.参与者` | 实际参与者未启用，或扮演模式下列入了“玩家” |
| `协议.场景` | 当前时间倒退，在场或所在的角色组不合法，从未出场的显式确认角色组未初始化就写为在场 |
| `协议.初始化` | 确认初始化的角色组未启用，或当前档案不成立 |
| `协议.能力取值` | 本局中能力的值不在维度的范围之内 |
| `协议.排斥冲突` | 排斥检查不通过 |
| `封卷.参数` | 封卷的参数不合法，方案不存在，或缺少开局时间 |
| `封卷.历史选择` | 历史选择的事件不是开局前事件或值不合法，或指定的分支未能写入 |
| `封卷.时间顺序冲突` | 封卷的历史求解中出现倒流 |
| `封卷.配置冲突` | 封卷的排斥检查不通过 |
| `运行参数.格式` | 运行参数不合法 |
| `模板.占位符` | 模板中出现未知的占位符 |
