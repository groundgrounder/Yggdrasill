# 参考：事件

本文逐项列出事件、条件、变化、角色位置、事件串与开局的字段和取值。各项的含义见第三章“事件”。

## 事件

`历史/事件/{事件ID}/事件.txt` 的字段，不能有表外的键。

| 字段 | 必填 | 写法 | 层 |
|---|---|---|---|
| `事件ID` | 是 | 等于目录名 | 三 |
| `事件标题` | 否 | 文本；省略时等于事件ID | 四 |
| `事件概要` | 是 | 文本 | 四 |
| `主类型` | 是 | 事件分类的主类型之一 | 三 |
| `标签` | 是 | 非空、无重复的列表，取事件分类的标签 | 三 |
| `事件结果` | 是 | 非空、无重复的列表，取事件分类的事件结果 | 三 |
| `影响范围` | 否 | 文本 | 四 |
| `触发时间` | 是 | `{最早, 最晚}`，只有这两个键，按纪年书写，窗口非空 | 三 |
| `地点` | 否 | 无重复的地点ID列表 | 三 |
| `确认策略` | 是 | `自动确认`、`条件确认` 或 `仅作候选` | 三 |
| `核心参与者` | 是 | 无重复的角色组ID列表，可以为空，不能含“玩家” | 三 |
| `门槛` | 否 | 条件，见“条件”；省略即恒成立 | 三 |
| `关联事件` | 否 | 非空、无重复的其它事件ID列表，只供作者查阅 | 三 |
| `叙事条件` | 否 | 文本，条件文本 | 四 |
| `公开信息` | 否 | 非空、无重复的文本列表 | 四 |
| `隐秘信息` | 否 | 非空、无重复的文本列表 | 四 |
| `默认分支` | 是 | 分支ID之一 | 三 |
| `分支` | 是 | 非空的分支列表，见“分支” | 三 |

## 机器字段

在组装上下文时剥离的字段，共十个。

| 字段 | 所在 |
|---|---|
| `门槛`、`确认策略`、`默认分支`、`关联事件` | 事件 |
| `变化` | 分支；分支的 `门槛` 也剥离 |
| `前置档案`、`生效条件`、`默认`、`适用版本` | `角色组.yaml` 的档案项 |
| `适用分支` | 角色位置 |

## 分支

| 字段 | 必填 | 写法 | 层 |
|---|---|---|---|
| `分支ID` | 是 | 文本，事件内唯一 | 三 |
| `门槛` | 否 | 条件；省略即恒成立 | 三 |
| `分支条件` | 是 | 文本，条件文本 | 四 |
| `分支结果` | 是 | 文本 | 四 |
| `变化` | 否 | 变化的列表，见“变化” | 三 |

自动确认的事件只要有分支带门槛，就须有不带门槛的兜底分支。

## 确认策略

| 确认策略 | 封卷 | 游玩中 | 封卷不可求值的条件 | 开局选项 |
|---|---|---|---|---|
| 自动确认 | 按门槛补入开局之前的历史 | 可由叙事模型确认；窗口结束时门槛成立且选得出分支，即为待登记 | 不得使用 | 可以 |
| 条件确认 | 按门槛补入开局之前的历史 | 须由叙事模型确认；窗口结束时未确认即排除 | 不得使用 | 可以 |
| 仅作候选 | 不参加 | 须由叙事模型确认；窗口结束时未确认即排除 | 可以使用 | 不可以 |

## 条件

条件是单键映射，键为组合词或条件类型。组合词 `all`、`any`、`none` 的值是非空的条件列表；条件类型的值是参数映射，不能有表外的参数。条件不能为 `null`。

| 条件类型 | 参数 | 参数的写法 | 成立 | 封卷可求值 | 依赖 |
|---|---|---|---|---|---|
| 角色启用 | `角色组ID` | 已有的角色组ID | 本局启用了该角色组 | 是 | |
| 角色版本 | `角色组ID`、`版本ID` | 版本须属于该组 | 启用且选定了该版本 | 是 | |
| 事件确认 | `事件ID`，可选 `分支ID` | 已有的事件与其分支 | 有效本局有该事件状态为 1 的记录；附分支ID时分支一致 | 是 | |
| 事件串状态 | `事件串ID`、`状态` | 状态为 `未开始`、`进行中` 或 `已结束` | 事件串处于该状态 | 是 | |
| 当前时间 | `比较`、`值` | 比较为 `小于` 或 `大于等于`；值按纪年书写 | 小于：时间语境的终点不晚于值的起点；大于等于：时间语境的起点不早于值的起点 | 是 | |
| 剧情标记 | `标记ID`、`比较`、`值` | 比较为 `等于` 或 `不等于`；值在该标记的取值中 | 标记的本局值满足比较；标记缺失为未知 | 是 | |
| 角色状态 | `角色组ID`、`字段`、`属于` | 字段为 `所在`，或二层角色字段中有取值表的字段格，映射写到键、子字段写到子键；`属于` 为非空、无重复的取值列表，字段为所在时列地点ID | 该字段的值在 `属于` 中；所在属于所列地点或其下级地点即成立；角色组未启用为不成立 | 是 | 字段为所在时，地点库 |
| 同处 | `角色组ID` | 至少两个、无重复的角色组ID | 所列角色组的所在相同；任一未启用为不成立，任一所在未知为未知 | 是 | 地点库 |
| 角色已出场 | `角色组ID` | 已有的角色组ID | 视为在场、已初始化，或是某个状态为 1 的记录的实际参与者 | 是 | |
| 当前场景 | `地标`、`场景` | 地标为地点ID，场景为文本 | 当前地点的地标与场景都一致；当前地点缺失为未知 | 否 | 地点库 |
| 在场实力人数 | `最低实力`、`最少人数`，可选 `排除角色组` | 最低实力取综合实力维度所用的等级；最少人数为正整数；排除角色组为无重复的角色组ID列表 | 视为在场者中，综合实力不低于最低实力的人数达到最少人数；人数不足而有人没有综合实力的值为未知；当前地点缺失为未知 | 否 | 综合实力维度 |

| 组合词 | 成立 | 不成立 | 未知 |
|---|---|---|---|
| `all` | 全部成立 | 有一项不成立 | 其余情况 |
| `any` | 有一项成立 | 全部不成立 | 其余情况 |
| `none` | 全部不成立 | 有一项成立 | 其余情况 |

封卷之前一律为未知。门槛与生效条件为未知时，按不成立处理。处于偶数层 `none` 之内的事件确认是正向引用，处于奇数层之内的是排斥。

## 变化

每条变化是映射，有 `路径`、`操作`，除移除之外还有 `值`。

| 路径 | 写到 |
|---|---|
| `世界.剧情标记.{标记ID}` | 已声明的剧情标记 |
| `世界.{字段}` | 二层世界字段 |
| `角色.{角色组ID}.{字段}`，按字段的写法向下写到要改的格 | 二层角色字段、能力维度、装备、所在 |

| 目标 | 操作 | 值 |
|---|---|---|
| 剧情标记 | 设定 | 该标记的取值之一 |
| 取值、引用、文本的单值字段，以及所在 | 设定 | 按字段的声明；所在为地点ID |
| 集合，写到集合 | 新增、移除 | 成员 |
| 映射，写到键 | 设定；新增，键不存在时才写入；移除，不带值 | 按值的声明 |
| 数值，以及值为数值的映射的键 | 增加、减少 | 正整数，不超过单次增减上限；本局没有值时从 0 起算，结果截断在值域之内 |
| 等级维度 | 提升、设定、移除 | 见参考“角色” |
| 装备 `装备.{装备ID}` | 新增、设定、移除 | 见参考“角色” |

| 限制 | 写法 |
|---|---|
| 不能写 | `能力移除记录`、`已初始化` |
| 预设事件不能写“玩家” | 路径、映射键与引用角色组的值都不能是“玩家”；门槛也不能引用它 |
| 角色组须保证已启用 | 路径与映射键中的角色组，须是核心参与者，或由事件门槛与本分支的门槛保证已启用 |

## 角色位置

`历史/事件/{事件ID}/角色/{角色组ID}.txt` 的字段，不能有表外的键。

| 字段 | 必填 | 写法 | 层 |
|---|---|---|---|
| `事件ID` | 是 | 等于事件目录名 | 三 |
| `角色组ID` | 是 | 等于文件名，须是已有的角色组 | 三 |
| `角色概要` | 是 | 文本 | 四 |
| `角色定位` | 是 | 非空、无重复的短语列表 | 四 |
| `适用分支` | 否 | 非空、无重复的分支ID列表；省略即适用于全部分支 | 三 |
| `介入条件` | 否 | 文本，条件文本 | 四 |
| `角色知情` | 否 | 非空、无重复的文本列表 | 四 |
| `主观记忆` | 否 | 非空、无重复的文本列表 | 四 |
| `按分支` | 否 | 映射：分支ID → `{角色知情, 主观记忆}`；分支ID须在适用分支之内 | 三、四 |
| `事件触发语料` | 否 | 列表，见“触发语料” | 四 |

| 进入上下文时 | 取用的字段 |
|---|---|
| 已确认经历、待登记，适用于所走的分支 | `角色概要`、`角色定位`、`角色知情`、`主观记忆`，外层与所走分支的“按分支”合并 |
| 候选，适用分支与门槛成立的分支有交集 | `角色定位`、`介入条件`、`事件触发语料` |

## 触发语料

| 子字段 | 必填 | 写法 |
|---|---|---|
| `触发情境` | 是 | 文本，条件文本 |
| `候选台词` | 是 | 非空、无重复的文本列表 |
| `表达目的` | 否 | 文本 |
| `情绪或语气` | 否 | 文本 |
| `触发限制` | 否 | 非空、无重复的文本列表，条件文本 |

## 事件串

`历史/事件串/{事件串ID}.yaml` 的字段，不能有表外的键。

| 字段 | 必填 | 写法 | 层 |
|---|---|---|---|
| `概述` | 是 | 文本；事件串进行中时进入上下文 | 四 |
| `事件` | 是 | 非空、无重复的事件ID列表，顺序不表示先后；每个事件至多属于一个事件串 | 三 |
| `结局` | 是 | 非空的列表，每项为 `{事件ID}` 或 `{事件ID, 分支ID}`，事件须属于本串 | 三 |

| 事件串状态 | 条件 |
|---|---|
| 已结束 | 有结局的记录状态为 1，指定了分支时分支一致；或有状态为 1 的记录声明本串结束 |
| 进行中 | 未结束，且有起点的记录状态为 1 |
| 未开始 | 其余情况 |

起点是事件门槛中没有正向引用本串其它事件的事件，每个事件串至少有一个。

## 开局选项

`历史/开局选项.yaml` 的字段，不能有表外的键。

| 字段 | 必填 | 写法 | 层 |
|---|---|---|---|
| `自由组合` | 否 | 布尔，缺省为否 | 三 |
| `选项` | 是 | 列表，每项只含 `事件ID`、`问题`、`选项` | 三 |

| 选项项的键 | 写法 | 层 |
|---|---|---|
| `事件ID` | 已有的事件，不重复声明，确认策略不是仅作候选 | 三 |
| `问题` | 文本，展示给玩家 | 四 |
| `选项` | 映射：该事件的分支ID或 `未发生` → 展示给玩家的文字 | 键三、值四 |

## 开局方案

`历史/开局方案/{方案ID}.yaml` 的字段，不能有表外的键。

| 字段 | 必填 | 写法 | 层 |
|---|---|---|---|
| `概述` | 是 | 文本，展示给玩家 | 四 |
| `开局时间` | 否 | 按纪年书写 | 三 |
| `角色组` | 否 | 映射：角色组ID → `{启用, 版本ID}`，两项都可选；启用为布尔，版本ID须属于该组 | 三 |
| `历史选择` | 否 | 映射：事件ID → 分支ID或 `未发生`，只能用开局选项中声明的事件与选项；写了开局时间时，所选事件的触发时间最晚的终点不能晚于开局时间的起点 | 三 |
