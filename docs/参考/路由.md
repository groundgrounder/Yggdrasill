# 参考：路由

本文逐项列出上下文的各部分、输出的字段、审计、运行参数与包裹标签。各项的含义见第五章“路由”。

下表只适用于叙事模型的生成前上下文。独立记账请求使用自己的系统提示与用户提示，不运行路由，也不将这份上下文并入记账请求或复用（见第六章）。

## 上下文

| 顺序 | 部分 | 内容 | 预算 |
|---|---|---|---|
| 1 | 协议文本 | 模板生成的变量更新规则、角色通用约束与扮演准则；按记账开关选用对应版本 | 不限 |
| 2 | 世界概况 | `世界概况/` 下各文件的原文，按文件名的码点顺序 | 不限 |
| 3 | 世界当前状态 | 见“输出的字段” | 不限 |
| 4 | 在场角色 | 在场者，按角色组ID的码点顺序，自建的玩家在最后 | 完整人数与字符，超出时逐人降为精简或最小 |
| 5 | 被提及角色 | 已启用而不在场、在提及窗口内被提到的角色组，按首次出现的位置 | 不限 |
| 6 | 条目 | 按条目库声明的顺序分组，组内按选入的顺序 | 每库的字符 |
| 7 | 事件 | 已确认经历、待登记、候选、待初始化 | 经历与候选的条数与字符，待登记与待初始化不限 |

没有内容的部分省略。字符数是该项序列化为 JSON 之后的 Unicode 码点数，一部分的用量是入选各项之和。

## 输出的字段

| 部分 | 每项输出 | 排序 | 超出预算 |
|---|---|---|---|
| 世界当前状态 | 当前时间、当前地点、剧情标记、有值的二层世界字段；进行中的事件串，各附概述与本串状态为 1 的事件，每项写作“事件标题：分支结果”；待定项，原样输出 | 事件串按ID的码点顺序，其中的事件按实际时间 | |
| 在场角色：完整 | 角色组ID、显示名、年龄、当前档案的基本信息与角色印象、当前能力、可用技能、本局状态，扮演角色组另标玩家扮演 | 见“上下文” | 完整名额已满或字符放不下时降级 |
| 在场角色：精简 | 角色组ID、显示名、年龄、玩家扮演、本局状态、当前能力、可用技能；档案只留基本信息的姓名、称号、性别、种族与角色印象的核心身份、表现禁区，空子映射省略 | 见“上下文” | 字符也放不下时降为最小 |
| 在场角色：最小 | 角色组ID、显示名、年龄、玩家扮演、本局状态；省略档案、当前能力与可用技能 | 见“上下文” | 始终保留在场身份 |
| 在场角色：档案冲突或解析异常 | 角色组ID、显示名 | | |
| 在场角色：自建的玩家 | 角色组ID“玩家”、显示名、年龄、开局设定中的玩家档案、当前能力、可用技能、本局状态；精简时档案只留姓名、称号、性别、种族，压缩后为空则省略 | 最后 | |
| 被提及角色 | 角色组ID、显示名、别名 | 首次出现的位置 | |
| 条目 | 条目正文；按种类分的库附所在各级目录的说明文件，库的根说明在前，每份只输出一次；按上下级分的库只附根说明 | 选入的顺序 | 整条略过，接着试下一条 |
| 已确认经历 | 事件ID、事件标题、事件概要、影响范围、实际时间、所走分支的分支结果、公开信息、隐秘信息、在场者的角色位置；四项文本按所走分支覆盖、未声明回退顶层；动态事件只有事件ID、摘要、实际时间 | 放入按优先级，输出按实际时间，同时刻按事件ID的码点顺序 | 先去掉角色位置，仍放不下就整条略过 |
| 待登记 | 与已确认经历的完整形式相同，另标已经发生 | 求解的顺序 | 不限 |
| 候选 | 事件ID、事件标题、事件概要、影响范围、叙事条件、公开信息、触发时间最晚、门槛成立的各分支的分支ID、分支条件与分支结果、在场者的角色位置；只读事件顶层文本，不输出分支专属文本 | 见“候选的排序” | 整条略过 |
| 待初始化 | 角色组ID、档案ID、待初始化预览的能力与装备 | 在场者的顺序 | 不限 |

| 项 | 取法 |
|---|---|
| 年龄 | 当前时间的年份减去出生年，没有出生年或当前时间时省略 |
| 本局状态 | 角色变量中的二层字段与装备 |
| 显示名 | 依次取所选版本的显示名、角色组的显示名与角色组ID，自建的玩家取档案的姓名，没有时为“玩家” |
| 待初始化 | 只列初始化方式为显式确认、有待初始化预览的在场者 |

## 条目的来源

| 顺序 | 来源 | 内容 |
|---|---|---|
| 1 | 本局状态引用 | 在场者的本局状态与集合维度中，按声明引用了条目库的值与映射键，按在场者、字段声明与值的顺序 |
| 2 | 地点链 | 当前地点的地标及其各级上级，从地标往上 |
| 3 | 提及 | 提及窗口内出现条目ID或名称的条目，按首次出现的位置 |

同一条目只选一次，以先选入的来源为准。技能另须是某个在场者的可用技能。

## 经历的理由

候选池是有效本局中状态为 1 的预设事件与动态事件，不含首次登场初始化的记录与待登记事件。

| 优先 | 理由 | 条件 |
|---|---|---|
| 1 | 点名 | 提及窗口内出现事件ID或事件标题 |
| 2 | 候选前置 | 某个已选入的候选，其门槛在成立的路径上正向引用了它 |
| 3 | 当前地点 | 事件的地点与地点链有交集 |
| 4 | 共同经历 | 实际参与者中至少两个是在场者 |
| 5 | 在场者经历 | 实际参与者中至少一个是在场者 |

同一理由之内，点名按首次出现的位置。其余依次按在场的实际参与者人数从多到少、实际时间从近到远、事件ID的码点顺序。

## 候选的排序

候选池是有效状态为候选的预设事件，有核心参与者在场、地点与地点链有交集或没有核心参与者的入选。

| 顺序 | 依据 |
|---|---|
| 1 | 属于进行中事件串的在前 |
| 2 | 地点与地点链有交集的在前 |
| 3 | 在场的核心参与者人数从多到少 |
| 4 | 触发时间最晚从早到晚 |
| 5 | 事件ID的码点顺序 |

## 审计

| 部分 | 选入 | 略过的原因 | 其它 |
|---|---|---|---|
| 经历 | 事件ID、理由、形式（完整或摘要，即去掉了角色位置）、字符 | 无关联、超出条数、超出字符 | 字符用量、预算 |
| 候选 | 事件ID、理由、形式、字符 | 无关联、超出条数、超出字符 | 字符用量、预算 |
| 条目，每库 | 条目ID、理由、字符 | 条目不存在、不可用、正文为空、超出字符 | 字符用量、预算 |
| 在场角色 | 按最终输出顺序逐人记角色组ID、形式（完整、精简、最小、异常）、字符 | | 字符用量、完整人数与字符预算 |
| 提及 | 角色组、条目、事件，各附首次出现的位置，被提及而未启用的角色组 | | |
| 异常 | | | 档案冲突、档案异常、当前地点不在地点库中、事件异常（附事件ID） |

## 运行参数

写在项目根的 `yggdrasill.yaml`，文件中只有 `运行参数` 一个键。不写时取默认值。取值须为非负整数，未知的键报错。

| 键 | 默认值 | 作用 |
|---|---|---|
| `经历.条数` | 6 | 已确认经历的条数上限 |
| `经历.字符` | 3000 | 已确认经历的字符预算 |
| `候选.条数` | 4 | 候选的条数上限 |
| `候选.字符` | 4000 | 候选的字符预算 |
| `在场角色.完整人数` | 6 | 允许使用完整形式的在场者人数上限，玩家优先 |
| `在场角色.字符` | 12000 | 在场角色的字符预算，超出时逐人降为精简或最小 |
| `条目字符.默认` | 1500 | 每个条目库的字符预算 |
| `条目字符.{库名}` | 同默认 | 某个库的字符预算，库名须是已声明的条目库 |
| `提及窗口` | 2 | 查找提及的最近消息条数 |
