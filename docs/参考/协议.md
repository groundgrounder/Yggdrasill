# 参考：协议

本文逐项列出本局变量、事件有效状态、命令、封卷、排斥检查与抽样。各项的含义见第四章“协议”。

## 本局骨架

一层骨架所有卡相同。“写入”一栏写由什么写入。读取时计算的状态不存入本局。

| 路径 | 写法 | 写入 |
|---|---|---|
| `世界.当前时间` | 按纪年书写，只能推进 | 封卷、写场景 |
| `世界.当前地点` | `{地标: 地点ID, 场景: 文本}` | 写场景 |
| `世界.剧情标记.{标记ID}` | 该标记的取值之一 | 封卷写入开局值，事件的变化 |
| `世界.{二层世界字段}` | 按声明 | 事件的变化 |
| `开局.世界线` | 世界线ID，仅多世界线世界书写入 | 封卷 |
| `开局.开局时间` | 按纪年书写 | 封卷 |
| `开局.已封卷` | 布尔 | 封卷 |
| `开局.历史选择` | 映射：事件ID → 分支ID或 `未发生` | 封卷 |
| `开局.方案` | 方案ID，可选 | 封卷 |
| `开局.角色组.{角色组ID}` | `{启用: 布尔, 版本ID}`，含全部角色组 | 封卷 |
| `开局.玩家` | 自建：`{模式: 自建, 档案, 初始能力?, 初始装备?}`；扮演：`{模式: 扮演, 扮演角色组}` | 封卷 |
| `角色.{角色组ID}.在场` | 布尔 | 写场景 |
| `角色.{角色组ID}.所在` | 地点ID | 写场景、事件的变化 |
| `角色.{角色组ID}.{能力维度}` | 见参考“角色” | 事件的变化、初始化 |
| `角色.{角色组ID}.装备.{装备ID}` | `{状态, 位置}` | 事件的变化、初始化 |
| `角色.{角色组ID}.能力移除记录` | 相对字段路径的列表 | 协议 |
| `角色.{角色组ID}.已初始化` | 布尔 | 协议 |
| `角色.{角色组ID}.{二层角色字段}` | 按声明 | 事件的变化 |
| `事件.{事件ID}` | 事件记录，见下表 | 封卷、命令 |
| `待定项` | 待定项的列表，见下表 | 命令“待定项” |

自建的玩家，角色变量记在 `角色.玩家`。角色变量在首次写入时创建。

| 事件记录的键 | 写法 |
|---|---|
| `状态` | 1 为确认，2 为排除。没有记录即未确认也未排除 |
| `分支` | 分支ID，动态事件为 `完成`，首次登场初始化为 `初始化` |
| `实际时间` | 按纪年书写 |
| `实际参与者` | 角色组ID列表 |
| `摘要` | 文本，动态事件必填 |
| `结束事件串` | 事件串ID，动态事件可选 |

封卷写下的排除记录只有 `状态` 一项。

| 待定项的键 | 写法 |
|---|---|
| `字段路径` | 按变化的路径写法，写到已声明的字段格，不能是在场或所在 |
| `候选值` | 非空列表 |
| `事件ID` | 本局中状态为 1 的事件 |
| `说明` | 文本 |

## 二层字段

`设定/本局变量.yaml` 的键都属第二层。

| 键 | 必填 | 写法 |
|---|---|---|
| `词表` | 是 | 映射：词表名 → 非空、无重复的取值列表，第一个值是默认值，须有 `装备状态` |
| `角色` | 是 | 映射：字段名 → 字段声明，见参考“世界书”，不能与一层骨架的角色字段或能力维度重名 |
| `世界` | 否 | 映射：字段名 → 字段声明，不能与一层骨架的世界字段重名 |
| `单次增减上限` | 否 | 正整数，缺省 100 |

默认声明 `defaults/设定/本局变量.yaml` 的内容：

| 项 | 声明 |
|---|---|
| `词表.关系阶段` | `[陌生, 相识, 友好, 信任, 疏远]` |
| `词表.装备状态` | `[完好, 破损, 报废]` |
| `角色.关系` | 映射：角色组 → `词表.关系阶段` |
| `角色.好感度` | 映射：角色组 → 数值 `[-100, 100]` |
| `角色.身份` | 文本的集合 |
| `角色.职位` | 映射：势力 → 文本，须有势力库 |
| `角色.知识` | 文本的集合 |

## 事件有效状态

按顺序取第一个符合的。候选与不适用的门槛在有效本局上求值，时间语境为当前时间。

| 顺序 | 状态 | 条件 |
|---|---|---|
| 1 | 已确认 | 本局有该事件状态为 1 的记录 |
| 2 | 已排除 | 本局有该事件状态为 2 的记录 |
| 3 | 待登记 | 在待登记列表中 |
| 4 | 未到 | 未封卷，或当前时间缺失 |
| 5 | 已排除 | 有核心参与者未启用 |
| 6 | 未到 | 当前时间的终点不晚于触发时间最早的起点 |
| 7 | 已排除 | 当前时间的起点不早于触发时间最晚的终点 |
| 8 | 候选 | 事件门槛成立，且至少一个分支的门槛成立 |
| 9 | 不适用 | 其余情况 |

## 命令

| 命令 | 参数 | 必填 | 前置 | 结果为未写入 |
|---|---|---|---|---|
| 确认事件 | `事件ID`、`分支ID`，可选 `实际参与者` | 前两项 | 已封卷，事件为预设事件，分支属于它，待登记时分支须一致，否则须为候选、所选分支的门槛成立，实际参与者都已启用 | 本局已有该事件的记录 |
| 动态事件 | `事件ID`、`摘要`、`变化`，可选 `实际参与者`、`结束事件串` | 前三项 | 已封卷，事件ID合法、不与预设事件重复、不以 `初次登场·` 开头，变化为列表，可以为空，结束事件串存在且进行中 | 本局已有该事件的记录 |
| 确认初始化 | `角色组ID` | 是 | 已封卷，角色组已启用、当前档案成立 | 已初始化 |
| 写场景 | `当前时间`、`当前地点`、`在场`、`所在` | 都可选 | 已封卷，见下表 | |
| 待定项 | `操作`、`字段路径`，新增另需 `候选值`、`事件ID`、`说明` | 见左 | 已封卷，操作为 `新增` 或 `移除`，字段路径同变化的规则 | |

| 写场景的参数 | 写法 | 规则 |
|---|---|---|
| `当前时间` | 按纪年书写 | 起点不早于原值的起点，写入后登记新到期的待登记事件 |
| `当前地点` | `{地标: 地点ID, 场景: 文本}` | |
| `在场` | 映射：角色组ID → 布尔 | 角色组已启用，扮演角色组与“玩家”不能写，从未出场的写为真时，显式确认的报错，出场自动的在本次初始化，由真变假而没有写所在时，存为写入之前的地标 |
| `所在` | 映射：角色组ID → 地点ID | 角色组已启用，写入之后视为在场的不能写 |

| 命令的外壳 | 写法 |
|---|---|
| 一轮的命令 | 列表，按顺序逐条执行，每条是独立的一次写入 |
| 每条命令 | 单键映射：命令名 → 参数映射，不能有表外的命令名与参数 |
| 默认记账 | 正文不写命令；记账 JSON 经适配层转换后得到同样的命令列表 |
| 关闭记账 | 回复末尾的 `<命令>` 标签，内为 YAML 列表 |
| 一轮的结果 | 最后的本局。各条已写入的内容按执行顺序合成的列表。失败的列表，每项记序号、命令名、错误码与说明 |

## 封卷

| 输入 | 写法 | 缺省 |
|---|---|---|
| `世界线` | 世界线ID（仅多世界线世界书允许，与方案冲突时报错） | 继承方案，或取默认世界线/码点第一条 |
| `开局时间` | 按纪年书写 | 取方案的，没有方案时必填 |
| `方案` | 方案ID | |
| `角色组` | 映射：角色组ID → `{启用, 版本ID}`，按世界线 < 方案 < 输入逐键合并 | 默认启用与默认版本 |
| `玩家` | `{模式: 自建, 档案, 初始能力?, 初始装备?}` 或 `{模式: 扮演, 扮演角色组}`，扮演角色组须已启用；自建带初始能力或初始装备时落盘 `角色.玩家` 并置 `已初始化: true` | 自建、档案为空 |
| `历史选择` | 映射：开局前事件 → 分支ID或 `未发生`，与方案按事件ID合并 | |

| 失败 | 错误码 |
|---|---|
| 参数不合法、方案不存在、缺少开局时间，或玩家档案含不可序列化的值 | `封卷.参数` |
| 历史选择的事件不是开局前事件，或值不合法，指定的分支未能写入 | `封卷.历史选择` |
| 历史求解中出现倒流 | `封卷.时间顺序冲突` |
| 排斥检查不通过 | `封卷.配置冲突` |

## 排斥检查

| 项 | 内容 |
|---|---|
| 时机 | 每次提交之前、封卷的最后一步 |
| 对象 | 写入之前有效本局中已确认的预设事件，以及随本次写入登记的待登记事件，封卷时为写入的全部预设事件 |
| 求值 | 以写入之后的记录重新求值对象的事件门槛与所走分支的门槛。事件确认按记录求值，计入极性。其余条件记为未知 |
| 失败 | 结果为不成立。写入时报 `协议.排斥冲突`，封卷时报 `封卷.配置冲突` |

## 抽样

静态检查没有错误时才抽样，否则提示 `抽样.未执行`。

| 项 | 内容 |
|---|---|
| 抽样年份 | 各事件触发时间最早与最晚所在的年份，各取该年与下一年，另加其中最早年份的前一年，不小于 0，去重后升序 |

| 抽样 | 样本 | 开局时间 | 失败 |
|---|---|---|---|
| 档案互斥 | 每个角色组的每个版本（多世界线世界书按每条世界线分桶）：生效条件所引事件的全部状态组合，即无记录、状态 2、各分支的状态 1，在只含这些记录的封卷后本局上解析，不封卷、不登记待登记事件 | 各抽样年份 | 冲突报 `抽样.档案冲突`，组合超过 4096 种时提示 `抽样.组合过多` 并跳过该版本 |
| 运行抽样 | 默认开局，全部角色组启用、各取第 i 个版本，i 从 1 到各角色组版本数的最大值，版本不足的取默认版本（多世界线世界书覆盖每条世界线） | 各抽样年份 | 封卷失败报 `抽样.封卷失败`，启用的角色组档案冲突报 `抽样.档案冲突`，解析异常提示 `抽样.档案异常` |
| 开局方案 | 每个方案 | 方案所写的，没有写时，所选事件中触发时间最晚的年份的下一年，没有所选事件时，最后一个抽样年份 | `开局.方案封卷失败` |
| 开局选项 | 每个选项的每个分支，包括 `未发生`，以默认开局加这一项历史选择（多世界线世界书逐条世界线尝试，全部不可选才提示） | 该事件触发时间最晚的年份的下一年 | 历史选择错误提示 `开局.选项不可选`，其它失败报 `开局.选项封卷失败` |

## 世界书事件数据非法

预设事件的触发时间不合法时，读写报 `协议.参数`；分支变化不合法时，报 `协议.变化`。说明带事件ID，不伪装成 `封卷.*`。封卷与有效本局的求解遇到这类事件时立即失败，不跳过自动确认事件。路由的候选枚举只逐条隔离 `ProtocolError`，在审计的异常中记 `事件异常` 与事件ID，其它事件照常处理。

## 输入限制

| 对象 | 限制 | 违反时 |
|---|---|---|
| 本局变量 | 由映射、列表、文本、布尔、有限的数与空值组成，无环，已封卷的本局只有一层骨架与已声明的二层字段 | `协议.参数` |
| 本局的映射键 | 不能是 `__proto__`、`constructor`、`prototype` | `协议.参数` |
| 本局中能力的值 | 在维度所用的等级或成员范围之内 | `协议.能力取值` |
| 写入 | 须已封卷 | `协议.未封卷` |
