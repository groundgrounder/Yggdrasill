# 参考：角色

本文逐项列出能力、角色组与档案的声明和字段。各项的含义见第二章“角色”。

## 能力维度

`设定/能力.yaml` 有 `维度` 与 `技能可用` 两个键，都必填。`维度` 是维度名 → 维度声明的映射。维度名不能与一层骨架的角色字段（在场、所在、装备、能力移除记录、已初始化）或二层角色字段重名。

| 类型 | 声明的键 | 本局路径 | 比较 | 变化操作 |
|---|---|---|---|---|
| 等级映射 | `类型`、`等级`、`键`，都必填 | `角色.{角色组ID}.{维度}.{键}` | 按等级序列中的位置 | 提升、设定、移除 |
| 单值等级 | `类型`、`等级` 必填，`综合实力` 可选 | `角色.{角色组ID}.{维度}` | 按等级序列中的位置 | 提升、设定、移除 |
| 集合 | `类型`、`成员`，都必填 | `角色.{角色组ID}.{维度}` | 是否包含 | 新增、移除 |

| 键 | 写法 |
|---|---|
| `等级` | 等级序列名，见参考“世界书” |
| `键` | 非空、无重复的列表，或键组名 → 键列表的映射，键在组间不重复 |
| `综合实力` | 布尔，至多一个单值等级维度写 `true` |
| `成员` | `文本`，或 `{条目库: 库名, 条件: {字段: 值, …}}`，条件可选、非空，字段须是该库已声明的字段 |

## 技能可用

`技能可用` 是规则的列表。声明了规则时须有技能库。技能库中的每个技能恰好适用一条规则。

| 规则 | 键 | 写法 |
|---|---|---|
| 等级门槛 | `适用` | 非空映射：技能字段 → 值，选出本规则管辖的技能 |
| | `规则` | `等级门槛` |
| | `维度` | 等级映射维度 |
| | `键字段` | 技能字段，值须是该维度的键 |
| | `等级字段` | 技能字段，值须在该维度所用的等级序列中 |
| | `键组` | 可选，该维度的键组名，键字段的值须在这一组 |
| 集合持有 | `适用` | 同上 |
| | `规则` | `集合持有` |
| | `维度` | 集合维度，技能ID在其中即可用 |

规则引用的技能字段，即适用条件中的字段、键字段与等级字段，是技能库的必需字段。

## 变化操作

| 目标 | 操作 | 值 | 写入 |
|---|---|---|---|
| 等级维度 | 提升 | 等级 | 本局没有值或新值更高时写入，否则不变，清除该字段的能力移除记录 |
| | 设定 | 等级 | 直接写入，可以降级，清除该字段的能力移除记录 |
| | 移除 | 不带值 | 删去该键或字段，记入能力移除记录 |
| 集合维度 | 新增、移除 | 成员 | 逐项加入或删去，不产生重复，移除不存在的成员不报错 |
| 装备 `装备.{装备ID}` | 新增 | `{状态, 位置}` | 本局未持有时加入，已持有时保留原有的状态与位置 |
| | 设定 | `{状态, 位置}` | 直接写入 |
| | 移除 | 不带值 | 删去 |

装备的状态取 `词表.装备状态`，位置为文本。能力移除记录由协议维护，记相对字段路径，例如 `武艺.剑术`、`勇力`。

## 角色组

`角色/{角色组ID}/角色组.yaml` 的字段，按下表的顺序书写，可选字段没有内容时整键省略。

| 字段 | 必填 | 写法 | 层 |
|---|---|---|---|
| `显示名` | 否 | 文本，省略时等于角色组ID | 四 |
| `别名` | 否 | 非空、无重复的文本列表 | 三 |
| `角色包` | 是 | `设定/角色分类.yaml` 的角色包之一 | 三 |
| `分类` | 是 | `设定/角色分类.yaml` 的分类之一 | 三 |
| `默认启用` | 是 | 布尔 | 三 |
| `默认版本` | 写了版本时必填 | 版本ID，没有写版本时省略 | 三 |
| `初始化方式` | 否 | `显式确认` 或 `出场自动`，缺省为显式确认 | 三 |
| `初始所在` | 否 | 地点ID | 三 |
| `版本` | 否 | 非空的版本列表，版本ID不重复，省略时视为只有一个版本，版本ID等于角色组ID | 三 |
| `档案` | 是 | 非空的档案项列表，与 `档案/` 下的子目录一一对应 | 三 |

别名在本组之内，包括各版本的别名，不得重复。与其它角色组的别名相同时提示。

## 版本

| 字段 | 必填 | 写法 | 层 |
|---|---|---|---|
| `版本ID` | 是 | 文本 | 三 |
| `显示名` | 否 | 文本 | 四 |
| `别名` | 否 | 文本列表，只在本局选定该版本时生效 | 三 |
| `简介` | 否 | 文本，开局选择版本时展示给玩家 | 四 |

## 档案项

| 字段 | 必填 | 写法 |
|---|---|---|
| `档案ID` | 是 | 等于 `档案/` 下的目录名，不重复 |
| `适用版本` | 写了版本时必填 | 非空、无重复的版本ID列表，没有写版本时省略 |
| `默认` | 否 | 布尔，每个版本至多一份默认档案 |
| `前置档案` | 否 | 档案ID，与本档案的适用版本有交集，前置链不成环 |
| `生效条件` | 非默认档案必填 | 条件，见参考“事件”，须含正向引用的事件确认或正向引用的世界线条件，不得含封卷不可求值的条件，默认档案不写 |
| `初始能力` | 否 | 非空映射：维度名 → 初始值。等级映射写 `{键: 等级}`，单值等级写等级，集合写无重复的成员列表 |
| `初始装备` | 否 | 非空列表，每项只含 `装备ID`、`状态`、`位置`，装备ID在装备库中且不重复，状态取 `词表.装备状态`，位置为文本 |

每个版本至少有一份适用的档案。档案项的字段都属第三层。

## 基本信息

`角色/{角色组ID}/档案/{档案ID}/基本信息.txt` 的字段表属第四层，所有卡相同。第五层只能在 `设定/文本规范.yaml` 的“档案追加字段”中追加可选字段。

| 字段 | 必填 | 写法 | 层 |
|---|---|---|---|
| `姓名` | 是 | 文本 | 四 |
| `称号` | 否 | 短语列表 | 四 |
| `性别` | 是 | 文本 | 四 |
| `出生年` | 否 | 取值：纪年 | 三 |
| `种族` | 是 | 文本 | 四 |
| `出身` | 是 | 文本 | 四 |
| `稳定体貌` | 是 | 子字段，至少写一个 | 四 |
| `穿着习惯` | 否 | 文本列表 | 四 |
| `能力特征` | 是 | 子字段，两个子字段都须写 | 一、三、四 |

| 字段 | 子字段 | 必填 | 写法 |
|---|---|---|---|
| `稳定体貌` | `发色发型` | 否 | 文本 |
| | `瞳色` | 否 | 文本 |
| | `体型` | 否 | 文本 |
| | `特征` | 否 | 短语列表 |
| `能力特征` | `特征` | 是 | 文本列表，可以为空列表 |
| | `技能补充` | 是 | 列表，可以为空，每项写 `技能ID`，以及 `个体表现`、`个体限制` 中至少一项，二者都是非空的文本列表，技能ID须在技能库中，不重复 |

档案不写年龄，文本中出现“N岁”时提示。档案中不写档案ID，也不能有字段表与追加字段之外的键。

## 角色印象

`角色/{角色组ID}/档案/{档案ID}/角色印象.txt` 的字段都属第四层。建议条数超出范围时只提示。

| 字段 | 必填 | 写法 | 建议条数 |
|---|---|---|---|
| `核心身份` | 是 | 短语列表 | 1–3 |
| `行为准则` | 是 | 文本列表 | 2–4 |
| `价值优先` | 是 | 短语列表，从高到低 | 2–4 |
| `表达规律` | 是 | 子字段，至少写一个 | |
| `通用反应` | 是 | 情境列表 | 2–5 |
| `关系表现` | 否 | 情境列表，针对具名角色时，键写第二层的关系阶段与场合 | 1–5 |
| `表现禁区` | 是 | 禁区列表 | 1–4 |

| `表达规律` 的子字段 | 写法 |
|---|---|
| `自称与称呼` | 文本 |
| `句式` | 文本列表 |
| `语气变化` | 情境列表 |
| `场合差异` | 情境列表 |
| `内外差` | 文本列表 |
| `口头特征` | 短语列表，每项不超过 8 字 |

## 自建玩家

自建模式下，玩家的身份写在本局的 `开局.玩家.档案`，字段取基本信息的子集，各项都可省略，写法同上表；另可在 `开局.玩家` 中可选填写 `初始能力` 与 `初始装备`（写法与合法性规则同档案项，封卷时直接写入 `角色.玩家` 并将 `已初始化` 记为真；未填写时不创建 `角色.玩家`）。

| 字段 |
|---|
| `姓名`、`称号`、`性别`、`出生年`、`种族`、`出身`、`稳定体貌`、`穿着习惯` |
