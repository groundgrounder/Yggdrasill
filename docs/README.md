# 世界树文档

本目录是世界树唯一的规范。第零章概述世界树。第一至第五章讲机制与原理，第六章讲酒馆适配。参考逐项列出字段与取值。写作规范规定作者怎样书写。术语是各部分共用的附录。

| 文件 | 内容 | 读者 |
|---|---|---|
| [00-概述](00-概述.md) | 世界树要解决的问题、做法与现状 | 所有人 |
| [01-世界书](01-世界书.md) | 运行、层、声明与目录 | 想理解或参与开发世界树的人 |
| [02-角色](02-角色.md) | 角色组、版本、能力、档案、初始化与玩家 | 同上 |
| [03-事件](03-事件.md) | 时间、门槛、分支、变化、确认、事件树、事件串、if 线与开局 | 同上 |
| [04-协议](04-协议.md) | 本局、求值、求解、封卷、写入、命令、排斥与抽样 | 同上 |
| [05-路由](05-路由.md) | 上下文、在场者、提及、条目、经历、候选、渲染与审计 | 同上 |
| [06-酒馆适配](06-酒馆适配.md) | 模型分工、一轮时序、打包、开局、楼层记录、回档与升级 | 实现与审阅适配的人 |
| [写作规范](写作规范.md) | 作者怎样书写世界书 | 写卡作者 |
| [作者指南](作者指南.md) | 从项目结构、五层、分层建卡 skill 到检查与审阅的写卡路径 | 写卡作者 |
| [术语](术语.md) | 各部分所用的术语与统一用语 | 所有人 |
| [作者视图](../view/README.md) | `ygg view` 的启动、视图、编辑与备份边界 | 写卡作者、审阅者 |

## 推荐阅读路径

- 写卡作者：从[作者指南](作者指南.md)与[写作规范](写作规范.md)开始，[第一章](01-世界书.md)与各参考表按需查阅；配合 `skills/` 的分层建卡 skill 与[`工具与检查`](../skills/shared/工具与检查.md)使用。
- 想理解原理或参与开发：依序读[第零章](00-概述.md)至第五章；涉及在酒馆中运行再看[第六章](06-酒馆适配.md)；术语与统一用语随时查[术语](术语.md)。
