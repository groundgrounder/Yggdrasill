## 项目根目录

```
项目/
├── 世界书/          本规范所定的世界书
├── 作者资料/        不进入模型上下文，不参与运行
├── 来源/            可选：原作章节等来源资料；位置也可在项目配置中声明
└── yggdrasill.yaml  可选：运行参数（spec/14）与工具配置（来源格式等）
```

## 作者资料

作者资料不进入上下文，不参与运行。世界树只规定工具要读写的部分，其余资料，例如核定日志、创作规划、交接说明，格式与位置由项目自定，不抄写声明与规范的条文。

角色卡除世界书与世界树的程序外，还需要卡名、头像与开场白等卡面内容；它们的位置与写法由适配层规定（spec/14），不在本节的项目布局之内。

```
作者资料/
├── 出处/      原台词出处记录
├── 暂存/      已写好、等条件满足后接回世界书的内容
├── 候选/      尚未定下的成长、效果、日期等
├── 生成/      工具输出：作者事件树、审阅器状态与备份；不手改
└── 归档/      撤下的内容，保留其在世界书中的相对布局
```

### 出处

`作者资料/出处/` 下是结构化记录（YAML，文件划分由项目自定），分两种：事件级记录写事件的出处；台词记录写每句收入角色位置的原台词的出处。

```yaml
- 事件ID: 拜师                  # 事件级记录：没有角色组ID与台词
  来源: 第一章
- 事件ID: 学修船
  来源: 作者改编
- 事件ID: 拜师                  # 台词记录
  角色组ID: 秦守
  台词: 灯不等人，明早天亮前上来。
  来源: 第一章 第42行
```

以上取自示例“雾港”，假设它改编自一部原作；示例本身的记录都写“作者原创”。

作者工具据此检查：每句原台词都有出处；台词在来源中逐字存在；说话人与所在角色位置一致。

### 暂存

暂存可以存放任何尚未接入的内容：档案、事件、条目。内容按其在世界书中的相对布局放在 `作者资料/暂存/` 下，并在 `作者资料/暂存/暂存清单.yaml` 逐项登记：

| 字段 | 写法 |
|---|---|
| 类型 | 档案 / 事件 / 条目 |
| ID | 暂存内容的 ID |
| 接回位置 | 接回后在世界书中的路径 |
| 接回结构 | 接回时要写入的结构，例如档案在 `角色组.yaml` 中的适用版本、前置档案、生效条件、初始能力 |
| 接回条件 | 文本，说明要先满足什么（例如“切换事件建成后”） |

接回后删除清单中的对应项。

### 候选

尚未定下的内容写在 `作者资料/候选/`，格式由项目自定。定下来以后写入世界书，并从候选中删除。

## 创作规划

规划由项目自己组织，世界树不规定模块数量与结构。规划只写设计理由、创作意图、进度与待办；不抄写二层、五层的声明，也不重述本规范的条文，需要时引用。
