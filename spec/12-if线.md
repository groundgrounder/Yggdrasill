# if 线

> 状态：2026-10-20 已确认。

世界树的主要目的是实现 if 线：开局时或游玩中，某件事没有发生、走了另一个分支、某个角色没有启用，后面的世界随之调整。if 线不是另一类事件，也不另建一棵树，只是事件树（spec/07）中的另一条路径。

## 写法原则

- **门槛只写真正的因果。** 门槛写“没有它，这件事就不会发生”，不写“原著里它排在前面”。按原著先后把事件串成一条链，任何一处偏离都会让下游整串消失。
- **核心参与者只列缺了就不成立的人。** 世界事件通常没有核心参与者。
- **世界事件与个人后果分开写。** 世界事件到时间就发生，只写世界层面的变化；每个人受到的后果各写一个事件，门槛是世界事件已确认，分支门槛读当时的状态（所在、关系、能力等）。
- **关键事件写出多个分支。** 例如“洛琪希到任”加一个“没有请家庭教师”的分支，后面的事件按实际所走的分支设门槛。
- 检查器在主类型为“世界”的事件引用个人或关系事件时提示。

## 示例：菲托亚领转移

```yaml
# 世界事件：到时间自动发生，没有前置
事件ID: 菲托亚领转移
触发时间: {最早: 甲龙历0417年05月16日, 最晚: 甲龙历0417年05月16日}
确认策略: 自动确认
核心参与者: []
默认分支: 发生
分支:
  - 分支ID: 发生
    变化:
      - {路径: 世界.剧情标记.菲托亚领状态, 操作: 设定, 值: 已毁}
```

以下示例只节选与 if 线相关的字段，省略了事件概要、分类、触发时间等必填字段。

```yaml
# 个人后果：落到哪里取决于当时和谁同处
事件ID: 鲁迪乌斯被转移
确认策略: 自动确认
核心参与者: [鲁迪乌斯·格雷拉特]
门槛:
  事件确认: {事件ID: 菲托亚领转移}
默认分支: 独自落地
分支:
  - 分支ID: 与艾莉丝落到魔大陆
    门槛:
      同处: {角色组ID: [鲁迪乌斯·格雷拉特, 艾莉丝·伯雷亚斯·格雷拉特]}
    变化:
      - {路径: 角色.鲁迪乌斯·格雷拉特.所在, 操作: 设定, 值: 魔大陆}
  - 分支ID: 与希露菲落到王宫
    门槛:
      同处: {角色组ID: [鲁迪乌斯·格雷拉特, 希露菲叶特]}
    变化:
      - {路径: 角色.鲁迪乌斯·格雷拉特.所在, 操作: 设定, 值: 王都亚尔斯}
  - 分支ID: 独自落地        # 兜底分支，不带门槛
    变化: [...]
```

- 原著：鲁迪赴任罗亚，与艾莉丝同处，落到魔大陆。
- if 线：鲁迪没有赴任，留在布耶纳村与希露菲同处，一同落到王宫。
- “洛琪希到任”没有发生时，转移照样发生，只是各人的后果不同。

各人的后果事件与转移本身可以合成一个事件串，转移为起点。

## 支撑机制

| 机制 | 位置 |
|---|---|
| 角色的“所在”与初始所在 | spec/09、spec/04 |
| 场景状态由叙事模型直接写 | spec/09 |
| 条件“同处”，以及“角色状态”比较所在 | spec/06 |
| 分支门槛与自动确认事件的兜底分支 | spec/06 |

## “如果”视图（作者工具）

作者选一个开局方案，或临时排除某个事件、改某个分支、关闭某个角色。工具以时间轴末尾为开局时间做两次封卷，一次用作者的选择，一次用默认分支，对比列出：

| 列出 | 含义 |
|---|---|
| 没发生的事件 | 默认路径里发生、这条路径里没发生；即 if 线缺口，由作者判断是否补写 |
| 新发生的事件 | 默认路径里没发生、这条路径里发生 |
| 分支不同的事件 | 例如鲁迪的落地从魔大陆变成王宫 |
| 停住的事件串 | 已开始却没有任何结局可达 |

另附“影响面”报告：对每个事件，假设只有它没发生，统计下游随之不发生的事件数，用来发现写得过死的门槛。

## 开局选项与开局方案

多数 if 线的分岔发生在开局之前。开局时由作者预设或玩家选择开局前历史中的关键分支。

### 开局选项

`历史/开局选项.yaml` 声明哪些事件可以在开局时选择：

```yaml
自由组合: false          # 缺省为否
选项:
  - 事件ID: 洛琪希到任
    问题: 格雷拉特家是否为鲁迪请了家庭教师？
    选项:
      到任: 请了，洛琪希前来任教
      未请教师: 没有请，鲁迪继续自学
  - 事件ID: 强制赴任罗亚与童年分离
    问题: 鲁迪是否被送往罗亚？
    选项:
      发生: 被送往罗亚，担任艾莉丝的家庭教师
      留在村里: 留在布耶纳村，和希露菲一起长大
```

- 选项的键是该事件的分支ID，或“未发生”；值是给玩家看的文字（第四层）。
- 只有触发时间最晚早于开局时间的事件可以选。
- 按触发时间顺序排列。前面的选择使后面某事件的门槛不成立时，该项不出现；分支门槛不成立的分支不能选。前端每选一项用协议预演封卷。
- 没有选的事件按默认规则补出。
- 自由组合为否：玩家只在默认历史与开局方案之间选，开局选项只供方案引用。为是：玩家还可以在方案基础上逐项改。

### 开局方案

每个方案一个文件：`历史/开局方案/{方案ID}.yaml`。

```yaml
概述: 鲁迪没有被送往罗亚，和希露菲在布耶纳村一起长大。
开局时间: 甲龙历0418年      # 可选
角色组: {}                   # 可选，写法与开局选择相同
历史选择:
  强制赴任罗亚与童年分离: 留在村里
```

- 历史选择只能用开局选项中声明的事件与选项。
- 概述随方案展示给玩家（第四层）。

### 封卷（第一层）

- 封卷接受历史选择：指定了分支的事件按该分支确认；指定“未发生”的事件记为排除；其余事件按默认规则。
- 指定的分支其事件门槛或分支门槛不成立时，报配置错误，不退回默认分支。
- 历史选择写入 `开局.历史选择`，所用方案写入 `开局.方案`。
- 检查器对每个开局方案各封卷一次，须通过；运行抽样另对开局选项的各个分支抽样封卷。
