# 条目库

> 状态：2026-10-20 已确认。

条目库的总体框架见 spec/01：由二层声明、平铺在根下、文件名等于 ID；技能、装备、地点三库的必需字段由一层规定（spec/01、spec/03）。本文规定二层 `设定/条目库.yaml` 的写法。

## 库的声明

`条目库.yaml` 的每个顶层键是一个库名，等于根下的目录名。下表的键都属第二层。

| 键 | 必填 | 写法 |
|---|---|---|
| 分法 | 是 | 按种类 / 按上下级；地点库固定为按上下级 |
| 分级 | 按种类时必填 | 字段名列表，依次对应各级子目录，例如技能 `[类别, 体系]` 表示 `技能/{类别}/{体系}/{技能ID}.txt` |
| 上级类型 | 否 | 按上下级时，每种类型允许的上级类型；空列表表示只能在顶层 |
| 字段 | 是 | 字段声明，见下 |

- **条目正文**是一个统称：条目的全部字段剥离机器字段之后的内容，对所有库相同；不是一个叫“正文”的字段。上下文展开条目时输出条目正文。
- ID 字段名为 `{库名}ID`，必填，等于文件名。
- “名称”可选，省略时等于 ID；所有库都用“名称”这个字段名，不写“装备名称”“道具名称”。ID 与名称不在“字段”里声明。
- 其余字段都必须声明；条目中出现未声明的键时报错。
- 按种类分的库，条目所在的各级目录名必须等于“分级”所列字段的值。
- 按上下级分的库，目录即实例，上级由目录推出；声明了上级类型时，检查器校验类型搭配。

## 字段声明（第一层写法）

每个字段声明可以写“必填”，并且恰好写以下一种：

| 写法 | 含义 | 层 |
|---|---|---|
| `形态: …` | 文本，形态见 spec/05（文本、文本列表、短语列表、情境列表、禁区列表） | 四 |
| `取值: …` | 取值域：行内列表、`等级.{名字}`、`能力.{维度}`（维度的键）、`纪年`、`词表.{名字}` | 三 |
| `引用: …` | 值是某个库的 ID，或 `角色组`、`事件`；必须能解析 | 三 |
| `子字段: {…}` | 由固定子键组成的结构，每个子键按同样写法声明 | 按子字段 |
| `映射: {键: …, 值: …}` | 键任意、结构相同的字典；键与值各按上述写法声明 | 按键与值 |
| `数值: [下限, 上限]` | 整数，结果按范围截断；只用于本局变量 | 三 |
| `集合: {…}` | 无序、不重复的成员，成员按上述写法声明；只能逐项新增或移除；只用于本局变量 | 按成员 |

- 取值、引用可加 `列表: true`，表示值是一组。
- 可加 `适用类型: [...]`，表示只有这些类型的条目可以有这个字段（例如“领主家”只用于领地）。
- 用到“上级类型”或“适用类型”的库，必须声明一个名为“类型”、以行内列表为取值的字段；上级类型的键与值、适用类型的值都取自这个列表。
- `词表.{名字}` 引用 `设定/本局变量.yaml` 中命名声明的取值表，见 spec/09。

## 示例

以无职转生为例：

```yaml
技能:
  分法: 按种类
  分级: [类别, 体系]
  字段:
    来源: {必填: true, 取值: [一般, 固有]}
    类别: {必填: true, 取值: [普通魔术, 功能魔术, 剑术, 斗气, 权能, 特质, 魔眼, 技艺]}
    体系: {必填: true, 取值: 能力.修习阶段}
    用途: {取值: [攻击, 防御, 控制, 治疗, 强化, 移动, 感知, 知识, 分析, 功能]}
    技能等级: {必填: true, 取值: 等级.七档}
    效果: {必填: true, 形态: 文本}
    边界: {形态: 文本列表}

装备:
  分法: 按种类
  分级: [标签]
  字段:
    标签: {必填: true, 取值: [剑, 刀, 枪, 斧, 锤, 弓, 弩, 杖, 盾, 魔道具]}
    装备等级: {必填: true, 取值: 等级.七档}
    简介: {必填: true, 形态: 文本}
    效果: {必填: true, 形态: 文本列表}
    边界: {形态: 文本列表}

地点:
  分法: 按上下级
  上级类型:
    大陆: []
    地区: [大陆, 地区]
    国家: [大陆, 地区]
    领地: [大陆, 地区, 国家]
    城市: [大陆, 地区, 国家, 领地]
    村落: [大陆, 地区, 国家, 领地]
    地标: [大陆, 地区, 国家, 领地, 城市, 村落]
  字段:
    类型: {必填: true, 取值: [大陆, 地区, 国家, 领地, 城市, 村落, 地标]}
    地理概况: {必填: true, 形态: 文本}
    领主家: {引用: 势力, 适用类型: [领地]}
    主要地点: {引用: 地点, 列表: true}

势力:
  分法: 按种类
  分级: [类型]
  字段:
    类型: {必填: true, 取值: [政治实体, 政治派系, 广域势力, 武装势力, 其他组织]}
    归属政治实体: {引用: 势力}
    所在区域: {引用: 地点}
    组织特点: {形态: 文本列表}

道具:
  分法: 按种类
  分级: [标签]
  字段:
    标签: {必填: true, 取值: [药剂, 食品, 材料, 工具, 书籍, 文书, 纪念]}
    简介: {必填: true, 形态: 文本}
    多货币价格表: {映射: {键: {引用: 货币}, 值: {形态: 文本}}}
```

地点的上级类型中，没有任何类型把“地标”列为上级，所以地标下面不能再挂地点。
