# 世界树·统筹

本 skill 只读诊断项目现状并编排分层建卡，不代写各层产物；各层写法归对应阶段 skill（职责表见 [`../README.md`](../README.md)）。工具调用与检查口径见 [`../shared/工具与检查.md`](../shared/工具与检查.md)。

## 诊断（只读）

按序检查项目根，判定项目处于第 0–5 层中的哪一层，并列出缺口与推荐下一步：

1. `来源资料/` 与 `作者资料/通读/`：分卷账本与 5 份全局总账是否齐全、坐标是否可查。
2. `世界书/设定/`、`世界书/世界概况/`、`世界书/扮演准则/`：第二层声明与全局文风。
3. 条目库目录（对照 `设定/条目库.yaml`）：公共条目与引用 ID 是否就绪。
4. `世界书/角色/` 与 `世界书/历史/`：角色组、事件树、事件串与开局。
5. 事件正文、角色位置与 `作者资料/出处/`：实写程度与出处完整性。
6. 卡面与打包产物：是否已有可导入的角色卡。

完成标准：能向作者说出“当前第 N 层、缺什么、下一步做哪件事”。

## 运行模式（开工时与作者确认，二选一）

- **引导模式（默认）**：执行并跑通当前层出口门禁后停下，按三段呈报——产出摘要、工具检查结果、待拍板清单与下一步建议；作者拍板后才进入下层。
- **自动模式**：作者要求自动推进或指定目标层时，按 `0→1→2→3→4a/4b→5` 连续推进至目标层，只在硬阻塞停下问作者：改编范围未定、核心设定冲突、缺少来源原文。非阻塞细节取保守方案记入待复核清单，推进完成或到达目标层后一并汇总呈报。

## 分流

- 各层执行：点名对应阶段 skill（通读/地基/条目/骨架/档案/填景/打包），传递诊断结论与作者拍板口径。当前代理环境支持隔离子代理时，每层（长篇可分批）派发独立子代理，交接包固定 4 项：项目根目录路径、当前层 skill 路径、上游总账与已拍板口径、运行模式与硬阻塞回报规则；不支持时在本会话按层收口。
- 建成卡（或返工）后的局部改动与跨层小修：交 [`世界树·修订`](../ygg-edit/SKILL.md)。
