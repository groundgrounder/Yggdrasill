# 世界树·建立

本 skill 负责从原作建立整套世界书的编排与建立期决策。建立顺序的正本在 [`docs/写作规范.md`“编辑”](../../docs/写作规范.md#编辑)；事件、角色与档案的字段规则见 [`docs/参考/事件.md`](../../docs/参考/事件.md)、[`docs/参考/角色.md`](../../docs/参考/角色.md)；档案正文的写法见 [`docs/写作规范.md`“档案”](../../docs/写作规范.md#档案)。分级、越界与公共检查见 [`../shared/编辑分级.md`](../shared/编辑分级.md)。本 skill 不复制这些正文。

## 1. 定名单

1. 逐章读原作，列出有名有台词的人物；无名说话人只按章记人数。
2. 把名单与计数写进 `作者资料/`，交作者确认；名单变化时保留旧版与增补原因。
3. 名单只收作者确认过的人物。单点新增一个角色组或事件不走本 skill。

完成标准：每个有名有台词的人物都在名单中；无名说话人只在核定日志中计数；作者已确认名单。

## 2. 预建角色组

1. 为名单内每个角色组建 `角色组.yaml` 与首次出场那一期的档案；字段与档案项按参考写，两份档案正文交“建角色”。
2. 首次出场只写当期档案；后续档案留给切期事件建成后处理。写了版本时同步至少一份适用档案。
3. 按首次出场分批审阅。

完成标准：每个名单人物都有角色组与至少一份默认档案；没有提前写入的后期档案；`check --static-only` 对本批没有角色组或档案错误。

## 3. 逐章循环

一篇审阅通过后再进入下一篇。

### 3.1 核对角色组

1. 本篇名单内的说话人都应已预建；缺人时先停下补建，再继续。
2. 补建只写当前篇起的档案；此前各篇的台词从核定日志的名单外记录中找回补入。

完成标准：本篇没有未建组的名单人物；补建角色组的档案从当前篇起。

### 3.2 建事件

1. 逐章抽取事件与角色位置，写结构与必填文本首稿；字段与书写规则按事件文档。
2. 名单内人物的台词按原句收进各自角色位置，并在 `作者资料/出处/` 逐句登记来源；名单外说话人只留在核定日志。
3. 本篇结束跑 `check --static-only`。

完成标准：本篇每个事件都有事件文件与必填文本首稿；每句名单内原台词都在对应角色位置且有出处记录；静态检查无新增错误。

### 3.3 命名事件串

1. 为本篇里有起点、有终点的过程建串，写概述、事件与结局。
2. 不把没有过程的零散事件硬凑成串；孤立事件不建串。

完成标准：事件串文件存在；起点与结局都可达；没有孤立成员或重复归属。

### 3.4 接档案

1. 本篇的切期事件建好后，写下一期的档案，或从 `作者资料/暂存/` 接回。
2. 没有切期事件的档案先进暂存，并在暂存清单登记接回位置、结构与条件。
3. 新档案只写本时期及以前已确立的事实。

完成标准：每个切期事件都有下一期档案或暂存登记；早期档案不含后期事实。

### 3.5 审阅

1. 逐项核对：台词的收录与出处、事件分类、档案与事件不矛盾、门槛与事件串。
2. 把审阅清单写进 `作者资料/`；问题项修正或列为未解决。

完成标准：审阅清单已写；本篇全量检查通过；问题项已修正或列为未解决。

## 4. 全书复核

1. 按 shared 跑全量 `check`，用 `if` 核对默认路径与事件串结局。
2. 每篇至少抽查一句台词与一份档案：台词能在原作逐字找到，说话人与角色位置一致；首次出场档案没有后期事实。
3. 需要统一 YAML 风格时按 shared 运行 `format`。

完成标准：全量检查无新增错误；抽查结果逐条记录；早期档案没有越界事实；没有名单外说话人混入角色位置。

## 5. 报告

写明名单、首批档案、逐章事件与事件串、出处记录、后续档案与暂存、检查和审阅结果，以及未解决项。

完成标准：报告按建立顺序列出产物与检查结果；未解决项写明位置与是否影响本次范围。
