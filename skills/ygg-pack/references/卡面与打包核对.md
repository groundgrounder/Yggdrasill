# 卡面与打包核对

## 卡面字段契约

| 字段 | 必填 | 约束 |
|---|---|---|
| `卡ID` | 是 | 非空文本；跨版本稳定，不得随 `名称` 改变 |
| `卡版本` | 是 | 非空文本，供人识别版本 |
| `名称` | 是 | 非空文本，同时决定产物文件名 `<名称>.json` |
| `描述` | 是 | 非空文本；写叙述者职责，不写命令语法或随运行模式冲突的长期指令 |
| `开场白` | 是 | 非空纯正文；严禁包含 `<命令>` 或 `</命令>` |
| `开局` | 是 | 映射（如 `开局时间`、`方案`、`角色组`、`玩家`、`历史选择`），供开局前端作默认初值 |
| `开场命令` | 否 | 单键命令映射的列表（如 `确认初始化`、`写场景`）；打包时会在内存中预执行一次 |

不得写入上述七键之外的未授权字段。

## 打包命令与路径解析

- 统一入口：`ygg pack [项目目录] [--face <卡面文件>] [--prepare-only] [--compatible <64位指纹>]...`
  - 未链接 `ygg` 到 `PATH` 时用 `node <世界树仓库>/cli/ygg.mjs pack ...`。
  - `[项目目录]` 相对当前工作目录解析，省略时取当前工作目录。
  - `--face` 相对当前工作目录解析，省略时取 `<项目目录>/卡面.yaml`。
- 兼容保留的旧脚本：`node <世界树仓库>/adapter/build.mjs [项目目录] [--face <卡面文件>]`（注意该旧脚本中 `[项目目录]` 相对仓库根解析且缺省为内部夹具、`--face` 相对 `adapter/` 解析）。日常建卡优先用 `ygg pack`。

## 打包后三项核对

1. **开场命令**：构建日志确认全部 `开场命令` 执行成功，无失败输出。
2. **构建清单**：打印的 `卡ID`、`卡版本`、`世界书哈希` 与 `程序指纹`（以及显式传入的 `--compatible` 旧指纹）与角色卡 JSON 内嵌脚本一致。
3. **资料隔离**：产物 JSON 不含 `/作者资料/` 与私有本地路径。

打包机制与兼容升级细节见本地 Yggdrasill 仓库 `docs/06-酒馆适配.md`。
