# 世界树·打包

本 skill 是建卡第 5 层：卡面定稿与酒馆打包。契约正本是 [`adapter/build.mjs`](../../adapter/build.mjs) 与 [`adapter/卡面.yaml`](../../adapter/卡面.yaml)；打包机制见 [`docs/06-酒馆适配.md`](../../docs/06-酒馆适配.md)；命令与路径解析口径见 [`../shared/工具与检查.md`](../shared/工具与检查.md)。

## 卡面（YAML）

必填：`卡ID`（跨版本稳定，不随名称改变）、`卡版本`、`名称`、`描述`、`开场白`、`开局`（默认开局映射）。可选：`开场命令`（单键命令映射的列表）。开场白禁止包含 `<命令>` 块。`描述` 写叙述者职责，不写命令语法。写法参照 [`adapter/卡面.yaml`](../../adapter/卡面.yaml)；出现“未授权字段”等报错时，按 `build.mjs` 的报错清单删改，不绕过校验。

## 构建与核对

1. 全量 `ygg check <世界书>` 0 错误后，执行 `node <世界树仓库>/adapter/build.mjs <项目目录> --face <卡面文件>`（路径解析口径见共享页）；预检查用 `--prepare-only`；声明兼容旧程序用 `--compatible <64位指纹>`。
2. 核对构建输出三项：开场命令全部执行成功；构建清单（卡ID、卡版本、程序指纹、世界书哈希）与卡内一致；卡内无 `/作者资料/` 泄露。
3. 构建整体失败并指明字段时，修卡面或回对应层修世界书，不在本层绕过检查。

## 交付酒馆

- 导入构建出的角色卡 JSON，导入时允许卡内脚本与局部正则。
- 配套预设导入 [`presets/yggdrasill.json`](../../presets/yggdrasill.json)：主提示词限定叙述者身份与正文边界，作者可按自己的文风改写，不影响协议与检查。

出口门禁：构建成功且三项核对全过。呈报：产出摘要（卡文件路径、世界书哈希、程序指纹）+ 检查结果 + 导入指引 + 待拍板项。
