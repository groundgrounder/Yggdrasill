# 按级编辑与检查矩阵

## 命令口径与最小检查矩阵

优先 `ygg <命令>`；未入 `PATH` 时用 `node <世界树仓库>/cli/ygg.mjs <命令>`。

| 级别 | 改前必跑 | 改后必跑 | 禁止事项 |
|---|---|---|---|
| 设定级 | 临时副本删改探针 `ygg check --static-only --json` + 全文检索旧值 | 全量 `ygg check` + 相关 `ygg if` | 不得静默丢弃旧值或留给未声明字段 |
| 结构级 | `ygg trace <世界书> <对象键>` 列全“引用它” | 全量 `ygg check` + 相关 `ygg if` / `ygg preview` + `ygg format --check` | 不得漏改跨文件引用 |
| 文本级 | 条件文本写下五槽范围；`check` 基线 | `ygg check` + `ygg format --check`（不要求跑 `if`） | 不得顺带改结构、声明或放宽范围 |

### `trace` 九类对象键

| 类型 | 对象键写法 |
|---|---|
| 事件 | `事件:<ID>` |
| 事件串 | `事件串:<ID>` |
| 角色组 | `角色组:<ID>` |
| 档案 | `档案:<角色组ID>:<档案ID>` |
| 条目 | `条目:<库名>:<条目ID>` |
| 剧情标记 | `剧情标记:<ID>` |
| 世界线 | `世界线:<ID>` |
| 开局选项 | `开局选项:<序号>` |
| 开局方案 | `开局方案:<ID>` |

## 条件文本五槽与红线

- **条件文本五槽**（用于 `叙事条件`、`分支条件`、`介入条件`、`触发情境`、`触发限制`）：
  `对象`（适用于哪些人）、`地点`（在哪些地点成立）、`时间`（在哪段时期成立）、`分支`（在哪些分支下成立）、`触发情形`（什么情形触发）。`check` 与 `if` 均不判适用范围，须人工对照。
- **越界清单**：文本一律不写 `关系、婚姻、家系、职位、资产、持有物、伤势、当前穿着、能力的取得与丧失、当前所在`。
- **文本四问**：删去它，模型会不会出错；它是信息还是装饰；能否改成列表；不看原文能否读懂。
- 完整参考见本地 Yggdrasill 仓库 `docs/写作规范.md` 与 `docs/参考/命令.md`。
