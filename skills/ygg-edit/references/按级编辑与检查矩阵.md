# 按级编辑与检查矩阵

本参考页供 `世界树·修订` 独立自包含查阅，覆盖外观级分流与三层编辑定级矩阵、`trace` 九类对象键、修改 `核心参与者` 连锁核查、旧存档 A/B/C 兼容评估、`作者资料/` 规范、条件文本五槽与越界红线。

## 1. 命令口径与按级检查矩阵

优先 `ygg <命令>`；未入 `PATH` 时用 `node <世界树仓库>/cli/ygg.mjs <命令>`。第一层架构由世界树规范固定，卡不能覆盖。

| 级别 | 范围说明 | 改前必跑 | 改后必跑 | 禁止事项 |
|---|---|---|---|---|
| **外观级（分流）** | `<项目目录>/外观/`（不属世界书三层，不改 `世界书哈希`） | 交 `世界树·前端` 处理 | `theme-tool.mjs validate` + 暗/亮/移动端 `preview` + `ygg pack` | 禁止把外观文件放入 `世界书/` |
| **设定级** | `设定/` 第二层声明（不含 `文本规范.yaml`） | `剧情标记:<ID>` / `条目:<库>:<ID>` 先跑 `ygg trace`；等级/能力/条目库/词表走一次性临时副本删改探针 `ygg check --static-only --json` + 全文检索旧值 | 全量 `ygg check` + 相关 `ygg if` | 不得静默丢弃旧值、不得为过检反改声明或检查器 |
| **结构级** | 事件/分支/门槛/变化/`核心参与者`/事件串/世界线/开局/角色组/档案生效条件/条目 ID 与引用 | `ygg trace <世界书> <对象键>` 列全“引用它”；改 `核心参与者` 另做连锁核查 | 全量 `ygg check` + 相关 `ygg if` / `ygg preview` + `ygg format --check`（若 `--write` 后须重跑 `check`） | 不得漏改跨文件引用；`ygg view` 仅限事件与角色位置图形化编辑 |
| **文本级** | 档案正文、事件概要与条件文本、角色位置、条目正文、概况、准则、**`设定/文本规范.yaml`**（须确认未放宽第四层） | 条件文本写下五槽范围；`check` 基线 | `ygg check` + `ygg format --check`（`--write` 后必重跑 `check`；纯文本不要求跑 `if`） | **绝不顺带补写事件或断言状态**（错位只清理越界并指出结构缺口）；不改结构/声明/测试/检查器 |

| 类型 | 对象键写法 |

| 开局方案 | `开局方案:<ID>` |

## 2. 改 `核心参与者` 连锁影响核查清单

修改任一事件的 `核心参与者` 属结构级高危改动，须逐项核查四重连锁影响：

1. **事件排除面**：新增的核心参与者一旦在本局被停用，整件事件将直接被判 `已排除`（若属世界事件，原则上应保持 `[]`）；
2. **变化表启用担保**：从 `核心参与者` 移除某角色组后，若分支 `变化` 路径或映射键仍写到该角色组且门槛未正极性担保其启用，会触发错误 `变化.角色未保证启用`；
3. **开局前端必选锁定**：若该事件在 `开局选项.yaml` / `开局方案` 中被选中（非 `未发生`），其 `核心参与者` 会被开局前端强制锁定为必选启用角色组；
4. **路由候选与经历召回**：直接改变该事件游玩期何时成为候选与排序权重，以及封卷/待登记后作为谁的 `实际参与者`（影响 `角色已出场`、`出场自动` 初始化与经历召回）。

## 3. 旧存档 A/B/C 三级兼容影响评估

面向已发布且存在玩家旧存档的卡片，修订前先预判兼容级别（保持 `卡ID` 不变）：

- **A 级（自动兼容，无感更新）**：仅改档案/事件/条目纯文本、世界概况、扮演准则、追加未到期未来事件，或仅修改 `<项目目录>/外观/`（外观甚至不改变 `世界书哈希`）；
- **B 级（纯增补待升级）**：仅在 `开局.角色组` 或 `世界.剧情标记` 新增默认键，原有历史与所有字段快照 100% 不变（玩家一键确认升级）；
- **C 级（破坏性冲突，旧存档只读）**：**改写任何对象 ID、删除角色组、删除剧情标记、修改早于开局时间的过去事件或改写已确认事件变化**。此类改动前须明确告知作者并征得拍板。

## 4. `作者资料/` 标准存放规范

`作者资料/` 不进入上下文也不随 `ygg pack` 打包，修订过程中按职责归位：

- **`作者资料/暂存/`**：已写好待接回世界书的内容（保留世界书相对目录结构），并在 **`作者资料/暂存/暂存清单.yaml`** 逐项登记（`类型`/`ID`/`接回位置`/`接回结构`/`接回条件`），接回后删除清单项；
- **`作者资料/候选/`**：尚未拍板的草案、文本级排查出的结构缺口或待补充设定，定案写入世界书后即移除；
- **`作者资料/归档/`**：撤下或废弃的内容，保留原世界书相对布局供回溯；
- **`作者资料/生成/`**：工具自动输出产物（如导出事件树），不手改。

## 5. 条件文本五槽与核心红线

- **条件文本五槽**（用于 `叙事条件`、`分支条件`、`介入条件`、`触发情境`、`触发限制`）：
  `对象`（适用于哪些人）、`地点`（在哪些地点成立）、`时间`（在哪段时期成立）、`分支`（在哪些分支下成立）、`触发情形`（什么情形触发）。`check` 与 `if` 均不判适用范围，须人工对照。
- **越界清单**：文本一律不写 `关系、婚姻、家系、职位、资产、持有物、伤势、当前穿着、能力的取得与丧失、当前所在`。
- **文本四问**：删去它，模型会不会出错；它是信息还是装饰；能否改成列表；不看原文能否读懂。
