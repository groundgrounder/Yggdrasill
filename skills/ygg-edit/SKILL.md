# 世界树·修订

本 skill 处理建成卡（或返工）后的局部改动。按所改字段判最高级别，允许在一次工作内连贯修改关联的结构与文本，只跑最小必要检查。分级正本见 [`docs/写作规范.md`“编辑”](../../docs/写作规范.md#编辑)；命令口径与按级别的最小检查矩阵见 [`../shared/工具与检查.md`](../shared/工具与检查.md)；红线速查见 [`../shared/写作红线.md`](../shared/写作红线.md)。

## 定级

| 级 | 所改字段 |
|---|---|
| 设定级 | `设定/` 第二层声明 |
| 结构级 | 事件/分支/门槛/变化/事件串/开局/角色组/条目 ID 与引用 |
| 文本级 | 档案正文、事件概要与条件文本、角色位置、条目、概况、准则 |

改前改后各跑哪些检查，按 [`../shared/工具与检查.md`](../shared/工具与检查.md) 的最小检查矩阵执行。混合改动取最高级：直接把关联的结构与文本一次改完，再按最高级统一跑检查。

## 流程

1. **设定级**：在一次性临时副本上删/改待改值，跑 `check --static-only --json` 得反向清单；配文本检索列出全部旧值位置，逐项与作者确认迁移值，再改真实文件。
2. **结构级**：改前 `trace` 列出指向待改对象的全部引用（八类对象键写法见 [`../shared/工具与检查.md#trace-对象键`](../shared/工具与检查.md#trace-对象键)）；改后同步全部引用与受影响文本。
3. **文本级**：改前写下五槽适用范围；改后逐槽对照，范围变了就退回原文，或把改动拆给结构级。
4. 改后按定级跑最小检查，对照改前基线只对新增失败负责；纯文本改动不要求跑 `if` 对比。

## 停下等作者

迁移值清单、ID 改名（它是存档中的引用键）、条件适用范围变化，须作者拍板后才落盘。完成后呈报：改动清单 + 级别 + 检查结果，改前已有与本次新增分开列出。
