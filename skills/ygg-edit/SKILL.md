# 世界树·修订

本 skill 处理建成卡（或返工）后的局部改动。按所改字段判最高级别，允许在一次工作内连贯修改关联的结构与文本，只跑最小必要检查。按级检查矩阵、`trace` 对象键、五槽与越界清单见 [`./references/按级编辑与检查矩阵.md`](./references/按级编辑与检查矩阵.md)。

## 定级

| 级 | 所改字段 |
|---|---|
| 设定级 | `设定/` 第二层声明 |
| 结构级 | 事件/分支/门槛/变化/事件串/开局/角色组/条目 ID 与引用 |
| 文本级 | 档案正文、事件概要与条件文本、角色位置、条目、概况、准则 |

混合改动取最高级：直接把关联的结构与文本一次改完，再按最高级统一跑检查。

## 流程

1. **改前留基线**：先跑 `ygg check <世界书目录> --static-only --json`（或全量 `ygg check`）记下已有错误与提示；改后只对新增失败负责。
2. **设定级**：在一次性临时副本上删/改待改值，跑 `ygg check <副本世界书> --static-only --json` 得反向清单；配文本检索列出全部旧值位置，逐项与作者确认迁移值，再改真实文件；改后跑全量 `ygg check` 与相关 `ygg if`。
3. **结构级**：改前用 `ygg trace <世界书目录> <对象键>` 列出指向待改对象的全部引用（“引用它”）；改后同步全部引用与受影响文本，再跑全量 `ygg check`、相关 `ygg if` / `ygg preview` 与 `ygg format <世界书目录> --check`。
4. **文本级**：改条件文本前先写下五槽适用范围；改后逐槽对照，范围变了就退回原文，或把改动拆给结构级；改后跑 `ygg check <世界书目录>` 与 `ygg format <世界书目录> --check`（纯文本改动不要求跑 `if` 对比）。

## 停下等作者

迁移值清单、ID 改名（它是存档中的引用键）、条件适用范围变化，须作者拍板后才落盘。完成后呈报：改动清单 + 级别 + 检查结果，改前已有与本次新增分开列出。
