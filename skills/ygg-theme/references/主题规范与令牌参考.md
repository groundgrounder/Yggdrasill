# 主题规范与令牌参考

本文是 `世界树·前端` 的自包含参考手册，涵盖 `<项目目录>/外观/` 目录规范、`主题.yaml` 字段清单、CSS 设计令牌、4 套内置基座、DOM 选择器挂钩、暗/亮双模式对白配色配方与安全红线排查表。

## 1. `<项目目录>/外观/` 目录结构与发现规则

外观目录必须位于项目根 `<项目目录>/外观/`（**严禁**放入 `<项目目录>/世界书/`），打包与校验工具按以下顺序收集主题：

1. 先检查 `<项目目录>/外观/主题.yaml`（单主题根形态）；
2. 再遍历 `<项目目录>/外观/` 的一级子目录（按码点序排序），读取其中包含 `主题.yaml` 的子目录（多主题形态）。

```text
<项目目录>/
├── 世界书/                 # 只放世界书运行文件，禁止放外观
├── 卡面.yaml
└── 外观/
    ├── 主题.yaml           # 形态 A：单主题直接放在 外观/ 下
    ├── 样式.css            # 可选，自动发现
    └── <子主题目录>/       # 形态 B：多主题按一级子目录存放
        ├── 主题.yaml
        └── 样式.css
```

### 样式文件自动发现顺序

每个主题目录内，CSS 按以下优先级加载并拼接：

1. 若 `主题.yaml` 显式填写了 `样式文件`（或 `cssFile`）：只加载该同目录文件（不得含 `/`、`\`、`.`、`..`，缺失或非普通文件即报错）；
2. 若未填写 `样式文件` / `cssFile`：按序自动发现同目录的 `样式.css` → `theme.css`（命中首个即停止）；
3. 若 `主题.yaml` 还填写了内联 `css`（或 `样式`）：拼在样式文件正文之后，两者合并后统一按 64KB 上限与安全红线校验。

> 安全约束：`外观/` 目录、子目录、配置与样式文件均不得为符号链接，须为合法 UTF-8 编码的普通文件且严格位于 `<项目目录>/外观/` 内。

## 2. `主题.yaml` 完整字段清单

字段均支持中英文别名（同义键同时出现时按列表前者优先）：

| 字段（别名） | 必填 | 类型 | 说明与校验边界 |
|---|---|---|---|
| `id` / `ID` | 是 | 文本 | 唯一主题标识。正则 `/^[a-z0-9][a-z0-9_-]{0,63}$/`；禁止保留字 `auto`、`default`、`none`、`builtin`、`card`、`__proto__`、`constructor`、`prototype`；不得与内置主题 `modern` / `classic` / `fantasy` / `cyber` 重名；同卡内不得重复 |
| `name` / `名称` | 是 | 文本 | 玩家在设置页看到的主题显示名，非空 |
| `description` / `说明` / `简介` | 否 | 文本 | 主题简介，展示于设置页主题说明区 |
| `default` / `默认` | 否 | 布尔 | 设为 `true` 时成为本卡默认主题（当玩家外观设置为 `auto` 时优先启用）；若卡内多个主题均未标 `default`，引擎取首个卡主题 |
| `base` / `基座` / `继承` | 否 | 文本 | 继承的内置基座，允许 `modern` / `classic` / `fantasy` / `cyber`，缺省为 `modern` |
| `tokens` / `令牌` | 否 | 键值映射 | 覆写 `--ygg-*` CSS 变量。键须匹配 `/^--ygg-[a-zA-Z0-9_-]+$/`；值为非空文本、不得含 `{` 或 `}`，且须通过 CSS 危险模式校验 |
| `layout` / `布局` | 否 | 映射 | 推荐排版与每楼形态，仅允许以下 4 个键：`每楼形态`、`正文美化`、`对白高亮`、`首行缩进` |
| `样式文件` / `cssFile` | 否 | 文本 | 同目录 CSS 文件名（不含路径分隔符）；省略时自动尝试 `样式.css` / `theme.css` |
| `css` / `样式` | 否 | 文本 | 内联 CSS 规则，会追加在同目录样式文件之后一起校验与注入 |

### `layout`（布局）4 项键与生效优先级

| 键名 | 允许值 | 系统兜底默认 | 说明 |
|---|---|---|---|
| `每楼形态` | `bar` / `card` / `minimal` | `bar` | `bar` 紧凑单行条；`card` 场景抬头卡（顶部胶囊 + 摘要）；`minimal` 极简细条 |
| `正文美化` | 布尔 | `true` | 是否为助手楼挂载 `.ygg-prose-host` 排版层 |
| `对白高亮` | 布尔 | `true` | 是否为 `“…”`、`「…」`、`『…』` 无损包裹 `.ygg-dialogue` |
| `首行缩进` | 布尔 | `false` | 是否对正文段落启用 `text-indent: 2em`（`blockquote p` 自动免缩进） |

生效优先级（从高到低）：

1. **玩家显式设置**（在「设置 → 外观」中手动选定的非 `auto` / 非 `null` 项）
2. **当前主题 `layout`**（卡主题在 `主题.yaml` 中声明的值）
3. **基座主题 `layout`**（所继承内置基座的默认值）
4. **系统兜底默认值**

## 3. 设计令牌清单（`--ygg-*`）

### 3.1 17 个基础宿主自适应令牌

以下 17 个基础令牌定义在 `.ygg-panel, .ygg-floor, .ygg-prose-host` 上，默认跟随酒馆主题变量（`--SmartTheme*`）实现暗/亮双模式自适应：

| 令牌 | 默认来源 / 含义 |
|---|---|
| `--ygg-text` | `var(--SmartThemeBodyColor, #e5e7eb)` — 主文本色 |
| `--ygg-muted` | `var(--SmartThemeEmColor, color-mix(in srgb, var(--ygg-text) 64%, transparent))` — 次要/说明文本色 |
| `--ygg-accent` | `var(--SmartThemeQuoteColor, #4f9d7a)` — 主强调色 |
| `--ygg-base` | `var(--SmartThemeBlurTintColor, rgba(22, 24, 29, 0.88))` — 宿主底板色 |
| `--ygg-bg-surface` | `color-mix(in srgb, var(--ygg-base) 84%, var(--ygg-text) 4%)` — 一级卡片表面 |
| `--ygg-bg-elevated` | `color-mix(in srgb, var(--ygg-base) 76%, var(--ygg-text) 8%)` — 抬升卡片/表头背景 |
| `--ygg-bg-subtle` | `color-mix(in srgb, var(--ygg-text) 5%, transparent)` — 柔和微底色（标签、胶囊、折叠子段） |
| `--ygg-border` | `color-mix(in srgb, var(--SmartThemeBorderColor, var(--ygg-text)) 32%, transparent)` — 常规边框 |
| `--ygg-border-strong` | `color-mix(in srgb, var(--SmartThemeBorderColor, var(--ygg-text)) 56%, transparent)` — 强调/悬停边框 |
| `--ygg-ok` | `#3fa36c` — 正常/成功语义色 |
| `--ygg-warn` | `#d4943a` — 警告语义色 |
| `--ygg-bad` | `#cf5c5c` — 阻断/失败语义色 |
| `--ygg-info` | `#4b8fd4` — 提示/升级语义色 |
| `--ygg-radius` | `10px` — 主容器圆角 |
| `--ygg-radius-sub` | `7px` — 子卡片/输入框圆角 |
| `--ygg-radius-pill` | `999px` — 胶囊/徽章圆角 |

### 3.2 字体、对白与正文排版扩展令牌

| 令牌 | 说明与典型值 |
|---|---|
| `--ygg-font-ui` | 面板与每楼状态栏字体栈（如系统衬线 `"Songti SC", "STSong", "Noto Serif SC", "Source Han Serif SC", Georgia, serif`） |
| `--ygg-font-prose` | 助手楼正文字体栈（仅使用系统字体或通用字体族，禁止外链 WebFont） |
| `--ygg-font-mono` | 等宽字体栈（`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`） |
| `--ygg-dialogue-color` | `.ygg-dialogue` 对白文字色（推荐用 `color-mix` 混入 `var(--ygg-text)` 保障双模式可读） |
| `--ygg-dialogue-bg` | `.ygg-dialogue` 对白微底色（推荐低透明 `color-mix(..., 8%–14%, transparent)`） |
| `--ygg-prose-scale` | 正文字号缩放系数（由玩家滑块写入，范围 `0.9`–`1.2`，默认 `1`） |
| `--ygg-prose-leading` | 正文行距（由玩家滑块写入，范围 `1.5`–`2.2`，默认 `1.75`） |

## 4. 4 套内置基座特点与选型

| 基座 ID | 名称 | 视觉特征 | 默认布局 | 适用题材 |
|---|---|---|---|---|
| `modern` | 现代工具 | 通透表面、柔和强调色、圆角 `10px`、`blockquote` 左侧强调条与渐变分割线 | `bar`、美化开、对白开、缩进关 | 现代都市、日常、推理、通用默认 |
| `classic` | 典雅书卷 | 宣纸暖金底调、朱砂 `#b8432e` 主色、硬朗 `4px` 圆角、双线抬头与双线左框、衬线字体、古籍眉批 `blockquote` | `card`、美化开、对白开、缩进开 | 历史演义、武侠仙侠、古典志怪 |
| `fantasy` | 奇幻手札 | 羊皮暖金 `#c99a3c` + 翡翠 `#2e9e6f` 双点缀、属性卡顶边强调、手札边框与徽章胶囊 | `card`、美化开、对白开、缩进关 | 西幻 RPG、异世界冒险、剑与魔法 |
| `cyber` | 赛博终端 | 锐利 `2px` 切角、微网格与扫描线头饰、青蓝 `#22d3ee` + 电光绿高对比、等宽标签与虚线 `<hr>` | `card`、美化开、对白开、缩进关 | 赛博朋克、科幻机甲、未来终端 |

继承机制：引擎会先合并 `baseTheme.tokens` 再覆写卡主题的 `tokens`，并将 `baseTheme.css` 中的 `[data-ygg-theme="<baseId>"]` 自动重写为 `[data-ygg-theme="<cardThemeId>"]`，随后再追加卡主题的自定义 `css`。因此卡主题只需写增量差异，不必重复整套基座代码。

## 5. 可安全定制的 DOM 选择器挂钩

所有卡主题规则建议以 `[data-ygg-theme="<你的id>"]` 开头，既清晰隔离作用域，又能稳定覆盖基座样式：

| 区域 | 选择器挂钩 | 说明 |
|---|---|---|
| 主题作用域 | `[data-ygg-theme="<id>"]` | 挂在 `.ygg-panel`、`.ygg-floor`、`.ygg-prose-host` 上 |
| 本局面板容器 | `.ygg-panel`、`.ygg-panel-head`、`.ygg-panel-brand`、`.ygg-head-pill` | 顶栏、品牌标题与右上角元信息胶囊 |
| 此刻总览区 | `.ygg-hero`、`.ygg-hero-head`、`.ygg-hero-grid`、`.ygg-stat-card`、`.ygg-stat-label`、`.ygg-stat-val` | 时间/地点/在场卡片 |
| 分段与折叠卡 | `.ygg-tabs`、`.ygg-tab-btn`、`.ygg-sec`、`.ygg-sec > summary`、`.ygg-tag`、`.ygg-chip` | 导航标签、折叠区与人物/条目胶囊 |
| 时间轴与表格 | `.ygg-timeline`、`.ygg-timeline-item`、`.ygg-timeline-time`、`.ygg-table-wrap`、`.ygg-table`、`.ygg-badge` | 经历时间轴与状态表 |
| 每楼状态栏 | `.ygg-floor`、`.ygg-floor-card`、`.ygg-floor-minimal`、`.ygg-label`、`.ygg-scene-pill`、`.ygg-brief` | 三种每楼形态、状态标签、场景抬头胶囊与摘要 |
| 正文排版宿主 | `.ygg-prose-host`、`.ygg-prose-host p`、`.ygg-prose-host em`、`.ygg-prose-host blockquote`、`.ygg-prose-host hr` | 助手楼正文排版 |
| 对白高亮 | `.ygg-prose-host[data-ygg-dialogue="true"] .ygg-dialogue` | 自动包裹的 `“…”`、`「…」`、`『…』` 对白（`<code>`/`<pre>`/`<a>` 内自动跳过） |

## 6. 暗/亮双模式自适应与对白对比度配方

玩家可能使用深色夜读主题，也可能使用浅色宣纸/白底主题。定制主题时请遵循以下配方：

1. **避免写死纯黑/纯白文字与不透明背景**：表面背景始终基于 `var(--ygg-base)` 和 `var(--ygg-text)` 使用 `color-mix(in srgb, ...)` 混合，例如：
   ```css
   --ygg-bg-surface: color-mix(in srgb, var(--ygg-base) 82%, #c9a86c 7%);
   --ygg-bg-elevated: color-mix(in srgb, var(--ygg-base) 74%, #c9a86c 11%);
   ```
2. **对白高对比度配方**：不要直接把低饱和或偏暗的强调色赋给 `--ygg-dialogue-color`，否则在暗底上发闷、亮底上刺眼。推荐把主色与 `var(--ygg-text)` 按 `52%–64%` 混合，再配 `8%–12%` 透明底：
   ```yaml
   tokens:
     --ygg-dialogue-color: "color-mix(in srgb, #c84b31 58%, var(--ygg-text))"
     --ygg-dialogue-bg: "color-mix(in srgb, #c84b31 11%, transparent)"
   ```
3. **验证方式**：始终用 `theme-tool.mjs preview` 同时在 `--mode dark` 与 `--mode light` 下实测，确保对白与正文 `p` 颜色明显区分且阅读不费眼。

## 7. CSS 安全红线与常见报错排查表

| 报错关键词 | 触发原因 | 修复方式 |
|---|---|---|
| `主题 id 不合法` | 含大写字母、中文、空格或非字母数字开头 | 改为小写字母/数字开头，仅含 `a-z0-9_-`，最长 64 字符 |
| `不得使用保留字` / `不得与内置主题重名` | 使用了 `auto`/`default`/`modern`/`classic`/`fantasy`/`cyber` 等 | 改用带作品前缀的唯一 ID（如 `sanguo-scroll`） |
| `含非法令牌键` | `tokens` 中键名未以 `--ygg-` 开头 | 统一改为 `--ygg-*` |
| `不得包含花括号` | 令牌值中写了 `{` 或 `}` | 移除花括号；完整规则应写进 `样式.css` |
| `布局含未授权字段` / `每楼形态 不合法` | `layout` 写了白名单外的键，或 `每楼形态` 不在 `bar`/`card`/`minimal` 内 | 仅保留 4 个白名单键并核对枚举/布尔值 |
| `禁止包含外链 URL` / `禁止使用 @import` | CSS 或令牌中含 `http(s)://` 或 `@import` | 删除所有外链与 `@import`，改用系统字体与纯 CSS 渐变/内联 SVG 策略 |
| `禁止顶层裸全局选择器` | 顶层写了 `body {}`、`html {}`、`* {}`、`:root {}`、`#chat {}`、`.mes {}` | 改用 `[data-ygg-theme="<id>"]`、`.ygg-panel`、`.ygg-floor`、`.ygg-prose-host` 限定作用域 |
| `主题 CSS 超过大小上限` | 样式文件 + 内联 `css` 超过 65,536 UTF-8 字节 | 精简冗余规则或移除大体积内嵌数据 |
| `不跟随符号链接` / `越出允许目录` | `外观/` 内含软链或 `样式文件` 含路径分隔符或上级目录引用 | 使用普通文件并将样式文件放在同目录 |
