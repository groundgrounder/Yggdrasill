# 写作红线

十一个作者 skill 共用本页速查。规范正本是 [`docs/写作规范.md`](../../docs/写作规范.md)；本页不复述正文，只留写作时最容易踩的核心红线。

## 越界

清单唯一出处在此。把本局状态写进文本就是越界。以下内容只由事件变化或写场景写入，文本一律不写，换个字段名承载同样越界：

关系、婚姻、家系、职位、资产、持有物、伤势、当前穿着、能力的取得与丧失、当前所在。

`check` 不判语义越界：状态断言可以零错误通过，须逐条人工核对。

## 条件文本五槽

改叙事条件、分支条件、介入条件、触发情境、触发限制之前，先写下五槽适用范围；改后逐槽对照，范围变了就退回原文，或把改动拆给结构级：

| 槽 | 问 |
|---|---|
| 对象 | 适用于哪些人 |
| 地点 | 在哪些地点成立 |
| 时间 | 在哪段时期成立 |
| 分支 | 在哪些分支下成立 |
| 触发情形 | 什么情形触发 |

`check` 与 `if` 都不判适用范围，这一项只能人工核对。

## 文本四问

每句话过四问：删去它，模型会不会出错；它是信息还是装饰；能否改成列表；不看原文能否读懂。只写会让模型出错的差异信息。

## 原台词归属

原台词逐字收进**实际说话角色**的角色位置候选台词，排在作者自拟台词之前；出处写进 `作者资料/出处/`，正文不标注。别人对他说的话写进他的角色知情或主观记忆；名单外说话人的台词不收录。

特殊情形默认口径（作者可在拍板清单中另定口径）：

- **联合齐声 / 多人共誓**：默认逐人收录进各说话角色的候选台词，并分别登记台词出处。
- **无朗读情节的书面信文原文**：默认归写信者（存在朗读情节时仍归实际朗读角色）。

## 事件树五条红线

第 0 层通读抽事件与第 3 层搭事件树须同时守住五条语义结构红线：

1. **事件原子化（禁「A与B」拼盘）**：一事件只承载一件可独立判定发生/未发生的因果节点，禁把无关甲乙两事用「与/及/暨」硬捆拼盘（如晋升与成婚、学艺与宴会）；皆重要则拆成两件，其一为琐事则降格进档案或舍弃。
2. **准入门槛（禁前史与零变化日常硬升事件）**：出场前固定前史写进默认档案，不建历史事件；建事件前过三问至少中其一（① 触发 `变化` 或档案切期；② 下游重要事件/分支的真实因果前提；③ 玩家可能亲历或介入改写的高光事件），三者皆无的纯日常流水账不入树。
3. **真因果铁律（严分因果与时间先后）**：时间先后只靠 `触发时间`，绝不靠伪 `事件确认` 硬串；`世界`/`势力` 级事件禁止把主角个人日常小事当作硬门槛，保证停用核心角色或远离主线时宏观大事仍可运转。
4. **`确认策略` 三分法（禁全员盲写 `自动确认`）**：`自动确认` 仅留即便玩家不在场也会爆发的世界大事、政局变动、幕后暗线与历史锚点；长篇卡应大量用 `条件确认`（封卷照常补历史，游玩期须实际演到才确认，过窗自然排除），承接个人战斗、感情、拜师、社交及可绕开/截胡的遭遇；`仅作候选` 不参与封卷补历史，留给可选支线与彩蛋。
5. **`主类型` 归类与真实纪年精度**：按实际影响层归类 `主类型`，不把个人成长或家庭琐事误标 `势力`；原作未交代具体月日时结构纪年只写到年，严禁为凑先后顺序编造 `01月01日`。
