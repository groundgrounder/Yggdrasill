# 写作红线

十个作者 skill 共用本页速查。规范正本是 [`docs/写作规范.md`](../../docs/写作规范.md)；本页不复述正文，只留写作时最容易踩的四条红线。

## 越界

清单唯一出处在此。把本局状态写进文本就是越界。以下内容只由事件变化或写场景写入，文本一律不写，换个字段名承载同样越界：

关系、婚姻、家系、职位、资产、持有物、伤势、当前穿着、能力的取得与丧失、当前所在。

`check` 不判语义越界：状态断言可以零错误通过，须逐条人工核对。

## 条件文本五槽

改叙事条件、分支条件、介入条件、触发情境、触发限制之前，先写下五槽适用范围；改后逐槽对照，范围变了就退回原文，或把改动拆给结构级：

| 槽 | 问 |
|---|---|
| 对象 | 适用于哪些人 |
| 地点 | 在哪些地点成立 |
| 时间 | 在哪段时期成立 |
| 分支 | 在哪些分支下成立 |
| 触发情形 | 什么情形触发 |

`check` 与 `if` 都不判适用范围，这一项只能人工核对。

## 文本四问

每句话过四问：删去它，模型会不会出错；它是信息还是装饰；能否改成列表；不看原文能否读懂。只写会让模型出错的差异信息。

## 原台词归属

原台词逐字收进**实际说话角色**的角色位置候选台词，排在作者自拟台词之前；出处写进 `作者资料/出处/`，正文不标注。别人对他说的话写进他的角色知情或主观记忆；名单外说话人的台词不收录。

特殊情形默认口径（作者可在拍板清单中另定口径）：

- **联合齐声 / 多人共誓**：默认逐人收录进各说话角色的候选台词，并分别登记台词出处。
- **无朗读情节的书面信文原文**：默认归写信者（存在朗读情节时仍归实际朗读角色）。
