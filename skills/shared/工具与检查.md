# 工具与检查

十二个作者 skill 在世界树仓库内共用本页速查。命令行为、输出与错误码的正本见 [`docs/参考/命令.md`](../../docs/参考/命令.md)；本页只固定调用口径、最小检查矩阵与 `作者资料/` 标准子目录速查。

## 调用口径（任意创作项目目录均可执行）

优先 `ygg <命令>`（在克隆的 Yggdrasill 仓库执行 `npm ci && npm link` 后全局可用）；`ygg` 未入 `PATH` 时用 `node <世界树仓库>/cli/ygg.mjs <命令>`，`<世界书目录>` 与 `<项目目录>` 按当前工作目录（`cwd`）写路径，不要求在世界树代码仓库根执行。

打包：`ygg pack [项目目录] [--face <卡面文件>] [--prepare-only] [--compatible <64位指纹>]...`。项目目录与 `--face` 均相对 `cwd` 解析；省略项目目录时取当前目录，`--face` 缺省为 `<项目目录>/卡面.yaml`。

日常创作默认直接编辑真实项目目录；动手前确认项目有 git 或备份保护。只用一次性临时副本的两种情况：破坏性探测（如设定级反向清单探针——复制后删/改待改值跑 `check --static-only --json`，用完即弃），以及试验世界树仓库自带的 `examples/三国演义/` 示例。

## 命令

| 用途 | 调用 |
|---|---|
| 全量检查 | `ygg check <世界书目录> [--json]`（静态通过后执行抽样） |
| 上下文预览 | `ygg context <世界书目录> [--世界线 <世界线ID>] [--开局 <纪年>] [--方案 <方案ID>] [--本局 <本局JSON>] [--地点 <地标ID>] [--场景 <场景文本>] [--在场 <角色组ID>]... [--消息 <文本>]... [--不自动初始化] [--raw] [--json]` |
| 事件树与台词统计 | `ygg tree <世界书目录> [--out <文件路径>] [--stats-only] [--json]` |
| 项目诊断 | `ygg status [项目目录或世界书目录] [--json]` |
| 初始化 | `ygg init <项目目录> [--纪年前缀 <前缀>] [--年位数 <整数>] [--月数 <整数>] [--每月天数 <整数>] [--force] [--json]` |
| 静态检查 | `ygg check <世界书目录> --static-only [--json]` |
| 溯源 | `ygg trace <世界书目录> <对象键> [--json]` |
| 如果视图 | `ygg if <世界书目录> [--世界线 <世界线ID>] [--方案 <方案ID>] [--排除 <事件ID>]... [--分支 <事件ID>:<分支ID>]... [--停用角色组 <角色组ID>]... [--json]` |
| 初始化与状态预览 | `ygg preview <世界书目录> <角色组ID> [--世界线 <世界线ID>] [--开局 <纪年>] [--方案 <方案ID>] [--本局 <本局JSON>] [--状态] [--json]` |
| 排版 | `ygg format <世界书目录> [--check] [--write] [--json]` |
| 作者视图 | `ygg view [<世界书目录或角色卡文件> \| --worldbook <世界书目录> \| --card <角色卡文件>] [--storage <审阅存储目录>] [--port <端口>]` |
| 打包 | `ygg pack [项目目录] [--face <卡面文件>] [--prepare-only] [--compatible <64位指纹>]...` |
| 解包 | `ygg unpack <角色卡文件> -o <输出目录> [--force] [--json]` |

改前先跑一次，把已有错误与提示记作基线；改后同命令重跑，只对新增失败负责。没跑的检查不说通过。反映真实因果的跨级过渡提示（如 `事件.世界依赖个人`）允许保留并在复核清单中单列说明，不为凑“零提示”破坏真实因果；`事件.疑似拼盘` 与 `事件.世界事件含核心参与者` 提示应逐条排查处置。原台词与冻结原作原文的逐字核对不在 `ygg` 工具内自动读取原作，可由作者用一次性只读脚本比对 `作者资料/出处/` 与冻结原文完成人工核对。

## 最小检查矩阵

按阶段（建卡期出口门禁，细则见各 skill）：

| 层 | 出口检查 |
|---|---|
| 0 通读 | 不跑工具；门禁是覆盖完整、坐标可查、事件表红线与拼盘豁免通过、作者拍板 |
| 0 迁移（`世界树·迁移`） | 拆包完整、映射表 100% 覆盖原卡字段与条目、总账坐标可查、作者拍板 |
| 1 地基 | `check --static-only` |
| 2 条目 | `check --static-only` |
| 3 骨架 | 全量 `check`（含排查 `事件.疑似拼盘`/`事件.世界事件含核心参与者`）+ `if` + `preview`（另用 `view` 人工审树） |
| 4a/4b 档案、填景 | 全量 `check` + `format`（`--write` 后必重跑 `check`）+ `tree --stats-only` |
| 上下文校准（第 4 层收口/打包前） | `ygg context` 实测典型开局与多人拥挤场景上下文体量与预算审计，按需调优项目根 `yggdrasill.yaml` |
| 可选 前端（`世界树·前端`） | `theme-tool.mjs validate` 0 错误（核清未知键告警）+ 暗/亮/移动端离线预览零溢出 + `ygg pack` 验证世界书哈希不变 |
| 5 打包 | `ygg pack` 构建 + 产物四项核对（开场命令、构建清单、资料隔离、多方案导出） |
| 5.5 验收（大型卡推荐，`世界树·验收`） | 打包卡离线挂载 + 五维反原作剧本试玩（含 `bundle.themes` 外观核验）+ 起止只读哈希核对 + 问题三分法裁决 |

按改动级别（建成后修订，见 [`世界树·修订`](../ygg-edit/SKILL.md)）：外观级（`<项目目录>/外观/`）直接分流 `世界树·前端`；设定级 = `trace` / 临时副本反向清单 + 全量 `check` + 相关 `if`；结构级 = `trace` + 全量 `check` + 相关 `if` / `preview` + `format`；文本级 = `check` + `format`，纯文本改动不要求跑 `if` 对比。

## `作者资料/` 标准子目录速查

`作者资料/` 放在世界书之外，不进入上下文，也不随 `ygg pack` 打包：

| 子目录 | 用途 |
|---|---|
| `作者资料/通读/` | 第 0 层分卷坐标账本（`分卷/`）、`活词表.yaml` 与 5 份全局总账 |
| `作者资料/迁移/` | 原卡盘点方案、`迁移映射表.yaml` 与 `原卡开场白.yaml` |
| `作者资料/出处/` | 事件级（`事件ID`/`来源`）与台词级（`事件ID`/`角色组ID`/`台词`/`来源`）出处记录 |
| `作者资料/暂存/` | 已写好待接回世界书的内容（保留相对布局）及 `暂存/暂存清单.yaml`（接回后删项） |
| `作者资料/候选/` | 尚未定案的草案与结构缺口备忘，定案落盘世界书后移除 |
| `作者资料/归档/` | 撤下或废弃的内容，保留原世界书相对布局供回溯 |
| `作者资料/生成/` | 工具自动生成产物（如事件树导出），不手改 |
| `作者资料/审阅器/` | `ygg view` 缺省审阅存储目录（批注、布局与保存备份） |
