# 工具与检查

九个作者 skill 在世界树仓库内共用本页速查。命令行为、输出与错误码的正本见 [`docs/参考/命令.md`](../../docs/参考/命令.md)；本页只固定调用口径与最小检查矩阵。

## 调用口径（任意创作项目目录均可执行）

优先 `ygg <命令>`（在克隆的 Yggdrasill 仓库执行 `npm ci && npm link` 后全局可用）；`ygg` 未入 `PATH` 时用 `node <世界树仓库>/cli/ygg.mjs <命令>`，`<世界书目录>` 与 `<项目目录>` 按当前工作目录（`cwd`）写路径，不要求在世界树代码仓库根执行。

打包：`ygg pack [项目目录] [--face <卡面文件>] [--prepare-only] [--compatible <64位指纹>]...`。项目目录与 `--face` 均相对 `cwd` 解析；省略项目目录时取当前目录，`--face` 缺省为 `<项目目录>/卡面.yaml`。（旧入口 `node <世界树仓库>/adapter/build.mjs` 仍向后兼容，其中项目目录相对仓库根、`--face` 相对 `adapter/` 解析。）

日常创作默认直接编辑真实项目目录；动手前确认项目有 git 或备份保护。只用一次性临时副本的两种情况：破坏性探测（如设定级反向清单探针——复制后删/改待改值跑 `check --static-only --json`，用完即弃），以及试验世界树仓库自带的 `examples/三国演义/` 示例。

## 命令

| 用途 | 调用 |
|---|---|
| 全量检查 | `ygg check <世界书目录> [--json]`（静态通过后执行抽样） |
| 上下文预览 | `ygg context <世界书目录> [--世界线 <世界线ID>] [--开局 <纪年>] [--方案 <方案ID>] [--本局 <本局JSON>] [--地点 <地标ID>] [--场景 <场景文本>] [--在场 <角色组ID>]... [--消息 <文本>]... [--不自动初始化] [--raw] [--json]` |
| 事件树与台词统计 | `ygg tree <世界书目录> [--out <文件路径>] [--stats-only] [--json]` |
| 项目诊断 | `ygg status [项目目录或世界书目录] [--json]` |
| 初始化 | `ygg init <项目目录> [--纪年前缀 <前缀>] [--年位数 <整数>] [--月数 <整数>] [--每月天数 <整数>] [--force] [--json]` |
| 静态检查 | `ygg check <世界书目录> --static-only [--json]` |
| 溯源 | `ygg trace <世界书目录> <对象键> [--json]` |
| 如果视图 | `ygg if <世界书目录> [--世界线 <世界线ID>] [--方案 <方案ID>] [--排除 <事件ID>]... [--分支 <事件ID>:<分支ID>]... [--停用角色组 <角色组ID>]... [--json]` |
| 初始化与状态预览 | `ygg preview <世界书目录> <角色组ID> [--世界线 <世界线ID>] [--开局 <纪年>] [--方案 <方案ID>] [--本局 <本局JSON>] [--状态] [--json]` |
| 排版 | `ygg format <世界书目录> [--check] [--write] [--json]` |
| 作者视图 | `ygg view [<世界书目录> \| --worldbook <世界书目录>] [--storage <审阅存储目录>] [--port <端口>]` |
| 打包 | `ygg pack [项目目录] [--face <卡面文件>] [--prepare-only] [--compatible <64位指纹>]...` |

改前先跑一次，把已有错误与提示记作基线；改后同命令重跑，只对新增失败负责。没跑的检查不说通过。反映真实因果的跨级过渡提示（如 `事件.世界依赖个人`）允许保留并在复核清单中单列说明，不为凑“零提示”破坏真实因果。原台词与冻结原作原文的逐字核对不在 `ygg` 工具内自动读取原作，可由作者用一次性只读脚本比对 `作者资料/出处/` 与冻结原文完成人工核对。

### trace 对象键

| 类型 | 对象键写法 |
|---|---|
| 事件 | `事件:<ID>` |
| 事件串 | `事件串:<ID>` |
| 角色组 | `角色组:<ID>` |
| 档案 | `档案:<角色组ID>:<档案ID>` |
| 条目 | `条目:<库名>:<条目ID>` |
| 剧情标记 | `剧情标记:<ID>` |
| 世界线 | `世界线:<ID>` |
| 开局选项 | `开局选项:<序号>` |
| 开局方案 | `开局方案:<ID>` |

## 最小检查矩阵

按阶段（建卡期出口门禁，细则见各 skill）：

| 层 | 出口检查 |
|---|---|
| 0 通读 | 不跑工具；门禁是覆盖完整、坐标可查、作者拍板 |
| 1 地基 | `check --static-only` |
| 2 条目 | `check --static-only` |
| 3 骨架 | 全量 `check` + `if` + `preview`（另用 `view` 人工审树） |
| 4a/4b 档案、填景 | 全量 `check` + `format` |
| 5 打包 | `ygg pack` 构建 + 产物三项核对 |

按改动级别（建成后修订，见 [`世界树·修订`](../ygg-edit/SKILL.md)）：设定级 = 反向清单 + 全量 `check` + 相关 `if`；结构级 = `trace` + 全量 `check` + 相关 `if` / `preview`；文本级 = `check` + `format`，纯文本改动不要求跑 `if` 对比。
