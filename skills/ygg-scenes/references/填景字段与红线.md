# 填景字段与红线

本参考页供 `世界树·填景` 独立自包含查阅，覆盖事件与角色位置字段、候选 vs 已确认可见性隔离表、分支覆盖 vs 角色位置合并对比、状态字段分工、原台词细则与完整措辞/格式红线。

## 1. 事件正文与角色位置字段

### 事件级正文字段（`历史/事件/{事件ID}/事件.txt`，正文字数预算 800 字）

- 顶层文本：`事件标题`（省略等于事件ID）、`事件概要`（必填）、`影响范围`、`叙事条件`（条件文本）、`公开信息`（非空无重复单行列表）、`隐秘信息`（非空无重复单行列表）。
- 分支文本：`分支条件`（必填，条件文本）、`分支结果`（必填），以及可选的分支专属四字段：`事件概要`、`影响范围`、`公开信息`、`隐秘信息`。
- **中性命名与防剧透**：事件ID与标题用世界内中性短语，身份转变（如成为护卫、任职）写进变化表，不单建事件；静态正文不写确认状态与出处；`事件串` 的 `概述` 在进行中每轮常驻上下文，**严禁剧透结局**；**防回弹**：绝不把新增无关剧情顺手塞进既有事件的分支中。

### 角色位置与触发语料（`历史/事件/{事件ID}/角色/{角色组ID}.txt`，不能有表外键）

| 字段 | 必填 | 写法 |
|---|---|---|
| `事件ID` | 是 | 等于事件目录名 |
| `角色组ID` | 是 | 等于文件名（已有的角色组） |
| `角色概要` | 是 | 单行文本 |
| `角色定位` | 是 | 非空、无重复短语列表（禁句末标点） |
| `适用分支` | 否 | 非空、无重复分支ID列表（省略即全部分支） |
| `介入条件` | 否 | 单行文本（条件文本） |
| `角色知情` | 否 | 非空、无重复单行文本列表 |
| `主观记忆` | 否 | 非空、无重复单行文本列表 |
| `按分支` | 否 | 分支ID → `{角色知情, 主观记忆}`（分支ID须在 `适用分支` 内） |
| `事件触发语料` | 否 | 列表，子字段：`触发情境`(必填, 条件文本)、`候选台词`(必填, 非空无重复文本列表)、`表达目的`(否, 文本)、`情绪或语气`(否, 文本)、`触发限制`(否, 非空无重复条件文本列表) |

## 2. 候选 vs 已确认可见性隔离表（关键防剧透）

路由根据事件有效状态严格隔离字段，写错字段会导致候选期缺触发线索或提前剧透：

| 对象 / 字段 | **候选阶段**（尚未发生） | **已确认经历 / 待登记**（已发生） | 常见错位禁忌 |
|---|---|---|---|
| 事件顶层 `事件概要`/`影响范围`/`公开信息` | 输出 | 输出（若所走分支未覆写） | 严禁把事件结局剧透进顶层 `公开信息` |
| 事件顶层 `叙事条件`、可用分支 `分支ID`/`分支条件`/`分支结果` | 输出（仅门槛成立的分支） | `分支结果` 输出；`叙事条件`/`分支条件` 不输出 | — |
| 事件 `隐秘信息` | **不输出** | 输出（若所走分支未覆写） | 绝不把触发前置线索塞进 `隐秘信息` |
| **事件分支专属四字段**（`事件概要`/`影响范围`/`公开信息`/`隐秘信息`） | **不输出** | **覆盖顶层同名字段（不拼接）** | 未声明才回退顶层；避免 IF 分支回顾串主线 |
| 角色位置 `角色定位`/`介入条件`/`事件触发语料` | 输出（仅在场者，且**`适用分支` 须与可用分支有交集**） | 仅输出 `角色概要`/`角色定位`（不输出 `介入条件`/`事件触发语料`） | 严禁把结果剧透进 `角色定位`/`介入条件` |
| 角色位置 `角色知情`/`主观记忆`（及 `按分支`） | **不输出** | 输出（仅在场者，**`按分支` 与外层合并追加**） | **严禁把触发线索错放 `角色知情`**；严禁把成功分支记忆写进失败分支 |

- **机制对比务必牢记**：
  - **事件分支专属四字段**：**覆盖**事件顶层同名字段，**不拼接**；
  - **角色位置 `按分支` 的 `角色知情` / `主观记忆`**：与外层 `角色知情` / `主观记忆` **合并追加**，不覆盖外层共用部分。

## 3. 状态字段分工表（防重复与防爆预算）

| 内容性质 | 存放字段 | 上下文特征与去重规则 |
|---|---|---|
| 与势力挂钩的职务 | 变化表 `职位` | 随在场角色本局状态每轮输出 |
| 与势力无关的社会身份（如“外乡人”） | 变化表 `身份` | 随在场角色本局状态每轮输出 |
| 会影响以后行为的长期事实 | 变化表 `知识` | **每轮必入上下文，不受经历预算限制**——只收影响后续行为的长期事实；**已写入 `知识` 的事实，`角色知情` 不再重复** |
| 全局剧情开关与分支条件 | 变化表 `剧情标记` | 随世界当前状态每轮输出 |
| 当事人记得的经过与主观感受 | 角色位置 `主观记忆` | 仅已确认经历选入且在场时输出 |
| 只与本次事件相关的局部知情/误判 | 角色位置 `角色知情` | 仅已确认经历选入且在场时输出；角色知道/猜测不等于世界事实已成立 |

## 4. 原台词归属、细则与出处

- **归属与排序**：原台词逐字收进**实际说话角色**的角色位置 `候选台词`，排在作者自拟台词之前；出处写进 `作者资料/出处/*.yaml`（`{事件ID, 角色组ID, 台词, 来源}`），**静态正文不写确认状态与出处**。别人对他说的话写进他的 `角色知情` 或 `主观记忆`；名单外说话人的台词不收录。
- **不造同义词与不单证事实**：**原作已有适用台词时，不另写同义台词**；台词**不能单独确认事实**（台词涉及的事实须已在事件正文或已确认结果中）；仅在原作无适用台词（新增分支、未覆盖情境、扩展角色）时由作者撰写，并符合当期档案表达规律。
- **原台词检查豁免**：已登记在 `作者资料/出处/` 台词记录中的逐字原台词，**破折号按原文保留**（检查器仅提示不报错），且**豁免 `文本.写法` 陈旧写法提示**。
- **特殊情形默认口径**（作者可在拍板清单另定）：
  - **联合齐声 / 多人共誓**：逐人收录进各说话角色的 `候选台词`，并分别登记台词出处；
  - **无朗读情节的书面信文原文**：归写信者（存在朗读情节时归实际朗读角色）。
- 原台词与冻结原作原文的逐字核对不在 `ygg` 工具自动范围内，可由作者用一次性只读脚本比对 `作者资料/出处/` 与 `来源资料/` 完成核对。

## 5. 条件文本五槽、越界清单与完整措辞/格式红线

- **条件文本五槽**：改 `叙事条件`、`分支条件`、`介入条件`、`触发情境`、`触发限制` 之前，先写下五槽适用范围；改后逐槽对照，范围变了就退回原文，或拆给结构级处理（`check` 与 `if` 均不判适用范围）：
  `对象`（适用于哪些人）、`地点`（在哪些地点成立）、`时间`（在哪段时期成立）、`分支`（在哪些分支下成立）、`触发情形`（什么情形触发）。
- **越界清单**：文本一律不写 `关系、婚姻、家系、职位、资产、持有物、伤势、当前穿着、能力的取得与丧失、当前所在`。
- **文本四问**：删去它，模型会不会出错；它是信息还是装饰；能否改成列表；不看原文能否读懂。
- **全部 25 个 `文本.禁用词`（出现即报错）**：
  `stat_data`、`变量`、`schema`、`索引`、`路由`、`ID`、`状态0`、`状态1`、`状态2`、`状态0/1/2`、`候选事件`、`额外模型`、`冲突队列`、`条目`、`注册`、`挂载`、`加载`、`目录`、`记录规则`、`目录规则`、`统一格式`、`登记规则`、`引用边界`、`记录边界`、`维护`。
- **全部 9 个 `文本.写法` 陈旧写法提示词（非原台词命中即提示）**：
  `似乎`、`几乎`、`仿佛`、`如同`、`宛如`、`嘴角微微上扬`、`眼中闪过一丝`、`心湖泛起涟漪`、`万念俱灰`。
- **格式硬规**：非原台词严禁 U+2014/U+2015 破折号（报 `文本.破折号`）；严禁单独成行的包裹标签（报 `目录.包裹标签`）；单行文本字段严禁换行；`短语列表`（如 `角色定位`）禁句末标点（`。！？；`）。
- **常用与校准命令**：
  - `ygg check <世界书目录>`、`ygg format <世界书目录> --check`、`ygg tree <世界书目录> --stats-only`；
  - 上下文校准：`ygg context <世界书目录> --方案 <方案ID> --地点 <地标ID> --在场 <角色组ID>...`（按审计结果调优项目根 `yggdrasill.yaml`）。
- 完整参考见本地 Yggdrasill 仓库 `docs/参考/事件.md` 与 `docs/写作规范.md`。
