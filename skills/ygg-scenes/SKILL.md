# 世界树·填景

本 skill 是建卡第 4b 层：横向写事与摘台词，两遍读法的第二遍在此落地。骨架锁定后，按卷/事件从第 0 层坐标精准回查 `作者资料/通读/分卷/` 与 `来源资料/` 原文行号。候选 vs 已确认可见性隔离表、分支覆盖 vs 角色位置合并对比、状态字段分工、原台词细则与完整禁用词/陈旧写法清单见 [`./references/填景字段与红线.md`](./references/填景字段与红线.md)。

## 步骤

优先使用 `ygg <命令>`（未链接 `ygg` 到 `PATH` 时改用 `node <世界树仓库>/cli/ygg.mjs <命令>`）：

1. 按卷/事件排期分批推进：回查原文行号，补实 `事件概要`、`公开信息`、`隐秘信息`、条件文本（`叙事条件`、`分支条件`）、`分支结果` 及按需补写分支专属四字段（`事件概要`/`影响范围`/`公开信息`/`隐秘信息`）。严守**候选可见性防剧透**（不把结果剧透进顶层 `公开信息`）与**防回弹**（绝不把新增无关剧情顺手塞进既有事件分支）；同步复核 `事件串` 的 `概述` 绝不剧透结局、事件名保持中性（身份转变写进变化表不单建事件）。每批跑过 `ygg check` 与 `ygg format --check` 即落盘，支持跨会话续跑；阶段汇报写明“已完成数 / 总数”与下批起点。
2. 补实角色位置（`历史/事件/{事件ID}/角色/{角色组ID}.txt`）：`角色概要`、`角色定位`、`介入条件`、`角色知情`、`主观记忆`、`按分支`、`事件触发语料`；知情与记忆须与所适用分支一致。严守候选/已确认隔离：触发线索放 `介入条件`/`触发情境`（**严禁错放 `角色知情`**，候选期不输出 `角色知情`），结局结果不剧透进 `角色定位`/`介入条件`。去重取舍：`知识` 每轮常驻上下文不受经历预算限制，只收影响后续行为的长期事实且不与 `角色知情` 重复。
3. **逐字摘录原台词**：按坐标从原文逐字抄入**实际说话角色**的 `候选台词`，排在作者自拟台词之前；同步写台词级 `作者资料/出处/` 记录（含 `事件ID`、`角色组ID`、`台词`、`来源`），静态正文不标注确认状态与出处。**原作已有适用台词时不另写同义台词**；台词不能单独确认事实（涉及事实须已在事件正文或已确认结果中）；原作没有适用台词时才自拟，且须符合当期档案表达规律。
4. 按需润色第 2 层留简的条目正文。

## 出口门禁

- 全量 `ygg check <世界书目录>` 0 新增错误。
- `ygg format <世界书目录> --check` 检查通过，或 `--write` 整理后复跑 `check`。
- **台词覆盖与上下文校准**：
  - `ygg tree <世界书目录> --stats-only` 核查原台词占比与缺台词位置；
  - `ygg context <世界书目录> --方案 <方案ID> --地点 <地标ID> --在场 <角色组ID>...` 实测典型开局与多人拥挤场景的上下文体量与预算审计，按需调优项目根 `yggdrasill.yaml`（`经历`/`候选`/`在场角色`/`条目字符`/`提及窗口`）。
- 人工复核有记录：条件文本五槽逐条对照、候选/已确认可见性防剧透核对、越界清单逐条读过、每句原台词的说话人归属核对过。
- 拍板收口：引导模式停下等作者拍板后收口本层；自动模式按统筹传入口径推进，非阻塞项取保守方案记入待复核清单。

门禁通过后呈报：产出摘要（已补实事件数、摘录台词数）+ 检查与上下文校准结果 + 人工复核记录 + 待拍板项 + 下一步建议（可选进入 `世界树·前端` 定制 `<项目目录>/外观/`，再进入 `世界树·打包`）。
