# 世界树·填景

本 skill 是建卡第 4b 层：横向写事与摘台词，两遍读法的第二遍在此落地。骨架锁定后，按卷/事件从第 0 层坐标精准回查 `作者资料/通读/分卷/` 与 `来源资料/` 原文行号。事件字段见 [`docs/参考/事件.md`](../../docs/参考/事件.md)；条件文本与台词规则见 [`docs/写作规范.md`“事件”](../../docs/写作规范.md#事件)；越界与五槽速查见 [`../shared/写作红线.md`](../shared/写作红线.md)；命令口径见 [`../shared/工具与检查.md`](../shared/工具与检查.md)。

## 步骤

1. 按卷/事件排期分批推进：回查原文行号，补实 `事件概要`、`公开信息`、`隐秘信息`、条件文本与 `分支结果`。每批跑过 `check` 与 `format` 即落盘，支持跨会话续跑；阶段汇报写明“已完成数 / 总数”与下批起点。
2. 补实角色位置：角色定位、介入条件、角色知情、主观记忆、事件触发语料；知情与记忆须与所适用的分支一致。去重取舍：`角色知情` 只写本角色视角独有的知情差异、误判或行动约束，事件变化表 `知识` 或 `事件概要` 已承载的公共结果留在事件侧，不在 `角色知情` 中复述。
3. **逐字摘录原台词**：归属与排序规则见 [`../shared/写作红线.md#原台词归属`](../shared/写作红线.md#原台词归属)——按坐标从原文逐字抄入实际说话角色的 `候选台词`，排在作者自拟台词之前；同步写台词级 `作者资料/出处/` 记录，字段规范见 [`docs/参考/世界书.md#出处记录`](../../docs/参考/世界书.md#出处记录)。原作没有适用台词时才自拟，且须符合当期档案的表达规律。
4. 按需润色第 2 层留简的条目正文。

## 出口门禁

- 全量 `ygg check <世界书>` 0 新增错误。
- `ygg format <世界书>` 检查通过，或 `--write` 整理后复跑 `check`。
- 补实后可用 `ygg tree <世界书> --stats-only` 查看台词覆盖统计（原台词占比与缺台词位置），用 `ygg context <世界书> --地点 <地标ID> --在场 <角色组ID>...` 预估上下文体量；两者均只读。
- 人工复核有记录：条件文本五槽逐条对照、越界清单逐条读过、每句原台词的说话人归属核对过。
- 拍板收口：引导模式停下等作者拍板后收口本层；自动模式按统筹传入口径推进，非阻塞项取保守方案记入待复核清单。

门禁通过后呈报：产出摘要（已补实事件数、摘录台词数）+ 检查结果 + 人工复核记录 + 待拍板项 + 下一步建议（进入 [`世界树·打包`](../ygg-pack/SKILL.md)）。
