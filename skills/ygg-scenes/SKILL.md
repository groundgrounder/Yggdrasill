# 世界树·填景

本 skill 是建卡第 4b 层：横向写事与摘台词，两遍读法的第二遍在此落地。骨架锁定后，按卷/事件从第 0 层坐标精准回查 `作者资料/通读/分卷/` 与 `来源资料/` 原文行号。事件与角色位置字段、条件文本五槽、原台词归属与出处规范见 [`./references/填景字段与红线.md`](./references/填景字段与红线.md)。

## 步骤

优先使用 `ygg <命令>`（未链接 `ygg` 到 `PATH` 时改用 `node <世界树仓库>/cli/ygg.mjs <命令>`）：

1. 按卷/事件排期分批推进：回查原文行号，补实 `事件概要`、`公开信息`、`隐秘信息`、条件文本（`叙事条件`、`分支条件`）与 `分支结果`。每批跑过 `ygg check` 与 `ygg format --check` 即落盘，支持跨会话续跑；阶段汇报写明“已完成数 / 总数”与下批起点。
2. 补实角色位置（`历史/事件/{事件ID}/角色/{角色组ID}.txt`）：`角色概要`、`角色定位`、`介入条件`、`角色知情`、`主观记忆`、`按分支`、`事件触发语料`；知情与记忆须与所适用的分支一致。去重取舍：`角色知情` 只写本角色视角独有的知情差异、误判或行动约束，事件变化表 `知识` 或 `事件概要` 已承载的公共结果留在事件侧，不在 `角色知情` 中复述。
3. **逐字摘录原台词**：按坐标从原文逐字抄入**实际说话角色**的 `候选台词`，排在作者自拟台词之前；同步写台词级 `作者资料/出处/` 记录（含 `事件ID`、`角色组ID`、`台词`、`来源`）。原作没有适用台词时才自拟，且须符合当期档案的表达规律。
4. 按需润色第 2 层留简的条目正文。

## 出口门禁

- 全量 `ygg check <世界书目录>` 0 新增错误。
- `ygg format <世界书目录> --check` 检查通过，或 `--write` 整理后复跑 `check`。
- 补实后可用 `ygg tree <世界书目录> --stats-only` 查看台词覆盖统计（原台词占比与缺台词位置），用 `ygg context <世界书目录> --地点 <地标ID> --在场 <角色组ID>...` 预估上下文体量；两者均只读。
- 人工复核有记录：条件文本五槽逐条对照、越界清单逐条读过、每句原台词的说话人归属核对过。
- 拍板收口：引导模式停下等作者拍板后收口本层；自动模式按统筹传入口径推进，非阻塞项取保守方案记入待复核清单。

门禁通过后呈报：产出摘要（已补实事件数、摘录台词数）+ 检查结果 + 人工复核记录 + 待拍板项 + 下一步建议（进入 `世界树·打包`）。
