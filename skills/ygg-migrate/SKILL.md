# 世界树·迁移

本 skill 与第 0 层 `世界树·通读` 并列，是“既有酒馆角色卡或世界书迁入世界树”的前置阶段。本层不写 `世界书/`，只产出确定性拆包目录、`作者资料/迁移/` 对账材料，以及与第 0 层完全同构的 `作者资料/通读/` 五份全局总账，供下游按 `世界树·地基 → 条目 → 骨架 → 档案 → 填景 → 打包` 无缝建卡。

字段映射细则、三类原卡处置策略与红线清单见 [`./references/概念映射与拆解规则.md`](./references/概念映射与拆解规则.md)。

## 执行步骤

### 1. 拆包取证

运行随本目录附带的零依赖拆包脚本（支持单份或多份输入，如 1 张角色卡加多份独立世界书）：

```sh
node ./scripts/unpack-card.mjs <原卡或世界书文件...> -o <项目目录>/来源资料/原卡拆包
```

读取产出的 `manifest.json`、`greetings.md` 与 `lorebook/index.json`，判定原卡形态（轻量单角/小群像卡、长篇多期 EJS 卡、MVU 强系统数值卡），核对条目总数、启停状态与六项动态特征标记（`hasEjs`、`hasMvu`、`hasTavernHelper`、`hasRegexScripts`、`hasHtmlUi`、`isMultiCharacter`）。

**完成标准**：原卡全部核心字段、开场白、世界书条目与扩展脚本均已完整落盘无截断；`manifest.json` 的输入列表、计数与特征标记已逐项核对。

### 2. 全量盘点与方案拍板

通读 `card-core.md`、`lorebook/index.json`、关键条目正文及 `scripts/`（若有正则或变量定义），产出 `作者资料/迁移/原卡盘点与方案.md`，包含：

- **全量去向分类**：逐项标明**保留迁移 / 结构改写 / 明确弃用**（含理由），杜绝静默丢弃；
- **最小合规默认方案**：针对原卡缺失的世界树必填结构（如纪年、事件树、地点树）给出最小合法默认方案，不擅自脑补扩写；
- **待作者拍板分岔**：列出需裁决项（如多个 `alternate_greetings` 是否映射为多个开局方案、是否需要补原作设定或严格忠实原卡零扩写、停用条目是否纳入）。

**完成标准**：每类核心字段与全部世界书条目均已分类定性；引导模式下停下等作者拍板后才进入第 3 步；自动模式按忠实原卡的最小保守方案落盘，并将未决分岔全部写入待复核清单。

### 3. 拆解提取与归并总账

对照 [`./references/概念映射与拆解规则.md`](./references/概念映射与拆解规则.md) 分批读取 `lorebook/entries/` 正文，清洗旧脚本语法与宏残片，产出三类产物：

1. **`作者资料/通读/` 下五份与第 0 层同构的全局总账**（坐标统一写 `原卡拆包/<相对路径>:L起-L止`）：
   - `世界体系汇总.yaml`
   - `人物总名单与分期方案.yaml`
   - `全书年表与因果事件表.yaml`
   - `if分岔与开局提案.yaml`
   - `待作者拍板清单.md`
2. **`作者资料/迁移/迁移映射表.yaml`**：原卡每个核心字段、每条已启用与已停用世界书条目及扩展脚本的 100% 全量台账（记录源坐标、去向世界树层与目标对象，或弃用及理由）。
3. **`作者资料/迁移/原卡开场白.yaml`**：保留 `first_mes` 与 `alternate_greetings` 的原索引映射与清洗后纯正文（去除 HTML 状态栏、`<UpdateVariable>` 与旧变量标签），供第 5 层 `世界树·打包` 直接复用。

**完成标准**：五份全局总账、`迁移映射表.yaml` 与 `原卡开场白.yaml` 全部落盘；原卡全部核心字段与世界书条目 100% 在 `迁移映射表.yaml` 有去向记录；待迁设定正文零 EJS/HTML/MVU 语法与 `{{user}}`/`{{char}}` 宏残片；口癖、关系、隐秘设定、`mes_example` 表达习惯与特殊装备等有效细节零静默删减。

### 4. 出口门禁与交接下游

逐项复核后呈报：

1. **全量覆盖**：`迁移映射表.yaml` 条目总数与 `lorebook/index.json` 严格一致，无漏条；
2. **忠实度**：无未经拍板的擅自扩写；由 `mes_example` 提炼的表达规律与参考台词已标明来源为 `原卡 mes_example`，不冒充原作逐字原台词；
3. **坐标回查**：总账与映射表中的 `原卡拆包/<相对路径>:L起-L止` 坐标均可精准回查。

门禁通过后呈报：迁移摘要（原卡形态、条目总数、保留/改写/弃用计数）、弃用项清单、待拍板清单与下一步建议——进入 `世界树·地基`（或交 `世界树·统筹` 按 `1→2→3→4a/4b→5` 连续完成构建、检查与打包）。
