# 声明与写作要点

本参考页供 `世界树·地基` 独立自包含查阅，涵盖 `世界书/设定/` 全部 9 份声明文件契约、7 种字段声明写法、`yggdrasill.yaml` 9 项运行参数、单一来源红线与完整措辞/ID 禁区。

## 1. 命令口径

- 优先 `ygg <命令>`；未入 `PATH` 时用 `node <世界树仓库>/cli/ygg.mjs <命令>`。
- 初始化：`ygg init <项目目录> [--纪年前缀 <前缀>] [--年位数 <整数>] [--月数 <整数>] [--每月天数 <整数>] [--force] [--json]`
- 静态检查：`ygg check <世界书目录> --static-only [--json]`
- 需要查看完整默认值或参考表时，读取本地 Yggdrasill 仓库的 `defaults/设定/` 与 `docs/参考/世界书.md`、`docs/参考/角色.md`。

## 2. 设定声明清单（`世界书/设定/*.yaml`）

`世界书/设定/` 只放 `.yaml` 文件：

| 文件 | 必需条件 | 关键结构与校验边界 |
|---|---|---|
| `纪年.yaml` | **无条件必写** | `前缀`（无首尾空白文本）、`年位数`（1–11）、`月数`（1–99）、`每月天数`（1–99 整数或长度等于月数的整数列表），不能有其它键。支持纪元前写法 `{前缀}前{年}年[MM月DD日]`，**严禁 `前000年`**；事件时间写到年或写到日，**严禁写到月** |
| `事件分类.yaml` | **无条件必写** | `主类型`、`世界事件`（可选，取主类型之一）、`标签`、`事件结果`（结果名 → 支撑字段列表，可为 `[]`）。合法支撑字段来源：一层骨架角色/世界字段、能力维度、二层角色字段、`剧情标记`、保留支撑名 `档案切期`。声明 `世界事件` 主类型后，检查器会启用 `事件.世界依赖个人` 与 `事件.世界事件含核心参与者` 提示 |
| `本局变量.yaml` | **无条件必写** | `词表`（首个值为默认值；**无论本卡有无装备库，都无条件必写 `词表.装备状态`**，缺即报 `设定.本局变量`）、`角色`（必填映射）、`世界`（可选映射）、`单次增减上限`（可选正整数，缺省 `100`）。字段名**不得与一层骨架**（角色：`在场`/`所在`/`装备`/`能力移除记录`/`已初始化`；世界：`当前时间`/`当前地点`/`剧情标记`）或能力维度重名；默认模板中的 `职位` 依赖 `势力` 库，无 `势力` 库时须删改 |
| `等级.yaml` | 声明等级维度或引用 `等级.*` 时 | `{序列名}` → 非空、无重复等级列表（从低到高） |
| `能力.yaml` | 有 `技能` 库或引用 `能力.*` 时 | `维度` 与 `技能可用` **两键均必填**（详见第 3 节） |
| `条目库.yaml` | 有公共条目库时 | 库名 → `{分法, 分级(按种类必填), 上级类型(按上下级可选), 字段}` |
| `剧情标记.yaml` | 有剧情标记时 | `{标记ID}` → 非空、无重复取值列表（首项为开局初值） |
| `角色分类.yaml` | **有角色组时必写** | `角色包`、`分类` 两个非空无重复列表 |
| `文本规范.yaml` | 可选（第五层） | `禁用词`、`ID命名`、`档案追加字段`、`长度预算`（**只收紧不放宽第四层**，详见第 4 节） |

## 3. 字段声明写法与 `能力.yaml` 细则

### 7 种字段写法、3 种修饰、5 种值域、5 种文本形态

每个字段声明**恰好使用下列 7 种写法之一**（多写或漏写报 `设定.字段声明`）：

| 写法 | 适用范围 | 说明 |
|---|---|---|
| `形态: <文本形态>` | 条目库、本局变量、档案追加字段 | 第四层文本字段 |
| `取值: <值域>` | 同上 | 第三层限定取值 |
| `引用: <库名 / 角色组 / 事件>` | 同上 | 第三层引用已存在对象 ID |
| `子字段: {子键: 声明, ...}` | 同上 | 固定子键映射（非空） |
| `映射: {键: 声明, 值: 声明}` | 同上 | 键任意、结构相同的字典 |
| `数值: [下限, 上限]` | **仅用于本局变量** | 整数范围（下限 ≤ 上限），结果截断在区间内 |
| `集合: <成员声明>` | **仅用于本局变量** | 无序不重复成员，只允许逐项 `新增`/`移除` |

- **3 种修饰**：`必填`（布尔）；`列表`（布尔，**仅用于 `取值` 或 `引用`**）；`适用类型`（类型列表，**仅用于条目库**，须引用本库单值行内列表字段 `类型`）。
- **5 种值域**：行内列表（非空无重复）、`等级.<序列名>`、`能力.<等级映射维度名>`、`词表.<词表名>`、`纪年`。
- **5 种文本形态**：
  1. `文本`：非空单行文本（**严禁换行**）；
  2. `文本列表`：非空无重复单行文本列表；
  3. `短语列表`：每项短语**禁止以 `。！？；` 等句末标点结尾**；
  4. `情境列表`：每项为单键映射 `情境: 表现`；
  5. `禁区列表`：每项**必须以“不”开头**。

### `能力.yaml` 三种维度与 `技能可用` 规则

- **三种维度键要求**：
  - `等级映射`：必填 `类型`、`等级`（等级序列名）、`键`（非空无重复列表，或 `键组名 → 键列表` 分组映射且键跨组不重复）；
  - `单值等级`：必填 `类型`、`等级`，可选 `综合实力`（布尔，**整卡至多一个单值等级维度写 `综合实力: true`**，供 `在场实力人数` 条件使用）；
  - `集合`：必填 `类型`、`成员`（写作 `文本`，或 `{条目库: 库名, 条件: {字段: 值}}`，`条件` 可选非空）。
- **`技能可用` 两种规则**（有 `技能` 库时每条技能**必须恰好适用 1 条规则**）：
  - `等级门槛`：必填 `适用`（非空技能字段匹配映射）、`规则: 等级门槛`、`维度`（等级映射维度）、`键字段`、`等级字段`，可选 `键组`；
  - `集合持有`：必填 `适用`、`规则: 集合持有`、`维度`（集合维度）。

## 4. `文本规范.yaml` 与 `yggdrasill.yaml` 精确契约

### `设定/文本规范.yaml`（4 项可选键）

- `禁用词`：追加禁用词列表，命中即报错误 `文本.禁用词`。
- `ID命名`：命名空间 → 规则映射。合法命名空间仅限：`全部`、`角色组ID`、`版本ID`、`档案ID`、`剧情标记ID`、`能力键`、`事件ID`、`{库名}ID`；`只用中文: true` 可用于全部合法命名空间；`前缀字段: <本库字段>` **仅适用于 `{库名}ID`** 且须引用本库已声明字段（要求 ID 写作 `字段值·名称`）。
- `档案追加字段`：`基本信息` 或 `角色印象` → 新增可选字段映射，**不能与第四层既有字段重名，且严禁设 `必填: true`**。
- `长度预算`：仅允许以下 4 个键，取值须为正整数且**不得大于第四层默认上限**（只能收紧不能放宽）：
  - `同名说明`: 上限 `300`
  - `基本信息`: 上限 `500`
  - `角色印象`: 上限 `600`
  - `事件`: 上限 `800`

### 项目根 `yggdrasill.yaml`（9 项运行参数）

顶层**只能含 `运行参数` 一个键**，取值均须为**非负整数**，未知键报错误 `运行参数.格式`：

```yaml
运行参数:
  经历:
    条数: 6
    字符: 3000
  候选:
    条数: 4
    字符: 4000
  在场角色:
    完整人数: 6
    字符: 12000
  条目字符:
    默认: 1500
    # 可按已声明条目库名单独覆写：<库名>: <非负整数>
  提及窗口: 2
```

## 5. 拆分粒度、单一来源与设计边界

- **单一来源红线**：第二层的种类、等级、关系阶段、可写字段与地点清单只在 `设定/` 与条目库中声明一次；**世界概况、扮演准则、条目说明文件与作者资料一律不复述这些清单**（打包时由模板占位符自动生成给模型）。
- **单主题与单一品类**：`世界概况/` 与 `扮演准则/` 按单一独立主题分文件，不为压文件数拼出“A与B”多主题文件（两者每轮全量进入上下文，总篇幅保持克制）；自定义条目库一库只收同一类、共享字段结构的公共对象，不把异质主题硬拼成杂烩库。
- **能力维度选型边界**：`等级映射` 仅收世界内通用且真实按该等级序列评定的门类；个别角色的独创招式、无统一评阶的秘技或禁术、先天异能与体质天赋走 `集合` 维度（配合 `集合持有` 规则）或写进档案 `能力特征`，不硬套等级序列造伪阶位。
- **扮演准则视角兼容**：本卡 `扮演准则/` 默认以玩家当前在场视角叙述，兼容自建玩家与扮演任意角色组，不锁死单一原作主角视角（仅刻意限定单主角卡除外）。

## 6. 越界清单、完整禁用词与 ID 安全红线

- **越界清单**：把本局状态写进文本就是越界。以下内容只由事件变化或写场景写入，文本一律不写，换个字段名承载同样越界：
  `关系、婚姻、家系、职位、资产、持有物、伤势、当前穿着、能力的取得与丧失、当前所在`。
- **文本四问**：每句话过四问——删去它，模型会不会出错；它是信息还是装饰；能否改成列表；不看原文能否读懂。只写会让模型出错的差异信息。
- **全部 25 个 `文本.禁用词`（出现即报错，含 `.txt` 正文与 `.yaml` 可见展示字段）**：
  `stat_data`、`变量`、`schema`、`索引`、`路由`、`ID`、`状态0`、`状态1`、`状态2`、`状态0/1/2`、`候选事件`、`额外模型`、`冲突队列`、`条目`、`注册`、`挂载`、`加载`、`目录`、`记录规则`、`目录规则`、`统一格式`、`登记规则`、`引用边界`、`记录边界`、`维护`（注意 `维护`、`目录`、`条目`、`加载` 等极易在日常行文中误踩）。
- **破折号与包裹标签硬禁**：
  - 全文严禁使用 U+2014（`—`）与 U+2015（`―`）破折号（非原台词出现即报错 `文本.破折号`）；
  - 源文件严禁出现单独成行的包裹标签（如 `<世界概况>`、`</协议>`，触发错误 `目录.包裹标签`），包裹标签由路由渲染时统一添加。
- **ID 一层字符安全规则**：全部 ID 非空、首尾无空白、不含 `.` `/` `\`，且严禁使用 4 个保留字 `玩家`、`__proto__`、`constructor`、`prototype`。
