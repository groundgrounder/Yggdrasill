# 声明与写作要点

## 命令口径

- 优先 `ygg <命令>`；未入 `PATH` 时用 `node <世界树仓库>/cli/ygg.mjs <命令>`。
- 初始化：`ygg init <项目目录> [--纪年前缀 <前缀>] [--年位数 <整数>] [--月数 <整数>] [--每月天数 <整数>] [--force] [--json]`
- 静态检查：`ygg check <世界书目录> --static-only [--json]`
- 需要查看完整默认值或参考表时，读取本地 Yggdrasill 仓库的 `defaults/设定/` 与 `docs/参考/世界书.md`、`docs/参考/角色.md`。

## 设定声明清单

`世界书/设定/` 只放 `.yaml` 文件：

| 文件 | 必需条件 | 关键结构 |
|---|---|---|
| `纪年.yaml` | 必写 | `前缀`（无首尾空白文本）、`年位数`（1–11）、`月数`（1–99）、`每月天数`（1–99 整数或长度等于月数的整数列表），不能有其它键 |
| `事件分类.yaml` | 必写 | `主类型`、`世界事件`（可选，取主类型之一）、`标签`、`事件结果`（结果名 → 支撑字段列表） |
| `本局变量.yaml` | 必写 | `词表`（首个值为默认值；有装备须含 `装备状态`）、`单次增减上限`（按需）、`角色`、`世界` |
| `等级.yaml` | 引用了等级序列时 | `{序列名}` → 非空、无重复等级列表（从低到高） |
| `能力.yaml` | 有技能库或引用能力时 | `维度`（等级映射 / 单值等级 / 集合）与 `技能可用`（等级门槛 / 集合持有规则列表），两键都必填 |
| `条目库.yaml` | 有公共条目库时 | 库名 → `{分法, 分级(按种类), 上级类型(按上下级), 字段}` |
| `剧情标记.yaml` | 有剧情标记时 | `{标记ID}` → 非空、无重复取值列表（首项为开局初值） |
| `角色分类.yaml` | 有角色组时 | `角色包`、`分类` 两个非空无重复列表 |
| `文本规范.yaml` | 可选 | `禁用词`、`ID命名`、`档案追加字段`、`长度预算`（只收紧不放宽第四层） |

## 拆分粒度与设计边界

- **单主题与单一品类**：`世界概况/` 与 `扮演准则/` 按单一独立主题分文件，不为压文件数拼出“A与B”多主题文件（两者每轮全量进入上下文，拆细为求清晰，总篇幅仍须克制）；自定义条目库一库只收同一类、共享字段结构的公共对象，不把异质主题硬拼成杂烩库，以免字段失焦与预算互挤。
- **能力维度选型边界**：`等级映射` 仅收世界内通用且真实按该等级序列评定的门类；个别角色的独创招式、无统一评阶的秘技或禁术、先天异能与体质天赋走 `集合` 维度（配合 `技能可用` 的 `集合持有` 规则）或写进档案 `能力特征`，不硬套等级序列造伪阶位（避免污染角色面板与自建开局表单）。
- **扮演准则视角兼容**：第一层模板已按“当前视角能感知的内容”与玩家模式中立约束；本卡 `扮演准则/` 默认以玩家当前在场视角叙述，兼容自建玩家与扮演任意角色组，不锁死单一原作主角视角（仅在刻意设计单主角限定卡时才显式锁定）。

## 越界清单与文本四问

- **越界清单**：把本局状态写进文本就是越界。以下内容只由事件变化或写场景写入，文本一律不写，换个字段名承载同样越界：
  `关系、婚姻、家系、职位、资产、持有物、伤势、当前穿着、能力的取得与丧失、当前所在`。
- **文本四问**：每句话过四问——删去它，模型会不会出错；它是信息还是装饰；能否改成列表；不看原文能否读懂。只写会让模型出错的差异信息。
- **措辞硬禁**：`.txt` 文本不得含 `stat_data`、`变量`、`schema`、`索引`、`路由`、`ID`、`状态0/1/2`、`候选事件`、`条目`、`注册`、`挂载`、`加载`、`目录` 等系统视角词与 U+2014/U+2015 破折号。
