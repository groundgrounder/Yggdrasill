# 世界树·地基

本 skill 是建卡第 1 层：基于第 0 层拍板后的总账，立第二层声明与全局文风。读取 `作者资料/通读/世界体系汇总.yaml` 与 `作者资料/通读/待作者拍板清单.md`。声明完整字段写法、运行参数键名、单一来源原则与完整禁用词清单见 [`./references/声明与写作要点.md`](./references/声明与写作要点.md)。

## 步骤

优先使用 `ygg <命令>`（未链接 `ygg` 到 `PATH` 时改用 `node <世界树仓库>/cli/ygg.mjs <命令>`）。

新项目可用 `ygg init <项目目录> [--纪年前缀 <前缀>] [--年位数 <整数>] [--月数 <整数>] [--每月天数 <整数>]` 生成分层骨架与最小声明（开箱即过 `check --static-only`）；已有目录则按下述步骤改写（可从已克隆或安装的本地 Yggdrasill 仓库 `defaults/设定/` 复制默认 `事件分类.yaml` 与 `本局变量.yaml` 作为起点）：

1. 在 `世界书/设定/` 按总账写入本卡声明：
   - **无条件必需**：`纪年.yaml`、`事件分类.yaml`、`本局变量.yaml`（注意：`本局变量.yaml` **无论本卡有无装备库，都必须声明 `词表.装备状态`**，缺即报错误 `设定.本局变量`；复制默认 `本局变量.yaml` 时若无 `势力` 库须删改默认的 `职位` 字段）；
   - **按需必需**：`等级.yaml`（引用等级序列时）、`能力.yaml`（有技能库或引用能力时）、`条目库.yaml`（有公共条目库时）、`剧情标记.yaml`（有剧情标记时）、**`角色分类.yaml`（有角色组时必写，缺即报 `设定.缺少文件`）**、`文本规范.yaml`（可选，只收紧不放宽第四层）。
2. 建 `世界书/世界概况/`：整个可游玩时期都成立的公共世界背景（体系、格局、纪年），按单一独立主题分文件（`.txt`，单主题一文件，不为压文件数把多个独立主题硬拼成“A与B”拼盘；概况每轮全量进入上下文，总篇幅保持克制）；多世界线卡若某世界线需要专属背景，可另建 `世界书/世界概况/世界线/{世界线ID}/*.txt`（路由按所选世界线追加在公共概况之后，共享同一概况时不必建此目录）。
3. 建 `世界书/扮演准则/`：按单一独立主题分文件（`.txt`），写叙述人称、对白比例、文风偏好与本卡写入约束；视角约定默认兼容自建玩家与扮演任意角色组（以玩家当前在场视角叙述，不把视角锁死在单一原作主角身上，除非本卡刻意限定单主角）。严守**单一来源**原则：正文、说明文件、扮演准则与作者资料一律不复述 `设定/` 的种类与取值清单（打包时由模板自动生成）。
4. 按需建项目根 `yggdrasill.yaml` 运行参数（只含 `运行参数` 一个顶层键，9 项合法键与默认值见参考页，未知键或非负整数之外的值会报 `运行参数.格式`）。

每步完成标准：文件落盘且与本卡一致——纪年取自总账，事件分类覆盖总账中全部事件原子，能力与条目库覆盖第 2、3 层将引用的种类；世界概况与扮演准则不触犯越界清单、禁用词与破折号禁令。

## 出口门禁

- `ygg check <世界书目录> --static-only` 0 错误（此时尚未建条目、角色与事件属正常，声明与目录合法即通过）。
- 规则与文风拍板收口：引导模式停下等作者拍板等级序列、能力维度、条目库清单、剧情标记取值与扮演准则要点；自动模式按统筹传入口径取保守方案，记入待复核清单。

门禁通过后呈报：产出摘要（声明清单 + 概况/准则文件）+ 检查结果 + 待拍板项 + 下一步建议（进入 `世界树·条目`）。
