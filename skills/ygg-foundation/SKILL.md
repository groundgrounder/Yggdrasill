# 世界树·地基

本 skill 是建卡第 1 层：基于第 0 层拍板后的总账，立第二层声明与全局文风。读取 `作者资料/通读/世界体系汇总.yaml` 与 `作者资料/通读/待作者拍板清单.md`。声明写法正本见 [`docs/01-世界书.md`“声明”](../../docs/01-世界书.md#声明) 与 [`docs/参考/世界书.md`“声明文件”](../../docs/参考/世界书.md#声明文件)；文本写法见 [`docs/写作规范.md`“文本”](../../docs/写作规范.md#文本)，红线速查见 [`../shared/写作红线.md`](../shared/写作红线.md)；命令口径见 [`../shared/工具与检查.md`](../shared/工具与检查.md)。

## 步骤

新项目可先用 `ygg init <项目目录> [--纪年前缀 <前缀>] [--年位数 <整数>] [--月数 <整数>] [--每月天数 <整数>]` 生成分层骨架与最小声明（开箱即过 `check --static-only`），已有目录则直接按下述步骤改写：

1. 复制 [`defaults/设定/`](../../defaults/设定/) 的默认声明进 `世界书/设定/`，按总账改写：
   - 必需：`纪年.yaml`、`事件分类.yaml`、`本局变量.yaml`；
   - 按需：`等级.yaml`、`能力.yaml`、`条目库.yaml`、`剧情标记.yaml`、`角色分类.yaml`、`文本规范.yaml`。
2. 建 `世界书/世界概况/`：整个可游玩时期都成立的世界背景（体系、格局、纪年），按主题分文件。
3. 建 `世界书/扮演准则/`：叙述人称、对白比例、文风偏好与本卡写入约束。
4. 按需建项目根 `yggdrasill.yaml` 运行参数。

每步完成标准：文件落盘且与本卡一致——纪年取自总账，事件分类覆盖总账中全部事件原子，能力与条目库覆盖第 2、3 层将引用的种类。

## 出口门禁

- `ygg check <世界书> --static-only` 0 错误（此时尚未建条目、角色与事件属正常，声明与目录合法即通过）。
- 规则与文风拍板收口：引导模式停下等作者拍板等级序列、能力维度、条目库清单、剧情标记取值与扮演准则要点；自动模式按统筹传入口径取保守方案，记入待复核清单。

门禁通过后呈报：产出摘要（声明清单 + 概况/准则文件）+ 检查结果 + 待拍板项 + 下一步建议（进入 [`世界树·条目`](../ygg-entries/SKILL.md)）。
