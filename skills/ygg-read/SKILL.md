# 世界树·通读

本 skill 是建卡第 0 层，也是两遍读法的第一遍：先把原作读透、立坐标账本，归并出全局总账；本层不动 `世界书/`。两遍读法：第一遍在本层（分批 Map 抽坐标 + Reduce 消歧归并）；第二遍在第 4a/4b 层按坐标回查原文精写与摘台词。

## 路径 A：长篇原作

1. **备料**：核对 `来源资料/` 中的分卷/分章纯文本，缺文本先向作者取得并冻结版本；与作者定覆盖范围（收哪些卷章）与切分粒度。完成标准：来源文本就位，范围有作者确认。
2. **分批 Map**：每次读 1 卷或 3–5 章，产出 `作者资料/通读/分卷/第XX卷.yaml`，固定抽 6 张结构表，每条记录必带 `卷/章:起止行` 坐标：
   1. 时间与地点轨迹（含地点上下级）；
   2. 体系与规则碎片（等级、能力、势力、重要技能装备、边界）；
   3. 人物轨迹与状态变动（含别名/称号与疑似切期节点）；
   4. 事件原子（发生了什么、缺谁不行、真正因果前置、结果）；
   5. 名场面与台词坐标索引（说话人 + 情境 + 原文起止行号 + 锚点首句；不搬全量台词）；
   6. 跨卷伏笔与 if 分岔种子。
   顺序推进时同步维护几 KB 的 `作者资料/通读/活词表.yaml`，统一译名与称谓，防前后漂移；超长篇可分卷并行 Map，Reduce 时统一消歧。
   **Map 每批完成标准**：批次内每章零遗漏扫描；6 张表每条结构记录带 `卷/章:起止行` 坐标（路径 B 用大纲编号）；本批分卷账本落盘、`活词表.yaml` 同步更新后，才进入下一批。落盘即存档，天然支持断点续跑。
3. **Reduce 消歧归并**：全部卷读完（或并行批次收齐）后归并去重，输出 `作者资料/通读/` 下 5 份全局总账：
   - `世界体系汇总.yaml`（**不设人为条目总数上限**；区分“世界通则概览”与“可独立持有、习得或寻址的单一原子对象”，将具体地点、势力、技能、装备拆回单件列出，不把笔记里的多物/多技归纳项当作第 2 层条目槽位）
   - `人物总名单与分期方案.yaml`
   - `全书年表与因果事件表.yaml`
   - `if分岔与开局提案.yaml`
   - `待作者拍板清单.md`
   **Reduce 完成标准**：覆盖范围内全部分卷账本已合拢；跨卷别名/化名已消歧；5 份全局总账全部产出，每个未决裁决都进入 `待作者拍板清单.md`；完成三项出口自检——①跨卷/跨回先验词全量倒查（允许范围边界声明白名单，0 混入未读卷章人物/地名/剧情）；②分卷表 1–4/6 与 5 份全局总账的坐标-内容全量回查（0 越界、0 错章错行）；③`活词表.yaml` 主表合入完整性校验（全部批次词条写入主体字典、计数与各批增量之和一致、0 占位句残留）。

## 路径 B：原创世界 / 大纲设定集

经作者访谈补齐设定后，直接产出同构的 5 份全局总账；无原文行号时以大纲条目编号代坐标。

## 出口门禁

- 覆盖范围完整：范围内每卷每章都有账本记录；跨卷/跨回先验词全量倒查通过（除范围边界声明白名单外，0 混入未读卷章人物/地名/剧情）。
- 坐标与词表全量回查通过：分卷表 1–4/6 与 5 份全局总账的坐标-内容全量回查 0 越界、0 错章错行；`活词表.yaml` 主表完整合入全部批次词条，计数与各批增量之和一致、0 占位句残留。
- 拍板收口：引导模式停下等作者拍板名单、分期方案与体系取值；自动模式按统筹传入口径取保守方案，记入待复核清单。未决项全部列入 `待作者拍板清单.md`。

门禁通过后呈报：产出摘要（卷数、人物数、事件原子数、总账清单）+ 待拍板清单 + 下一步建议（进入 `世界树·地基`）。
