# 世界树·通读

本 skill 是建卡第 0 层，也是两遍读法的第一遍：先把原作读透、立坐标账本，归并出全局总账；本层不动 `世界书/`。两遍读法：第一遍在本层（分批 Map 抽坐标 + Reduce 消歧归并）；第二遍在第 4a/4b 层按坐标回查原文精写与摘台词。

## 路径 A：长篇原作

1. **备料**：核对 `来源资料/` 中的分卷/分章纯文本，缺文本先向作者取得并冻结版本；与作者定覆盖范围（收哪些卷章）与切分粒度。完成标准：来源文本就位，范围有作者确认。
2. **分批 Map**：每次读 1 卷或 3–5 章，产出 `作者资料/通读/分卷/第XX卷.yaml`，固定抽 6 张结构表，每条记录必带 `卷/章:起止行` 坐标：
   1. 时间与地点轨迹（含地点上下级）；
   2. 体系与规则碎片（等级、能力、势力、重要技能装备、边界）；
   3. 人物轨迹与状态变动（含出生年如有、初始所在、两字及以上别名/称号——**禁用单字别名**、角色包/分类线索与疑似切期节点）；
   4. **事件原子**：一事件只记一件可独立判定的因果节点，严禁把无关甲乙两事硬捆成拼盘——逐条过 **4 条机械一票否决拆分测试**（① **反事实独立成败测试**：A 发生而 B 不发生/走另一分支是否成立？成立必拆；② **核心参与者正交测试**：拆开能否减少任一方核心参与者？能少人必拆；③ **跨日/跨地拆分铁律**：不同日或不同地的两事禁合写，过程改用事件串；④ **单焦点分支测试**：概要/结果含“先……随后……/同时完成另一事”且可独立分岔的必拆）。出场前固定前史归入角色默认档案不入事件表；拟入表事件须过**三问**至少中其一（触发 `变化` 或档案切期 / 下游真实因果前提 / 玩家可亲历改写的高光节点）。每条显式记录：
      - 发生了什么、**事件地点**、**缺谁不行的最小化 `核心参与者`**（任一核心参与者未启用即直接排除整个事件，绝不塞入旁观者/路人；**世界事件通常留空 `[]`，个人后果另拆事件**）；
      - **是否世界事件 / 个人后果**、**是否触发档案切期**、**是否关键多分支分岔点**；
      - 真正因果前置（时间先后只靠 `触发时间` 纪年，不把章节先后写成伪因果）、影响层 `主类型`、建议 `确认策略`（`自动确认`/`条件确认`/`仅作候选`）与结果；
      - 纪年精度：原作未交代具体月日时只写到年，严禁编造 `01月01日`（同一年内若前置事件精确到日，须注明起点比较陷阱，交第 3 层按年末日或同精度处理）；
   5. 名场面与台词坐标索引（说话人 + 情境 + 原文起止行号 + 锚点首句；不搬全量台词）；
   6. 跨卷伏笔与 if 分岔种子。
   顺序推进时同步维护几 KB 的 `作者资料/通读/活词表.yaml`，统一译名与称谓，防前后漂移；超长篇可分卷并行 Map，Reduce 时统一消歧。
   **Map 每批完成标准**：批次内每章零遗漏扫描；6 张表每条结构记录带 `卷/章:起止行` 坐标（路径 B 用大纲编号）；本批分卷账本落盘、`活词表.yaml` 同步更新后，才进入下一批。落盘即存档，天然支持断点续跑。
3. **Reduce 消歧归并**：全部卷读完（或并行批次收齐）后归并去重，输出 `作者资料/通读/` 下 5 份全局总账：
   - `世界体系汇总.yaml`（**不设人为条目总数上限**；区分“世界通则概览”与“可独立持有、习得或寻址的单一原子对象”，将具体地点、势力、技能、装备拆回单件列出，不把笔记里的多物/多技归纳项当作第 2 层条目槽位）
   - `人物总名单与分期方案.yaml`（逐角色组列出：出生年如有、初始所在、别名（**禁用单字**）、角色包/分类建议、是否多版本、分期方案与切期触发事件、建议 `初始化方式`（`显式确认` 或 `出场自动`））
   - `全书年表与因果事件表.yaml`（逐条落实事件树五条红线 + **4 条机械拆分测试** + **核心参与者最小化与世界事件留空 `[]`、个人后果另拆**：剔除前史与三问皆不中的零变化日常流水账、严分时间先后与真因果且宏观大事不硬绑个人日常、逐件标明事件地点/是否世界事件或个人后果/是否切期/是否多分支分岔点与建议 `确认策略` 三分法分类不盲全标 `自动确认`、核对 `主类型` 影响层并保持缺月日只写到年不编造 `01月01日`，同一年前置精确到日的标注交第 3 层按年末日或同精度处理）
   - `if分岔与开局提案.yaml`
   - `待作者拍板清单.md`
   **Reduce 完成标准**：覆盖范围内全部分卷账本已合拢；跨卷别名/化名已消歧；5 份全局总账全部产出，每个未决裁决都进入 `待作者拍板清单.md`；完成三项出口自检——①跨卷/跨回先验词全量倒查（允许范围边界声明白名单，0 混入未读卷章人物/地名/剧情）；②分卷表 1–4/6 与 5 份全局总账的坐标-内容全量回查（0 越界、0 错章错行）；③`活词表.yaml` 主表合入完整性校验（全部批次词条写入主体字典、计数与各批增量之和一致、0 占位句残留）。

## 路径 B：原创世界 / 大纲设定集

经作者访谈补齐设定后，直接产出同构的 5 份全局总账；无原文行号时以大纲条目编号代坐标。

## 出口门禁

- 覆盖范围完整：范围内每卷每章都有账本记录；跨卷/跨回先验词全量倒查通过（除范围边界声明白名单外，0 混入未读卷章人物/地名/剧情）。
- 坐标与词表全量回查通过：分卷表 1–4/6 与 5 份全局总账的坐标-内容全量回查 0 越界、0 错章错行；`活词表.yaml` 主表完整合入全部批次词条，计数与各批增量之和一致、0 占位句残留。
- 事件表红线与拼盘豁免自检通过：`全书年表与因果事件表.yaml` 通过 4 条机械拆分测试，**对仍含并列连接词（如「与/及/暨/并/兼/、」等）的条目逐条写出“不可分割单一互动专名”豁免理由，否则拆分后才放行**；无出场前固定前史或三问皆不中的零变化日常流水账；`核心参与者` 最小化且世界事件默认留空 `[]`、个人后果已拆出；真因果与时间先后分离、已按三分法标明建议 `确认策略`、`主类型` 归类准确且缺月日仅写到年（无编造 `01月01日`）。
- 拍板收口：引导模式停下等作者拍板名单、分期方案与体系取值；自动模式按统筹传入口径取保守方案，记入待复核清单。未决项全部列入 `待作者拍板清单.md`。

门禁通过后呈报：产出摘要（卷数、人物数、事件原子数、总账清单）+ 拼盘豁免明细（如有）+ 待拍板清单 + 下一步建议（进入 `世界树·地基`）。
