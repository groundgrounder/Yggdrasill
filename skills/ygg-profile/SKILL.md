# 世界树·档案

本 skill 是建卡第 4a 层：纵深写人，两遍读法的第二遍在此落地。第 3 层出口门禁通过、骨架锁定后，按人物与时期把占位档案壳精写为高质量正文。读取 `作者资料/通读/人物总名单与分期方案.yaml` 与 `作者资料/通读/分卷/`，按第 0 层坐标回查 `来源资料/` 原文。档案字段表、越界清单与文本四问见 [`./references/档案字段与红线.md`](./references/档案字段与红线.md)。

## 步骤

优先使用 `ygg <命令>`（未链接 `ygg` 到 `PATH` 时改用 `node <世界树仓库>/cli/ygg.mjs <命令>`）：

1. 按总账的分期方案排人物与时期，按人物/时期分批推进：逐份从第 0 层坐标回查该人物当期段落原文。每批跑过 `ygg check <世界书目录>` 与 `ygg format <世界书目录> --check` 即落盘，支持跨会话续跑；阶段汇报写明“已完成数 / 总数”与下批起点。
2. 精写 `基本信息.txt`：身份与外观只写当期已确立的事实；稳定体貌写遮住名字也能认出的特征；出生年不确定时省略，不编造。
3. 精写 `角色印象.txt`：核心身份、行为准则、价值优先、表达规律、通用反应、关系表现、表现禁区，逐栏填实。
4. 逐份自检三条：严格当期视角，只写该时期开始前与进行中已确立的事实；用行为与画面代替主观标签；表达规律可辨识——拿到一句台词，能据它判断像不像这个人。

骨架漏掉的本局状态记入 `作者资料/候选/`，交给事件与场景承载（勿写入文本）。

## 出口门禁

- `ygg check <世界书目录>` 相对改动前基线无新增错误。
- `ygg format <世界书目录> --check` 通过，或 `--write` 整理后复跑 `check`。
- 越界与串期人工核对有记录：每份档案对照红线清单读过一遍，核对结论写进阶段汇报。
- 拍板收口：引导模式停下等作者拍板后收口本层；自动模式按统筹传入口径推进，非阻塞项取保守方案记入待复核清单。

门禁通过后呈报：产出摘要（已精写档案数 / 总档案数）+ 检查结果 + 越界与串期核对记录 + 待拍板项。
