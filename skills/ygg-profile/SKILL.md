# 世界树·建角色

本 skill 从作者资料新写两份档案正文：`基本信息.txt` 与 `角色印象.txt`。世界书内只改这两份档案；档案目录、档案项、适用版本、生效条件与初始值归“角色”或“建立”。字段见 [`docs/参考/角色.md`“基本信息”](../../docs/参考/角色.md#基本信息) 与 [`docs/参考/角色.md`“角色印象”](../../docs/参考/角色.md#角色印象)，写法见 [`docs/写作规范.md`“档案”](../../docs/写作规范.md#档案)；越界与公共检查见 [`../shared/编辑分级.md`](../shared/编辑分级.md)。

## 1. 读资料、分栏与基线

1. 读作者资料中的角色材料，确认这份档案的时期与当期视角。
2. 按 shared 的越界清单分栏：稳定事实与行为方式归档案；越界事实归状态事实。
3. 状态事实逐条写进 `作者资料/候选/`，每条写明建议去向：事件变化、角色组元数据、条目或场景。候选只在本步写一次。
4. 在临时副本上工作，记录输入哈希；按 shared 跑 `check --static-only --json` 与 `format --check --json`，保存基线；记录 `角色组.yaml` 的哈希。

完成标准：材料已分栏；每条状态事实都在候选文件中有唯一一条记录与建议去向；输入哈希、检查基线与 `角色组.yaml` 哈希已保存。

## 2. 确认骨架与范围

1. 确认档案目录与档案项已经存在；写了版本的角色组还要有适用版本。缺骨架时停下，交给“角色”或“建立”。
2. 不改结构字段、表外键或档案项；本次世界书内只准备修改两份文本文件。
3. 核对 `角色组.yaml` 的哈希，确认它不在改动范围。

完成标准：档案骨架存在；本次只改两份文本文件；`角色组.yaml` 不在改动范围。

## 3. 写基本信息

1. 按字段表写姓名、性别、种族、出身与稳定体貌；出生年按纪年写，资料不足时省略，不编造。
2. 稳定体貌只写遮住名字也能认出的特征；穿着习惯写场合偏好，不写当前穿着。
3. 能力特征写个人差异与技能补充，不写当前能力、已学技能名单或综合实力。
4. 本步写下的每一句都回到第 1 步的分栏找依据；越界写法按 shared 处理。

完成标准：必填字段齐全；本步每句都有分栏依据；越界事实没有写进档案。

## 4. 写角色印象

1. 核心身份写这一时期最稳定的身份感；行为准则写可执行的处事顺序；价值优先按冲突时的胜负排序。
2. 表达规律只写与常规叙述口吻不同的部分；自称与称呼、句式、语气变化、场合差异、内外差、口头特征按资料归位。
3. 通用反应写具体情境与做法；关系表现只写行为方式，不用数值或频率；表现禁区每条以“不”开头。
4. 完整台词不写进档案；原台词归入事件角色位置，本 skill 只保留行为与说话方式。

完成标准：角色印象的必填字段齐全；每条表达规律都能让读者判断一句台词像不像这个角色；本步每句都有分栏依据。

## 5. 检查、人工复核与交接

1. 按 shared 跑 `check` 与 `format`，与基线比较；只把本次新增问题列为问题。
2. 复核 `角色组.yaml` 的哈希没有变化；用逐行 `diff` 确认世界书内只有两份档案变化。
3. 人工复核越界：逐条读出两份档案中涉及状态事实的写法并确认没有；`check` 不判定这一项，核对结果写进报告。
4. 把候选清单交给“角色”或“事件”，由结构级 skill 决定是否写成事件变化。

完成标准：检查无新增问题；世界书内只有两份档案变化；越界人工复核逐条有结论；候选清单已交接。

## 6. 报告

写明角色组、档案ID、时期、资料来源、两份档案的改动、候选事实与去向、人工复核记录、检查结果，以及未解决项。

完成标准：报告能按档案ID复核两份文本；未解决项写明位置与是否影响本次范围。
