# 档案字段与红线

## 基本信息（`基本信息.txt`）

档案中不写 `档案ID`，也不写“N岁”（出现“N岁”时提示）。以下字段表属第四层，第五层只能在 `设定/文本规范.yaml` 的 `档案追加字段` 中追加可选字段；正文字数预算 500 字。

| 字段 | 必填 | 写法 |
|---|---|---|
| `姓名` | 是 | 文本 |
| `称号` | 否 | 短语列表（不以句末标点结尾） |
| `性别` | 是 | 文本 |
| `出生年` | 否 | 按纪年书写（不确定时省略） |
| `种族` | 是 | 文本 |
| `出身` | 是 | 文本 |
| `稳定体貌` | 是 | 子字段，至少写一项：`发色发型`(文本)、`瞳色`(文本)、`体型`(文本)、`特征`(短语列表) |
| `穿着习惯` | 否 | 文本列表 |
| `能力特征` | 是 | 子字段，两项都必填：`特征`(文本列表，可写 `[]`)、`技能补充`(列表，可写 `[]`，每项含 `技能ID` 及 `个体表现` / `个体限制` 至少一项) |

## 角色印象（`角色印象.txt`）

以下字段都属第四层，建议条数超出范围时只提示；正文字数预算 600 字。

| 字段 | 必填 | 写法 | 建议条数 |
|---|---|---|---|
| `核心身份` | 是 | 短语列表 | 1–3 |
| `行为准则` | 是 | 文本列表 | 2–4 |
| `价值优先` | 是 | 短语列表，从高到低 | 2–4 |
| `表达规律` | 是 | 子字段，至少写一项：`自称与称呼`(文本)、`句式`(文本列表)、`语气变化`(情境列表)、`场合差异`(情境列表)、`内外差`(文本列表)、`口头特征`(短语列表，每项不超过 8 字) | |
| `通用反应` | 是 | 情境列表（单键映射：`情境: 表现`） | 2–5 |
| `关系表现` | 否 | 情境列表，针对具名角色时，键写第二层关系阶段与场合 | 1–5 |
| `表现禁区` | 是 | 禁区列表（每项以“不”开头） | 1–4 |

## 越界清单与文本四问

- **越界清单**：把本局状态写进文本就是越界。以下内容只由事件变化或写场景写入，文本一律不写，换个字段名承载同样越界：
  `关系、婚姻、家系、职位、资产、持有物、伤势、当前穿着、能力的取得与丧失、当前所在`。
  `check` 不判语义越界，须逐份人工对照。
- **文本四问**：每句话过四问——删去它，模型会不会出错；它是信息还是装饰；能否改成列表；不看原文能否读懂。只写会让模型出错的差异信息。
- **检查命令**：`ygg check <世界书目录> [--json]`、`ygg format <世界书目录> --check`（需统一排版时先确认差异再 `--write`）。
- 完整参考见本地 Yggdrasill 仓库 `docs/参考/角色.md` 与 `docs/写作规范.md`。
