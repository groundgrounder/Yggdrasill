# 档案字段与红线

本参考页供 `世界树·档案` 独立自包含查阅，覆盖 `基本信息.txt` 与 `角色印象.txt` 逐字段精写细则、切期与共享/镜像档案纪律、在场拥挤降级机制与完整措辞/格式红线。

## 1. 基本信息（`基本信息.txt`，正文字数预算 500 字）

档案中不写 `档案ID`，也不写年龄（**`档案.年龄` 提示同时拦截阿拉伯数字与中文数字，如“18岁”“二十岁”**）。以下字段属第四层，第五层只能在 `设定/文本规范.yaml` 的 `档案追加字段` 中追加可选字段。**可选字段无内容时一律整键省略（仅 `能力特征.特征` 与 `能力特征.技能补充` 例外，可写 `[]`）**。

| 字段 | 必填 | 写法与逐字段精写细则 |
|---|---|---|
| `姓名` | 是 | 单行文本 |
| `称号` | 否 | 短语列表（禁句末标点）；只写本时期对外使用的称号/名号，**没有就整键省略，严禁写“无”** |
| `性别` | 是 | 单行文本 |
| `出生年` | 否 | 按纪年书写；只有模糊范围或不确定时省略，不编造 |
| `种族` | 是 | 单行文本（一句话，补充放括号） |
| `出身` | 是 | 单行文本（一句话，补充放括号；身份转变与经历交给事件） |
| `稳定体貌` | 是 | 子字段，至少写一项：`发色发型`(文本)、`瞳色`(文本)、`体型`(文本)、`特征`(短语列表)。只写遮住名字也能认出、偏离默认印象的特征，不写“精致/白皙”等泛词；各时期体貌变化写入各自档案 |
| `穿着习惯` | 否 | 文本列表；写“在什么场合偏好穿什么、为什么”，**偏好不等于当前穿着或持有**；涉及专属装备须写“持有并使用某物时……” |
| `能力特征` | 是 | 子字段，两项都必填：`特征`(文本列表，可写 `[]`)、`技能补充`(列表，可写 `[]`，每项含 `技能ID` 及 `个体表现`/`个体限制` 至少一项)。写个人天赋、体质与当期施法/出手限制；**严禁写当前能力等级、已学技能名单、综合实力或公共技能正文**；写了 `技能补充` 不等于已掌握该技能（路由仅在该技能对本角色可用时才输出对应项） |

## 2. 角色印象（`角色印象.txt`，正文字数预算 600 字）

**核心红线：严禁在档案中写完整台词！** 档案每轮进入上下文，写进档案的完整台词会被模型反复机械套用；完整台词只放入事件角色位置的 `事件触发语料.候选台词`。

| 字段 | 必填 | 写法与逐字段精写细则 | 建议条数 |
|---|---|---|---|
| `核心身份` | 是 | 短语列表（禁句末标点）；本时期最稳定的身份感（“形容词+身份”），不放亲密倾向或一次性处境 | 1–3 |
| `行为准则` | 是 | 文本列表；写可执行的处事顺序，不写“善良/冷静”等空泛评价 | 2–4 |
| `价值优先` | 是 | 短语列表，从高到低排序，冲突时前者胜出 | 2–4 |
| `表达规律` | 是 | 子字段，至少写一项：`自称与称呼`(文本)、`句式`(文本列表)、`语气变化`(情境列表，**只写怎么说**)、`场合差异`(情境列表)、`内外差`(文本列表)、`口头特征`(短语列表，**每项超过 8 字直接报错误 `档案.形态`**)。**禁空泛评价词**（“温柔/冷淡/礼貌”须落到具体说法）；资料缺失自称/句式时在 `作者资料/` 列待补，绝不编造 | |
| `通用反应` | 是 | 情境列表（单键映射 `情境: 表现`），**只写做什么**（与 `语气变化` 写怎么说分工明确）；仅属于某一次事件的反应写进该事件角色位置 | 2–5 |
| `关系表现` | 否 | 情境列表；针对具名角色或亲密关系时，键写第二层关系阶段与场合，**严禁用好感度等数值作条件**；**键只描述条件，不声明双方现状**；同一对象的言行写在同一条不重复；值写具体触发与收起情境，**不用“偶尔/有时”等频率词**；亲密场景写主动性、态度与节奏，**保留成年与自愿前提** | 1–5 |
| `表现禁区` | 是 | 禁区列表（每项必须以“不”开头）；写模型最容易写歪的具体方向，通用规则归 `扮演准则/` 不在每份档案重复 | 1–4 |

## 3. 切期原则、共享/镜像档案纪律与拥挤降级重点

- **切期原则**：仅当**核心身份、行为准则、价值优先或稳定体貌**发生明显改变（如流亡前后、婚后、身份公开前后）才另开档案；单纯能力成长或装备变化由事件写入本局，不另开档案。每个版本通常 **1–4 份**档案，超过时在作者资料说明理由。
- **共享档案 vs 镜像档案修改纪律**：
  - **共享档案**（`适用版本` 含多个版本）：改一处即对全部适用版本生效；若只想改单一版本，必须先拆为独立镜像档案；
  - **镜像档案**（不同版本同一时期的独立档案）：改其中一份时，须逐栏比对另一份对应字段——原本相同的考虑是否同步，原本不同的属版本差异勿覆盖。
- **在场拥挤降级机制（写实重点提示）**：当在场人数超出 `在场角色.完整人数`（默认 6）或字符预算（默认 12000）时，路由按「玩家 > 最近提及 > 码点序」逐人降级：
  - **`精简` 态**：档案**仅保留 `基本信息` 的 `姓名`/`称号`/`性别`/`种族` 与 `角色印象` 的 `核心身份`/`表现禁区`**（其余印象字段全部略去）；
  - **`最小` 态**：仅保留身份、年龄与本局状态，不输出档案正文。
  - 因此 `核心身份` 与 `表现禁区` 是最底线的定调锚点，务必高度凝练、直击防 OOC 要害。

## 4. 越界清单、完整禁用词、陈旧写法与格式硬规

- **越界清单**：把本局状态写进文本就是越界。以下内容只由事件变化或写场景写入，文本一律不写，换个字段名承载同样越界：
  `关系、婚姻、家系、职位、资产、持有物、伤势、当前穿着、能力的取得与丧失、当前所在`（`check` 不判语义越界，须逐份人工对照）。
- **文本四问**：删去它，模型会不会出错；它是信息还是装饰；能否改成列表；不看原文能否读懂。
- **全部 25 个 `文本.禁用词`（出现即报错）**：
  `stat_data`、`变量`、`schema`、`索引`、`路由`、`ID`、`状态0`、`状态1`、`状态2`、`状态0/1/2`、`候选事件`、`额外模型`、`冲突队列`、`条目`、`注册`、`挂载`、`加载`、`目录`、`记录规则`、`目录规则`、`统一格式`、`登记规则`、`引用边界`、`记录边界`、`维护`。
- **全部 9 个 `文本.写法` 陈旧写法提示词**：
  `似乎`、`几乎`、`仿佛`、`如同`、`宛如`、`嘴角微微上扬`、`眼中闪过一丝`、`心湖泛起涟漪`、`万念俱灰`。
- **格式硬规**：
  - 严禁 U+2014/U+2015 破折号（报 `文本.破折号`）；
  - 严禁单独成行的包裹标签（如 `<在场角色>`，报 `目录.包裹标签`）；
  - 单行文本字段（`文本`、`文本列表` 项、`短语列表` 项）严禁换行；`短语列表` 禁句末标点（`。！？；`）；`禁区列表` 须以“不”开头；`口头特征` 超 8 字报错误。
- **检查命令**：`ygg check <世界书目录> [--json]`、`ygg format <世界书目录> --check`（需统一排版时先确认差异再 `--write` 并复跑 `check`）。
- 完整参考见本地 Yggdrasill 仓库 `docs/参考/角色.md` 与 `docs/写作规范.md`。
