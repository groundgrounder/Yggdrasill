# 世界树·条目

本 skill 是建卡第 2 层：铺公共条目库的舞台。读取 `作者资料/通读/世界体系汇总.yaml`，对照 `世界书/设定/条目库.yaml`。条目与说明文件的写法正本见 [`docs/写作规范.md`“条目”](../../docs/写作规范.md#条目)；库声明见 [`docs/参考/世界书.md`“条目库声明”](../../docs/参考/世界书.md#条目库声明)；本局状态清单唯一出处见 [`../shared/写作红线.md#越界`](../shared/写作红线.md#越界)；命令口径见 [`../shared/工具与检查.md`](../shared/工具与检查.md)。

## 步骤

1. 按 `设定/条目库.yaml` 逐库铺设：地点按上下级建树，势力/技能/装备/自定义库按声明的分级建目录；每条一个 `.txt`，文件名即 ID。
2. 按需写精炼的库/分类说明文件：只写本层特有的世界内容，写不出就不写。
3. 条目写对象本身与领域特有的边界（例如“灯号须双方约定同一套”）；细节文采留简，第 4b 层再润色。
4. 逐条自检：删去一条，卡失去的是一件公共之物，而非某个人的现状；本局状态一律交给事件与场景写入。

## 出口门禁

- `ygg check <世界书> --static-only` 0 错误。
- 公共引用 ID 就绪：第 3 层事件与角色组将引用的地点、势力、技能、装备条目都已存在。

门禁通过后呈报：产出摘要（各库条目数）+ 检查结果 + 下一步建议（进入 [`世界树·骨架`](../ygg-skeleton/SKILL.md)）。
