# 世界树·条目

本 skill 是建卡第 2 层：铺公共条目库的舞台。读取 `作者资料/通读/世界体系汇总.yaml`，对照 `世界书/设定/条目库.yaml` 与 `世界书/设定/能力.yaml`。条目库平铺约定、`按上下级`/`按种类` 目录硬规、`技能/` 隐藏必填规则与完整禁用词清单见 [`./references/条目与红线.md`](./references/条目与红线.md)。

## 步骤

1. 按 `设定/条目库.yaml` 逐库铺设：**全部条目库平铺于 `世界书/` 根下**（不得在外层再套分组目录）；**一物/一技/一地/一势力一文件**，不设人为总条目配额。
   - `按上下级`（地点库固定此分法）：凡建立子目录，**必须在该子目录内配同名实例 `.txt`**（缺即报 `条目.上级类型`）；若声明了 `上级类型`，仅映射值为 `[]` 的类型允许放在库根。
   - `按种类`：子目录层数须严格等于 `分级` 列表长度，且各级目录名与条目对应字段值一致。
   - `技能/`：每条技能**必须恰好适用 `设定/能力.yaml` 中 1 条 `技能可用` 规则**；命中 `等级门槛` 规则的技能，该规则声明的 `键字段` 与 `等级字段` 为隐藏必填项（缺即报 `条目.缺必填`）。
   - 每条一个 `.txt`，文件名即 ID（文件内写 `{库名}ID` 须与文件名一致，遵守 ID 一层字符安全规则）。
2. 善用库/分类同名说明文件（≤300 字）：同类原子条目拆分后，将整类共性法则抽入库根或分类目录同名 `.txt`（展开同分类多条时只输出一次），单条只写自身差异，避免重复抄写或回退拼盘；写不出本层特有内容就不写。**注意：说明文件与 `按上下级` 目录同名实例 `.txt` 均受 11 个 `文本.系统视角` 禁用词与 300 字 `同名说明` 预算检查**。
3. 条目写对象本身与领域特有的边界（例如“灯号须双方约定同一套”）；世上独一件的装备可在条目写可选内建字段 `唯一: true`（缺省 `false`，且不得在 `条目库.yaml` 重复声明），严禁在装备条目写原主或当前归属；细节文采留简，第 4b 层再润色。
4. 逐条自检：删去一条，卡失去的是一件单一可独立寻址的公共之物，而非多物拼盘或某个人的现状；本局状态一律交给事件与场景写入；全文无 25 禁用词、无破折号、无单独成行包裹标签、单行字段无换行。

## 出口门禁

- `ygg check <世界书目录> --static-only` 0 错误（未链接 `ygg` 到 `PATH` 时改用 `node <世界树仓库>/cli/ygg.mjs check <世界书目录> --static-only`）。
- 公共引用 ID 就绪：第 3 层事件与角色组将引用的地点、势力、技能、装备条目都已存在。

门禁通过后呈报：产出摘要（各库条目数）+ 检查结果 + 下一步建议（进入 `世界树·骨架`）。
