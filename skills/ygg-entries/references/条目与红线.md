# 条目与红线

本参考页供 `世界树·条目` 独立自包含查阅，涵盖条目库目录布局硬规、`按上下级`/`按种类` 校验边界、`技能/` 隐藏规则与完整措辞/ID 红线。

## 1. 条目库平铺与声明硬边界

- **平铺于 `世界书/` 根下**：`设定/条目库.yaml` 的每个顶层键是一个库名，直接对应 `世界书/{库名}/`（**严禁在外层套分组目录**，未声明的顶层目录报 `目录.未声明目录`）；库名不能与 `角色`、`历史`、`设定`、`世界概况`、`扮演准则` 或保留字重名。
- **禁止在库 `字段` 中重复声明的内建键**：任何库声明均不得写 `名称`、`ID` 或 `{库名}ID`；`装备` 库另**不得声明内建布尔字段 `唯一`**（否则报 `设定.字段声明`）。
- **每条实例必备键**：`{库名}ID` 必填且等于文件名（目录型实例等于目录名）；`名称` 可选，省略时等于 ID；其余键都须已在库 `字段` 中声明。
- 若声明了 `上级类型` 或字段的 `适用类型`，库须声明单值行内列表字段 `类型`。

## 2. 两种分法与目录硬错

| 分法 | 目录与实例文件硬规 | 说明文件 | 上级关系与校验边界 |
|---|---|---|---|
| `按种类` | 须填 `分级`（单值取值字段列表）；**目录层数须严格等于 `分级` 长度**，各级目录名等于对应分级字段值，否则报 `条目.分级` | 库根与各级分类目录下与目录同名的 `.txt` | 无 |
| `按上下级` | `地点` 库固定此分法；**凡建子目录必配同名实例 `.txt`**（否则报 `条目.上级类型`）；与所在目录同名的 `.txt` 即该目录实例，非说明文件 | 只有库根 `{库名}.txt` | 同名文件上级为再上一级目录实例，其余为所在目录实例；声明 `上级类型` 时，**仅映射值为 `[]` 的类型允许放在库根** |

- **同名实例特殊校验**：`按上下级` 库中与目录同名的实例 `.txt`（如 `地点/幽州/幽州.txt`）在检查器中与说明文件同享两项检查——**11 个 `文本.系统视角` 禁用词（报错）**与 **300 字 `同名说明` 长度预算（提示）**。

## 3. 协议直读库与 `技能/` 隐藏硬规

- **`地点`**：`地点ID` 与目录推导的上下级链，用于当前地点、地点链、`角色状态(所在)` 与 `当前场景`。
- **`装备`**：`装备ID` 与可选内建布尔字段 `唯一`（缺省 `false`，标示世上独一件的器物），用于初始装备、变化表与全本局强制唯一归属；条目本身不写原主或当前归属状态。
- **`技能`（隐藏硬规）**：
  1. 存在 `技能` 库时必须存在 `设定/能力.yaml`；
  2. **每条技能必须恰好适用 `技能可用` 中的 1 条规则**（匹配 0 条或多条均报错误 `技能.可用规则`）；
  3. 命中 `等级门槛` 规则的技能，该规则声明的 **`键字段` 与 `等级字段` 为隐藏必填项**（即便在 `条目库.yaml` 未标 `必填: true`，缺失仍报错误 `条目.缺必填`，取值须分别落入该维度键/键组与等级序列）；
  4. **路由只展开对在场者可用的技能**：即使在消息中被提及，若无在场者满足该技能的 `技能可用` 规则，路由仍会略过（理由：`不可用`）。

## 4. 原子粒度与禁拼盘

- **按需路由的原子优势**：公共条目按本局状态引用、地点链与提及窗口按需展开，且提及窗口按条目 `ID` 与 `名称` 逐字匹配、每库独立计字符预算。把多件对象揉成一条拼盘不仅导致角色与自建开局表单无法单持/单选，还会让单件名称无法命中提及路由，并挤占单库预算。
- **协议库边界**：
  - `技能/` 只收角色可习得或可持有的具体技能；纯百科总纲、体系原理放入常识类自定义条目库、分类说明文件或 `世界概况/`。
  - `装备/` 只收单一可独立持有的具体器物（或不可分的成套随身装备，如对剑、随身套装包）；不收巨型固定建筑/实验室设施（归 `地点/` 或自定义库），严禁把多件独立器物拼成一条。
  - `地点/` 与 `势力/` 等同理，一地/一势力一文件，不以合集条目替代具体对象。
- **共性抽入分类说明**：按种类分的库，将整类共性法则写进分类目录同名 `.txt`（≤300 字），具体原子条目只写自身差异。

## 5. 越界清单、完整措辞禁区与 ID 安全

- **越界清单**：把本局状态写进文本就是越界。以下内容只由事件变化或写场景写入，文本一律不写，换个字段名承载同样越界：
  `关系、婚姻、家系、职位、资产、持有物、伤势、当前穿着、能力的取得与丧失、当前所在`。
- **文本四问**：删去它，模型会不会出错；它是信息还是装饰；能否改成列表；不看原文能否读懂。
- **全部 25 个 `文本.禁用词`（出现即报错）**：
  `stat_data`、`变量`、`schema`、`索引`、`路由`、`ID`、`状态0`、`状态1`、`状态2`、`状态0/1/2`、`候选事件`、`额外模型`、`冲突队列`、`条目`、`注册`、`挂载`、`加载`、`目录`、`记录规则`、`目录规则`、`统一格式`、`登记规则`、`引用边界`、`记录边界`、`维护`。
- **全部 11 个 `文本.系统视角` 禁用词（说明文件及 `按上下级` 目录同名实例出现即报错）**：
  `模块`、`读取`、`登记`、`记录`、`资料`、`写入`、`本文件`、`运行状态`、`定义`、`依据`、`入口`（正文字数预算 300 字）。
- **格式与字符红线**：
  - 严禁 U+2014/U+2015 破折号（报 `文本.破折号`）；
  - 严禁单独成行的包裹标签（如 `<条目>`，报 `目录.包裹标签`）；
  - 单行文本字段（`文本` / `文本列表` 项 / `短语列表` 项）严禁包含换行符；`短语列表` 禁句末标点；
  - ID 一层字符安全：非空、首尾无空白、不含 `.` `/` `\`，不用保留字 `玩家`、`__proto__`、`constructor`、`prototype`。
- 完整参考见本地 Yggdrasill 仓库 `docs/参考/世界书.md` 与 `docs/写作规范.md`。
