# 世界树·骨架

本 skill 是建卡第 3 层：先搭可运行的逻辑骨架，正文字段只写足以过检与表意的短句，修饰与长段描写留给第 4 层。读取 `作者资料/通读/人物总名单与分期方案.yaml`、`作者资料/通读/全书年表与因果事件表.yaml` 与 `作者资料/通读/if分岔与开局提案.yaml`。角色组、事件、条件、变化与出口命令速查见 [`./references/骨架字段与检查.md`](./references/骨架字段与检查.md)。

## 步骤

1. **全名单角色组**：按总账名单建 `角色/{角色组ID}/角色组.yaml`：版本、档案分期与生效条件、初始能力/装备/所在、别名（使用两字及以上可辨识称呼，**禁用单字别名**——路由按逐字子串匹配，单字别名易高频误触发）；每份档案建最小合法壳（`基本信息.txt` 与 `角色印象.txt` 两份文件、必填字段齐全），切期档案的生效条件指向实际达成结果的分支。
2. **全书事件树**：逐事件原子建 `历史/事件/{事件ID}/事件.txt`：触发时间、地点、核心参与者、只写因果的门槛、分支、变化表、确认策略；把发现所需的取值同步补进 `设定/剧情标记.yaml`。
3. **过程与开局**：建 `历史/事件串/{事件串ID}.yaml` 与结局、if 线分支、`历史/开局选项.yaml` 与 `历史/开局方案/{方案ID}.yaml`。
4. **事件级出处**：每条 `作者资料/出处/` 记录写明来源（只含 `事件ID`、`来源` 两键；写原作卷章或作者原创）。

步骤完成标准：拍板名单中每个角色组与年表中每个保留事件全部落盘且可被静态检查接受；占位正文保持短句。

## 出口门禁（逻辑跑通再填肉）

优先使用 `ygg <命令>`（未链接 `ygg` 到 `PATH` 时改用 `node <世界树仓库>/cli/ygg.mjs <命令>`）：

- 全量 `ygg check <世界书目录>` 0 错误（含抽样）；反映真实因果的跨级过渡提示（如 `事件.世界依赖个人`）允许保留并在复核清单中单列说明，保持真实因果，不为凑“零提示”改写门槛。
- `ygg if <世界书目录>`：默认路径、各 if 线与开局方案符合预期，影响面无意外。
- `ygg preview <世界书目录> <关键角色组>`：首次登场初始化符合预期。
- 骨架拍板收口：引导模式引导作者用 `ygg view <世界书目录> --port 0` 审树，拍板后才进入第 4 层；自动模式按统筹传入口径取保守方案，记入待复核清单。

门禁通过后呈报：产出摘要（角色组/事件/事件串/开局数量）+ 检查与 `if`/`preview` 结果 + 待拍板项 + 下一步建议（并行进入 `世界树·档案` 与 `世界树·填景`）。
