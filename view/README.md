# 作者视图 `ygg view`

本地作者可视化工具。以世界书目录为输入，复用 `core/`、`checker/` 与 `cli/ygg.mjs` 的检查、引用、事件树、`if`、`context` 与 `tree` 语义。

## 启动

在任意创作项目目录直接执行；未把 CLI 链接到 PATH 时，把 `ygg` 换成 `node <世界树仓库>/cli/ygg.mjs`：

```sh
ygg view [<世界书目录> | --worldbook <世界书目录>] [--storage <审阅存储目录>] [--port <端口>]
# 未把 CLI 链接到 PATH 时
node <世界树仓库>/cli/ygg.mjs view [<世界书目录> | --worldbook <世界书目录>] [--storage <审阅存储目录>] [--port <端口>]
```

| 参数 | 缺省 | 说明 |
|---|---|---|
| `<世界书目录>` / `--worldbook` | 必填其一 | 现行世界书目录，含 `设定/`、`角色/`、`历史/`（两者不可同时传入） |
| `--storage` | `<世界书父目录>/作者资料/审阅器`（仓库内示例自动回退临时目录） | 批注、布局、备份与预览状态；显式传入时必须在实现仓库与世界书之外 |
| `--port` | `4317` | `0` 使用空闲端口；只监听 `127.0.0.1` |

启动后终端输出实际 URL。打开仓库内示例（如 `node cli/ygg.mjs view examples/三国演义/世界书 --port 0`）且未显式传入 `--storage` 时，因默认存储路径落入实现仓库内，CLI 会自动改用系统临时目录下的隔离路径（启动时不提前创建目录，不写入仓库）；若显式传入位于实现仓库或世界书内的 `--storage`，仍按存储隔离规则严格拒绝启动。

## 输入与不读取的内容

- 使用 `readDeclarations`、`validateDeclarations`、`loadWorldbook`、`parseYaml`、`buildReferenceIndex`、`analyzeEventTree`、`whatIf` 与 `checkWorldbook`。
- 时间按 `设定/纪年.yaml`，事件分类按 `设定/事件分类.yaml`，对象键按现行 `类型:ID`。
- 检查读取世界书父目录下的 `作者资料/出处` 与 `yggdrasill.yaml`；预览的临时项目副本同时复制世界书、`作者资料/出处` 与 `yggdrasill.yaml`，不复制 `来源资料/`、存储目录或无关资产。
- 不读取原作正文，不调用叙事模型，不访问外网。

## 视图

1. **世界主树**：按事件串与独立事件分组的时间轴；显示时间窗口、核心参与者、分类与结构状态；支持缩放、折叠、搜索及角色、版本、主类型、标签、事件结果筛选，筛选变更即时刷新左侧计数。
2. **局部关系**：选中事件展开 1–5 层；条件、排斥与普通关联来自现行引用索引；箭头不替代完整 `all/any/none` 与分支详情。
3. **角色汇总**：按角色组、版本与档案分区显示档案初始能力/初始装备、事件变化、暂存未接回项与台词统计卡片。
4. **如果视图**：选择开局方案、排除事件、指定分支、停用角色组；结果来自 `core/what-if.mjs` 的唯一计算。
5. **上下文预览**：封卷并只读推演一局的路由上下文；复用 `core/context-preview.mjs`，展示输入摘要、总字符与分块字符、预算占用（经历、候选与各条目库）与审计明细，可勾选输出完整渲染正文；不写世界书、不调用叙事模型、不访问外网，不接受 `本局` 文件路径。
6. **事件详情与相关角色**：完整门槛、分支与变化、角色位置、适用分支、知情、记忆、语料、候选台词与本事件台词统计；版本/时期档案对照只作手动查阅。
7. **编辑、批注与布局**：单事件结构化表单 ↔ YAML 原文双模式编辑、新建事件、角色位置编辑/新建、批注与节点布局保存。世界主树工具栏提供「台词统计 / 导出树」弹窗（纯静态统计、`GET /api/tree.md` 预览与下载）与「＋ 新建事件」。

## 图形化编辑

- **单事件表单**：覆盖 `docs/参考/事件.md` 全部 18 个字段、递归条件树（`all`/`any`/`none` + 11 类条件）与变化表（含 `移除` 有/无值与类型保持）。表单模式经 `POST /api/yaml/format` 按规范键序重排且不保留行内注释；需保留注释请用 YAML 原文模式。切换与预览经 `POST /api/yaml/parse`，解析失败时停留在 YAML 模式且草稿不丢失。
- **新建事件**：`POST /api/event/create/preview` 复用同一静态检查与保存管线；保存前二次核对目标文件仍不存在。
- **角色位置**：覆盖全部 10 个字段与 5 个触发语料子字段，`POST /api/position/preview` 区分编辑（核对 revision）与新建（revision 须为空）。
- 仍不在视图内：事件与角色位置的删除、`事件ID`/`角色组ID` 改名、跨文件引用迁移，以及设定声明/角色组/档案/条目库/事件串/开局文件的编辑——这些仍在源文件、CLI 或 skill 中完成。视图不读取 `来源资料/`。

## 编辑与保存

候选内容是现行事件 `.txt` 或角色位置 `.txt` 的 YAML 原文，不要求 `<事件>` 外壳；独立成行的包裹标签仍由现行检查器拒绝。

- 预览在「世界书 + 作者资料/出处 + yggdrasill.yaml」的临时副本中执行，使用 `checkWorldbook(..., {sampling: false})` 静态检查；预览不写世界书、不写存储目录。
- 预览令牌 15 分钟有效，绑定候选原文、整树输入指纹与令牌种类（编辑事件、新建事件、编辑角色位置、新建角色位置）。原文或依赖变化、预览后再编辑、并发保存、目标文件在保存前被外部创建均返回 409。
- 保存前写入 `<storage>/修改备份/<时间戳_UUID>/` 只增不删：编辑事件备份 `事件.txt`；编辑角色位置备份 `角色位置.txt`；`修改说明.json` 固定记录 `事件ID`、`源文件`、`保存时间`、`修改前哈希`（新建时为 `null`）与 `修改后哈希`，仅在新建事件或角色位置操作时记录 `操作`，仅在涉及角色位置时记录 `角色组ID`，仅在编辑角色位置时记录 `备份文件`。写回使用同目录临时文件与 `rename` 原子替换，保留原文件权限；新建文件以 `0o644` 原子创建。保存后运行现行全量检查（`checkWorldbook`）并报告错误/提示。
- `view/store.mjs` 提供 `restore(backup)` 供测试/人工恢复演练：事件编辑、角色位置编辑与新建回滚三类各自核对前后哈希；新建回滚只删除新建文件并清理其自身留下的空目录，绝不删除非空目录或 `历史/事件` 本身。
- 批注与布局写入 `<storage>/审阅状态.json`，schema 为 `{notes:{key:{text,status}}, layout:{key:{x,y}}}`；与事件正文完全分离，写操作串行化，冲突返回 409。

## 安全边界

只监听 `127.0.0.1`；校验 `Host`、`Origin`、一次性 `X-Review-Token`、`Content-Type`；CSP 禁止外部脚本与框架；请求体上限 2.5MB（YAML 转换接口为 256KB）；拒绝符号链接、路径穿越、`__proto__`/`prototype`/`constructor` 键与保留 ID（`玩家` 等）；静态资源只从内置白名单读取，不按 URL 读取任意文件；`POST /api/context` 只接受白名单键并拒绝 `本局`，避免成为任意本地文件读取入口。

存储默认值必须在世界书、`作者资料/出处` 与实现仓库之外；显式 `--storage` 也不能落在这些位置。启动与读取不创建存储目录，不写世界书。
