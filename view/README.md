# 作者视图 `ygg view`

本地作者可视化工具。以现行世界书为输入，复用 `core/`、`checker/` 与 `cli/ygg.mjs` 的检查、引用、事件树与 `if` 语义；不读取旧创作项目、旧 forge 解析器或旧索引文件。

## 启动

在世界树代码仓库根执行：

```sh
ygg view --worldbook <世界书目录> [--storage <审阅存储目录>] [--port <端口>]
# 未把 CLI 链接到 PATH 时
node cli/ygg.mjs view --worldbook <世界书目录> [--storage <审阅存储目录>] [--port <端口>]
```

| 参数 | 缺省 | 说明 |
|---|---|---|
| `--worldbook` | 必填 | 现行世界书目录，含 `设定/`、`角色/`、`历史/` |
| `--storage` | `<世界书父目录>/作者资料/审阅器` | 批注、布局、备份与预览状态；必须在实现仓库与世界书之外 |
| `--port` | `4317` | `0` 使用空闲端口；只监听 `127.0.0.1` |

启动后终端输出实际 URL。仓库内示例 `examples/雾港/` 位于实现仓库中，使用时必须显式指定仓库外的 `--storage`，否则按存储隔离规则拒绝启动。

## 输入与不读取的内容

- 使用 `readDeclarations`、`validateDeclarations`、`loadWorldbook`、`parseYaml`、`buildReferenceIndex`、`analyzeEventTree`、`whatIf` 与 `checkWorldbook`。
- 时间按 `设定/纪年.yaml`，事件分类按 `设定/事件分类.yaml`，对象键按现行 `类型:ID`。
- 检查读取世界书父目录下的 `作者资料/出处` 与 `yggdrasill.yaml`；预览的临时项目副本同时复制世界书、`作者资料/出处` 与 `yggdrasill.yaml`，不复制 `来源资料/`、存储目录或无关资产。
- 不读取原作正文，不调用叙事模型，不访问外网。

## 视图

1. **世界主树**：按事件串与独立事件分组的时间轴；显示时间窗口、核心参与者、分类与结构状态；支持缩放、折叠、搜索及角色、版本、主类型、标签、事件结果筛选。
2. **局部关系**：选中事件展开 1–5 层；条件、排斥与普通关联来自现行引用索引；箭头不替代完整 `all/any/none` 与分支详情。
3. **角色汇总**：按角色组、版本与档案分区显示档案初始能力/初始装备、事件变化与暂存未接回项；替代旧成长树。事件变化是分支定义，不等于默认已发生；暂存项不计入当前档案。
4. **如果视图**：选择开局方案、排除事件、指定分支、停用角色组；结果来自 `core/what-if.mjs` 的唯一计算，列出没发生、新发生、分支不同、停住的事件串、影响面与异常。
5. **事件详情与相关角色**：完整门槛、分支与变化、角色位置、适用分支、知情、记忆、语料与候选台词；版本/时期档案对照只作手动查阅，不冒充事件当时已生效。
6. **编辑、批注与布局**：单事件 YAML 原文编辑、差异预览、影响反查、批注与节点布局保存。

不包含本局快照/上下文预览、图形化机制编辑器、Markdown 事件树生成器或台词统计；这些不在本工具范围。

## 编辑与保存

候选内容是现行事件 `.txt` 的 YAML 原文，不要求 `<事件>` 外壳；独立成行的包裹标签仍由现行检查器拒绝。

- 预览在临时项目副本中执行，使用 `checkWorldbook(..., {sampling: false})` 静态检查；预览保留世界书、`作者资料/出处` 与 `yggdrasill.yaml`，并报告运行参数来源。
- 预览令牌 15 分钟有效，绑定事件原文 revision、整树输入指纹与候选原文。原文或依赖变化、预览后再编辑、并发保存均返回 409。
- 保存前把旧原文与 `修改说明.json`（事件ID、源路径、保存时间、前后哈希）写入 `<storage>/修改备份/<时间戳_UUID>/`；备份只增不删。
- 写回使用同目录临时文件与 `rename` 原子替换，保留原文件权限；保存后运行现行完整 `checkWorldbook` 并报告错误/提示，不把静态预览当作完整检查。
- 批注与布局写入 `<storage>/审阅状态.json`，schema 为 `{notes:{key:{text,status}}, layout:{key:{x,y}}}`；与事件正文完全分离，写操作串行化，冲突返回 409，状态文件损坏时页面提示并允许保存重建。
- `view/store.mjs` 提供 `restore(backup)` 供测试/人工恢复演练：只接受本存储 `修改备份/` 内的目录，核对前后哈希，目标文件在保存后又被修改时拒绝覆盖。

## 安全边界

只监听 `127.0.0.1`；校验 `Host`、`Origin`、一次性 `X-Review-Token`、`Content-Type`；CSP 禁止外部脚本与框架；请求体上限 2.5MB，请求超时 90 秒；拒绝符号链接、路径穿越与 `__proto__`/`prototype`/`constructor` 键；静态资源只从内置白名单读取，不按 URL 读取任意文件。

存储默认值必须在世界书、`作者资料/出处` 与实现仓库之外；显式 `--storage` 也不能落在这些位置。启动与读取不创建存储目录，不写世界书。
