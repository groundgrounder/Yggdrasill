# 作者视图

`ygg view` 是本地运行的网页可视化工具，用来浏览事件树、查看角色分期、推演 `if` 分支、预览单轮上下文，并直接编辑事件和角色位置。它只监听本机 `127.0.0.1`，不联网，不调用模型，也不读取原作正文。

## 启动

在任意创作项目目录直接运行（未执行 `npm link` 时，将 `ygg` 替换为 `node <世界树仓库>/cli/ygg.mjs`）：

```sh
ygg view <世界书目录> --port 0
```

| 参数 | 缺省 | 说明 |
|---|---|---|
| `<世界书目录>` / `--worldbook` | 必填其一 | 目标世界书目录，含 `设定/`、`角色/`、`历史/`（两者不可同时传入） |
| `--storage` | `<世界书父目录>/作者资料/审阅器`（仓库内示例自动回退临时目录） | 存放批注、节点布局和修改备份；显式指定时须落在世界书和实现仓库之外 |
| `--port` | `4317` | 传 `0` 自动选用空闲端口，仅监听 `127.0.0.1` |

启动后终端会打印本机访问地址，在浏览器打开即可，按 `Ctrl + C` 停止。打开仓库自带示例（如 `node cli/ygg.mjs view examples/三国演义/世界书 --port 0`）且未传 `--storage` 时，会自动使用系统临时目录，不向仓库写入任何文件。

## 主要页面

1. **世界主树**：按事件串和独立事件展开时间轴，展示时间窗口、核心参与者、分类和结构状态；支持缩放、折叠、搜索，以及按角色、版本、主类型、标签、事件结果筛选。顶部工具栏提供「台词统计 / 导出树」和「＋ 新建事件」。
2. **局部关系**：选中任意事件后展开 1–5 层上下游依赖、排斥和普通关联连线（连线用于快速看清邻域，完整 `all`/`any`/`none` 门槛以事件详情为准）。
3. **角色汇总**：按角色组、版本和档案分区查看初始能力、初始装备、事件变化、暂存未接回项和台词统计。
4. **如果视图**：勾选开局方案、排除事件、指定分支或停用角色组，实时查看下游事件变化（结果与 `ygg if` 一致）。
5. **上下文预览**：填写开局方案、地点、在场角色和最近消息，只读推演一轮进入模型的提示词总字符、各区块预算占用和略过原因，可展开查看完整渲染正文（结果与 `ygg context` 一致）。
6. **事件详情**：查看单个事件的完整门槛、分支、变化表、角色位置、候选台词和台词统计，并可在右侧直接编辑或记录审阅批注。

## 编辑范围

**支持在网页中直接操作**

- **编辑单事件**：支持结构化表单模式和 YAML 原文模式切换，涵盖事件全部字段、递归条件树和变化表。表单模式保存时会按规范键序重排且不保留行内注释；需要保留注释请用 YAML 原文模式。
- **新建事件**：走同一套检查和保存流程，保存前会二次确认目标文件尚不存在。
- **编辑角色位置**：支持编辑或新建某事件下的角色位置文件，覆盖全部字段和触发语料。
- **批注布局**：节点批注和画布布局保存在审阅目录的 `审阅状态.json` 中，不修改世界书源文件。

**暂不在网页内处理**

删除事件或角色位置、重命名 `事件ID` 或 `角色组ID`、跨文件引用迁移，以及设定声明、角色组、档案、条目库、事件串、世界线和开局文件的编辑，仍在源文件、CLI 或对应 skill 中完成。

## 备份机制

网页里的每次写入都带有预览校验和自动备份，不会悄悄覆盖坏数据：

- **先预览再保存**：点击保存前，工具会在临时副本中跑静态检查；只要原文未变且无并发修改才允许落盘，保存后会自动跑一次全量检查并展示错误或提示。
- **原文件只增不删备份**：每次写入前，原文件会备份到 `<storage>/修改备份/<时间戳_UUID>/`，并附带记录修改前后哈希的 `修改说明.json`，方便人工核对或回退。

## 实现说明

以下内容供维护或二次开发 `view/` 的开发者查阅。

### 数据来源

- 直接复用 `core/`、`checker/` 和 `cli/ygg.mjs` 的读取、校验、引用索引、事件树、`whatIf` 和上下文预览逻辑（`readDeclarations`、`validateDeclarations`、`loadWorldbook`、`parseYaml`、`buildReferenceIndex`、`analyzeEventTree`、`whatIf`、`checkWorldbook`、`core/context-preview.mjs`）。
- 时间按 `设定/纪年.yaml`，事件分类按 `设定/事件分类.yaml`，对象键按现行 `类型:ID`。
- 检查读取世界书父目录下的 `作者资料/出处` 和 `yggdrasill.yaml`；预览的临时项目副本只复制世界书、`作者资料/出处` 和 `yggdrasill.yaml`，不复制 `来源资料/`、存储目录或无关资产。

### 保存协议

- 候选内容是现行事件 `.txt` 或角色位置 `.txt` 的 YAML 原文，不要求包裹标签；独立成行的包裹标签由检查器拒绝。
- 单事件表单覆盖 `docs/参考/事件.md` 全部 18 个字段、递归条件树（`all`/`any`/`none` + 11 类基础条件；新增的 `世界线` 条件在表单中以「未知（保留原样）」保留，亦可在 YAML 原文模式直接编辑）和变化表（含 `移除` 有/无值及类型保持）；表单经 `POST /api/yaml/format` 重排，切换预览经 `POST /api/yaml/parse`，解析失败停留在 YAML 模式且不丢草稿。
- 预览接口包括事件编辑、新建（`POST /api/event/create/preview`）和角色位置编辑/新建（`POST /api/position/preview`，按 revision 区分编辑和新建），在临时副本中使用 `checkWorldbook(..., {sampling: false})` 校验，不写世界书和存储目录。
- 预览令牌 15 分钟有效，绑定候选原文、整树输入指纹和令牌种类；原文变化、预览后再编辑、并发保存或新建目标已存在均返回 `409`。
- 落盘使用同目录临时文件配合 `rename` 原子替换（新建文件权限 `0o644`）；`view/store.mjs` 提供 `restore(backup)` 供测试和人工恢复演练，按操作类型核对前后哈希，新建回滚仅删新建文件及其自身留下的空目录。
- 批注和布局写入 `<storage>/审阅状态.json`，schema 为 `{notes:{key:{text,status}}, layout:{key:{x,y}}}`，写操作串行化，冲突返回 `409`。

### 安全边界

- 只监听 `127.0.0.1`；校验 `Host`、`Origin`、一次性 `X-Review-Token` 和 `Content-Type`；CSP 禁止外部脚本和框架；请求体上限 2.5MB（YAML 转换接口为 256KB）。
- 拒绝符号链接、路径穿越、`__proto__`/`prototype`/`constructor` 键和保留 ID（如 `玩家`）；静态资源仅从内置白名单读取；`POST /api/context` 只接受白名单键并拒绝 `本局`。
- 存储默认值须落在世界书、`作者资料/出处` 和实现仓库之外；显式传入 `--storage` 落入上述位置时拒绝启动。启动和读取不提前创建存储目录，不写世界书。
